# 星海尽头：总览

2026-10-25 整理。这是所有文档的入口：项目是什么、已经定下的决定、文档怎么读、工作怎么做。第一版之前的方案、规格和各步记录已经删除（需要时从 Git 历史里找），其中还没做完的内容都已合并进本目录的新文档。

## 一、一句话

**一个人在星海中漂流，降落到荒凉而美丽的星球上，看远山、日落和满天星辰；沿着一个已经消失的文明留下的路、塔和回声，走到他们离开的地方。**

塞尔达式的卡通画风，简单而好看的明暗，整体基调是寂寥。用户要的感觉是：**宇宙文明的寂寥与沧桑**。故事很简单，氛围要到位。

## 二、现在在哪里

- **第一版可玩已完成**（2026-10-24，已合并进 `main`）：晨的主线从出发地 → 古城 → 回声洞 → 烽火塔链 → 天梯 → 断口平台 → 终章与字幕，能完整玩一遍。现有内容见 [03 现状与遗留](03-现状与遗留.md)。
- **用户试玩的结论**：流程有了，但质量不够——画面有"廉价的塑料感"，全球地形"像硬凑出来的"，没有引导，界面文字堆砌，近景模型粗糙。
- **接下来**：按 [20 分步交接](20-分步交接.md) 做第 1～4 步（渲染、地形、主线模型、引导与界面），然后 GPT 自测、Claude 审图，再交给真人试玩，根据反馈慢慢改。当前做到哪一步见 [进度](进度.md)。

## 三、已经定下的决定

| 决定 | 内容 |
| --- | --- |
| 引擎 | Godot 4.7.2 标准版 + GDScript；卡通明暗写光照着色器；780M 核显上流畅 |
| 世界 | 晨（可降落，半径 40 公里，有海）、烬、霜（可降落的原型星球）、渊（带光环的气态巨星，背景）。太空到地面无缝，没有读条 |
| 范围 | **只做晨。** 烬、霜、渊环暂不涉及，不为它们新增内容；公共代码的改动仍要保证它们不坏 |
| 故事 | 简单的暗线，不写一句台词和文字说明，靠建筑、壁画和"回声"讲 |
| 氛围 | 优先级最高；所有内容先问"它让这里更寂寥、更沧桑、更有文明感吗" |
| 飞行 | 飞船和人分开：飞行就是驾驶飞船；降落后飞船停在原地，人只能步行 |
| 移动 | 步行、跳跃、滑翔（围巾展开成软翼）、只在标出的地方攀爬；没有体力条、没有摔伤 |
| 地形 | 史诗尺度：近 4 公里的主山脉、近 1 公里深的大峡谷、洞穴网络。**2026-10-25 起，晨的大尺度地形改为离线雕刻、侵蚀、烘焙成高度场**（[11](11-地形重塑.md)），不再用公式叠加 |
| 结局 | 晨自己收尾：四个回声看完后天梯断口亮起；驾驶飞船飞上去看终章回声，沿光之路飞向星海，字幕，然后继续自由探索 |
| 画面 | 卡通但不塑料：AgX 色调映射、明暗交界过渡带、描边、环境光遮蔽、多尺度笔触材质、保留明度层次的大气（[10](10-质感与渲染.md)） |
| 建模 | 人和东西用 Blender 的建模工具做，所有边倒角；通用自然物可用 CC0 素材；地形、洞穴、天梯主体程序生成 |
| 引导 | **2026-10-25 改：要有引导，但不做箭头。** 用远景信号、路碑、回声余光、手记草图、地图上的模糊圆圈引导；设置里可调强弱（[12](12-引导与界面.md)） |
| 界面 | 默认画面没有常驻文字；三种字号、大留白；能用图标和画面表达的不用字 |
| 音乐 | 用户提供的曲目，只用于个人游玩，不商用、不公开分发；按情境分配，统一响度 |
| 不做 | 敌人、战斗、任务列表、任务文字、指路箭头、文字剧情、对话、收集计数器、照片或扫描贴图 |

## 五、工作方式

### 分工

- **Claude**：写方案和规格，调度编码，审图验收，整理文档。
- **编码**：GPT、Grok（Cursor 命令行 `agent -p` 或 Grok Build `grok -p`）按 [分步交接](20-分步交接.md) 执行；Claude 也可以直接改。
- **用户**：在"第二版"完成后自己试玩，并请 3～5 个没玩过的人试玩（[20](20-分步交接.md) 的"真人试玩"）；画面、听感、手感和性能以用户本机实际试玩为准。

### 每一步

1. 先读 [进度](进度.md)，再读本步涉及的规格和 [03](03-现状与遗留.md) 里相关的遗留。
2. 一步一步做，不跳步，不合并步骤；不改和当前步骤无关的代码，发现别处的问题记进记录。
3. 规格里的数值是起点，不是最终值。效果不好可以调，在记录里写明调了什么、为什么。
4. 规格没写到、需要设计判断的地方，按 [圣经](01-世界观与美术圣经.md) 决定并记录。只有规格之间互相矛盾、或要改变第三节的决定时，才停下来问用户。
5. 每一步结束：跑本步的检查（以报告里的 `passed` 为准）→ 截本步机位并和参考对比 → GPT 自查 → **Claude 审图** → 写记录 → 把遗留合并进 [03](03-现状与遗留.md) → 更新进度 → 提交推送。
6. **随时可能中断，中断不丢东西**：每完成一步就提交推送；一步做到一半要停时，把能提交的部分整理成可运行的状态提交推送，更新 [进度](进度.md)（做到哪一项、下一步从哪里接、有什么临时的东西），然后停下。用户给了终点就做到那里为止。

### 分支

只有 `main` 和 AI 开发分支 `ai/wanderer`（不存在时从 `main` 新建）。所有 AI 都在 `ai/wanderer` 上提交；合并进 `main` 由用户决定。

## 六、名词

| 名词 | 意思 |
| --- | --- |
| 远行者 | 这个已经消失的文明。只在文档里使用，游戏里不出现文字 |
| 文明区 | 一组相互关联的遗迹：聚落、道路、水渠、梯田、墓地、神殿洞穴、烽火塔 |
| 回声 | 在关键遗迹处出现的一段过去的剪影光影，无文字，是讲故事的主要手段 |
| 烽火塔 | 建在山顶、两两相望的石塔，点亮一座就能看到下一座 |
| 天梯 | 晨上通往太空的巨型高塔，已断裂，是全星球最醒目的巨构 |
| 断口平台 | 天梯 6.2 公里高的断口下方还完整的平台，只能驾驶飞船到达，晨的结局在这里 |
| 光之路 | 终章回声留下的一串光点，从断口平台伸向「渊」 |
| 意图图 | 第 2 步地形烘焙的输入：晨的大轮廓和山脉、峡谷、火山、出发地的位置 |
| 高度场 | 第 2 步烘焙出的六面立方体高度数据 `dawn_terrain.res`，运行时采样 |
| 远景信号 | 第 4 步的引导手段：下一个目标处只有远看才明显的光、光尘、鸟群 |
| 参考对比 | 每张主机位截图和参考作品同类画面并排比较，见工程约定第四节 |
| 审图 | Claude 看截图对比，判断这一步的画面是否达标；不达标不算完成 |
