# 世界观与美术圣经

本文是所有内容的判断标准。做任何会被玩家看到或听到的东西之前，先对照这里。

## 一、一句话

> 很久以前，远行者在这三颗星球之间生活、建造、迁徙。后来他们沿着天梯离开，去了星海尽头。你在他们离开很久以后来到这里，沿着他们留下的路、塔和回声，走到他们出发的地方。

## 二、故事

完整的故事只写在文档里，游戏中没有任何文字叙述，玩家只能从环境里拼出来。拼不全也没关系。

1. **晨，故乡。** 远行者在河边建起聚落，开梯田、修水渠、在山顶建烽火塔互相照应。他们相信星海有尽头，那里是所有光汇聚的地方。神殿洞穴的壁画画的就是这个信仰：一个圆环，一条从地面通向圆环的路。
2. **烬，熔炉。** 为了建造离开的方舟，他们在烬上开山采石、冶炼。烬原本也有绿色，过度开采后变成了今天的赤色荒漠，巨大的采石坑和倒下的巨像还留在沙丘里。
3. **霜，记忆。** 他们把文明的记录封存在霜上的一艘方舟里。方舟最后没有出发，被冰川吞没。
4. **天梯与渊环。** 他们在晨上建起直通太空的天梯，在气态巨星「渊」的轨道上建起环形站，在那里组装方舟，最后全部离开。
5. **守望者。** 有一个人留了下来，负责让烽火塔一直亮着，好让后来的人找到路。很多年后，烽火一座座熄灭了。
6. **你。** 你在很久以后到来。你登上的每一座烽火塔都会重新点亮，下一座塔会回应。晨的回声都看完以后，天梯的断口上亮起一处光。你驾驶飞船飞上去，在那里看到守望者最后做的事：他把一盏灯放在断口的尽头，一条光的路从那里升向「渊」，留给后来的人。你可以沿着这条路飞向星海尽头，这就是结局。

> 2026-10-20：目前只做晨，结局放在天梯断口。烬、霜和渊环的故事（第 2、3 条，以及第 4 条里渊环的部分）保留，作为以后的方向；以后做到渊环时，可以让光之路通向那里。

基调是**离开与等待**，不是毁灭与死亡。没有灾难，没有尸骨，没有战争痕迹。寂寥来自"他们走了，这里只剩风"；沧桑来自"时间过去了很久"。

## 三、三种感觉怎么做出来

| 感觉 | 规则 | 具体手段 |
| --- | --- | --- |
| **文明感** | 遗迹有生活的逻辑，不是随手撒的 | 聚落建在河边平地；道路连接聚落、神殿和烽火塔；水渠从上游顺等高线引水；梯田在聚落周围的缓坡上；墓地在能望见天梯的山坡；烽火塔在山顶两两相望。玩家走一圈就能感觉到"这里住过人，他们这样生活" |
| **史诗感** | 尺度和视线 | 每颗星球一个在大部分地方都能看见的巨构；地形本身也要有尺度：晨有一条最高近 4 公里、带雪峰和冰川的主山脉，和一条深近 1 公里、岩层像台阶一样的大峡谷（[11 地形重塑](11-地形重塑.md)）；地标在几公里外就能认出轮廓；关键地点有开阔的视野，比如烽火塔顶、山口、峡谷边、天梯观景环和断口平台。滑翔让人能从这些高处飞下去 |
| **空寂感** | 留白、时间、自然的回收 | 没有人，也没有会说话的东西；遗迹被土、苔藓、沙和藤蔓慢慢吞掉；声音以风为主，音乐稀疏，大量安静的时间；每个地点之间留出足够的空旷 |

### 节奏

- 在晨上沿路走，**大约每五到十分钟**应该遇到一样新东西：一段倒塌的墙、一座桥、一片梯田、一座烽火塔、一个洞口。
- 两个"大"地点（聚落、神殿、天梯基座）之间，步行至少十五分钟。空旷本身就是体验的一部分。
- 不要把东西挤在一起。宁可少放，也不要让玩家同时看到三四个遗迹在争夺注意力。

## 四、远行者的建筑语言

### 形态

- **主母题是"环与径"**：一个圆环，加一条从下方通向圆环的直线。出现在门楣、地面铺装、壁画、塔顶火盆和巨构上。这是全游戏唯一的符号，不要发明别的文字或符号。
- **整体修长**：门洞高 3.2 米、宽 1.6 米，比人高出一截，暗示远行者比人更高更瘦。柱子细长，柱身直径与高度之比约 1:10。
- **圆与弧**：平面多为圆形或弧形，屋顶是低矮的穹顶或平顶加檐，少用尖顶和直角转角。
- **台地与台阶**：重要建筑都建在台基上，有宽而浅的台阶（踏步高 0.25 米、深 0.6 米）。
- **厚重的底，轻盈的顶**：墙基和台基用大块石材，上部逐渐变薄变细。

### 材料与颜色

| 材料 | 颜色 | 用在哪里 |
| --- | --- | --- |
| 石材 | 浅赭 `#D6C7A4`，阴影偏暖灰 | 墙、柱、台阶、塔身，占绝大部分 |
| 古铜 | 青绿铜锈 `#5E8C84` | 门框、环形构件、塔顶火盆、天梯的环箍 |
| 光纹 | 琥珀 `#F2B45A`，自发光 | 刻在石上的环与径符号；平时几乎熄灭（亮度 0.1），被唤醒时亮起（亮度 2.0） |
| 布 | 褪色的赭红 `#B5654A` | 极少量：残破的旗、帘，被风吹动 |

不用照片纹理。石材的细节来自卡通色块、层理色带和风化处理，与现有 `stone.svg` 的笔触风格一致。

### 时间的痕迹

每个遗迹都要至少有两种：

| 痕迹 | 规则 |
| --- | --- |
| 顶部残缺 | 墙和塔的上部缺块，断面不规则 |
| 倾斜与下沉 | 部分构件倾斜 2～6 度，或下沉 0.2～1 米 |
| 苔藓 | 朝上的面，在潮湿的群系里，颜色用现有苔色 |
| 积沙与积土 | 墙基和低处被土掩埋；干燥的地方偏沙色 |
| 藤蔓 | 潮湿地区的墙面，从墙脚往上爬，不超过墙高的一半 |
| 倒塌 | 两成左右的房屋只剩墙基，旁边有落石 |
| 植物占据 | 广场裂缝里长草，少数房屋里长出一棵树 |

完好无损的建筑只有一种：天梯的主体。它的完好本身就是一种震撼。即便如此，它的顶部也是断的。

## 五、尺度阶梯

| 层级 | 尺寸 | 例子 | 应该在多远被认出 |
| --- | --- | --- | --- |
| 人 | 1～3 米 | 台阶、灯柱、矮墙、石碑 | 50 米 |
| 建筑 | 5～15 米 | 房屋、桥、水渠拱 | 300 米 |
| 纪念物 | 20～80 米 | 烽火塔、神殿门、巨像、巨环 | 2～5 公里 |
| 巨构 | 1 公里以上 | 天梯、倒下的巨像、冰中方舟、渊环 | 大半个星球 |

纪念物和巨构必须在远处有清楚的轮廓：

- 用和背景对比明显的明度。比如雪山顶上的塔要用深色石材。
- 顶部加一个形状特别的元素：火盆、环、旗。
- 夜里用琥珀色光点标出位置。

## 六、色彩与光

### 各星球的整体色调

| 星球 | 主色 | 气质 |
| --- | --- | --- |
| 晨 | 绿、蓝、浅赭石材 | 温和、宁静，故乡的感觉，最有生活痕迹 |
| 烬 | 赤红、锈橙、深紫阴影 | 炎热、荒芜、被耗尽，巨大的人工伤痕 |
| 霜 | 冰蓝、白、青灰 | 冰冷、凝固、封存，像时间停止 |
| 渊环 | 深蓝黑、古铜、琥珀光 | 太空中的寂静，最后的光 |

### 时间与情绪

- **正午**：干净明亮，适合看清遗迹的布局。
- **黄昏**：最有沧桑感的时刻。石材被染成暖金色，影子拉长。重要的回声在黄昏看效果最好，但不强制。
- **夜晚**：琥珀光纹在夜里格外明显；已点亮的烽火塔在远处是一串光点；天梯的光带像通向星空的阶梯。
- **雨与雾**：遗迹在雾里只剩轮廓，最寂寥。

## 七、声音的气质

- 风是主角。在遗迹里，风穿过拱门和破窗会有不同的音色（空洞的低鸣、细的哨音）。
- 音乐稀疏，大部分时间是安静的，每段之间留 40～120 秒空白。
- 回声和点亮烽火时有一小段音乐，短、轻、温暖，不是胜利号角。
- 洞穴和室内有混响，脚步声变化。
- 不用人声歌唱，不用对白，不用语言。

## 八、界面与引导

> 2026-10-25 更新：第一版试玩后，用户要求有引导、界面留白。细则见 [12 引导与界面](12-引导与界面.md)。

- 默认画面没有常驻文字。状态数字只在驾驶飞船时出现，小地图不带文字。
- 文字只有三类：地点名称（只出现在旅行手记和地图上，2～6 个字）；必要的操作提示（例如"F 登船"），只在需要时短暂出现，熟悉后不再出现；菜单和设置。
- 一种字体、三种字号，大留白；能用图标或画面表达的不用字。
- 地点名称要朴素、有画面感，例如「河畔古城」「回声洞」「天梯基座」「海蚀拱门」。不用"遗迹 A""区域 3"这类名字。
- **引导靠世界本身**：下一个目标处只在远看时明显的光、光尘或鸟群；古道上的路碑；回声结束时飘向下一处的光点；手记里下一处的线稿草图；地图上的模糊圆圈。玩家感到的是"那边好像有什么"，而不是"去那里"。

## 九、不做

- 敌人、战斗、生命值、任务列表、任务文字、指路箭头、任务标记、距离数字。
- 文字剧情、日志条目、对话、旁白、可读的书信。
- 收集计数器显示在主画面上。手记里可以看到回声的进度，但用符号表示，不用数字。
- 远行者的遗体、骸骨、战争或灾难痕迹。
- 照片、扫描贴图，以及用户没有确认可以使用的外部素材。
- 和"环与径"之外的符号、文字、标志。
- 过多的同类重复：同一种房屋不要连续出现超过三次而没有变化。

## 十、判断一个新东西该不该做

依次问四个问题，有一个答"否"就不做或改方案：

1. 它让这里更寂寥、更沧桑或更有文明感吗？
2. 它和远行者的生活逻辑一致吗？（为什么会在这里，曾经用来做什么）
3. 它在远处、近处各有可看的东西吗？
4. 780M 跑得动吗？（见 [工程约定](02-工程约定.md) 的性能预算）
