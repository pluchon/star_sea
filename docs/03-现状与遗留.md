# 现状与遗留

2026-10-25 整理自第一版的各步记录、性能对照和进度表。本文回答两个问题：**游戏里现在有什么**，**还有哪些已知问题、由哪一步处理**。每一步结束时更新遗留表：新发现的加进来，做完的删掉。

代码结构、数据文件、着色器和全局参数见 [工程约定](02-工程约定.md) 第一节。

## 一、现在能玩到什么

第一版（2026-10-24，提交 `0b60d8a`，已合并进 `main`）。

### 主线

| 段落 | 内容 | 熟练玩家用时 |
| --- | --- | --- |
| 出发地 → 河畔古城 | 海边出发，沿古道（普通步行约 45 分钟，驾驶飞船约 77 秒）到河边古城；广场停留观看**日常回声** | 约 2.3 分钟（飞船） |
| 古城 → 回声洞 | 道路约 2.5 公里（普通步行约 10 分钟）；神殿门、柱廊、大厅、天井，大厅观看**信仰回声** | 约 7.8 分钟（含洞内往返） |
| 烽火塔链 | 九座塔经山口翻过主山脉，点亮一座、下一座回应；末塔登顶观看**守望回声** | 约 1.3 分钟飞行 + 21 秒回声 |
| 天梯 | 主门外约 150 米的台地可降落；进主门观看**启程回声**；升降台单程 75 秒到 2455 米观景环 | 约 3 分钟 |
| 断口与结局 | 召唤飞船飞到 6160 米断口停泊台，沿石环和栈桥走到终章圆台，观看终章；沿光之路飞行约 60 秒进入字幕，之后继续自由探索 | 约 2 分钟 |

熟悉路线、驾驶飞船并加速步行约 20～30 分钟；首次探索、找路另计。

## 二、性能基线

本机 780M、1920×1080、渲染比例 1.0、关闭垂直同步，第一版全套验收的结果。预算：固定机位平均 ≤ 12.5 ms、P95 ≤ 16 ms，单次地形上传 ≤ 4 ms。56 个机位里 51 个通过，下面是没通过的和需要关注的：

| 项目 | 第一版结果 | 由哪一步处理 |
| --- | --- | --- |
| `s30_town_plaza` | 14.910 / 16.419 ms | 第 3 步（广场重做时控制构件数量和投影） |
| `s32_terraces` | 13.642 / 15.578 ms | 第 3 步 |
| `s46_echo_plaza` | 13.058 / 14.448 ms | 第 3 步 |
| `s19_broadleaf` | 12.873 / 15.122 ms，上传 3.928 ms | 第 6 步（植被重做） |
| `s25_waterfall` | 帧时间通过，上传 4.083 ms | 第 2 步（重新烘焙水系后复测） |
| 冷缓存降落 | 平均 7.3 ms，但三秒后仍有三帧超过 50 ms（最慢 191 ms） | 第 2 步（高度场采样替换噪声后复测），第 10 步收尾 |
| 洞穴创建 | 无界面复查单帧创建峰值 23 ms、碰撞创建 8 ms | 第 5 步 |
| 古城系统增量 | 文明构件在 `s30` 上增加 3.2 ms，超过单系统 1 ms 预算 | 第 3 步 |

第 1 步渲染基础的预算另算：合计增加不超过 1.5 ms（[10](10-质感与渲染.md) 第六节）。2026-10-26 同机位重测，最大平均增量 1.29 ms；`s30` 为 15.340 / 18.965 ms、`s31` 为 13.051 / 14.450 ms，仍超过绝对预算，由第 3 步古城模型调整时处理。其余本次机位通过。完整前后表见 [第 1 步记录](记录/第1步-渲染基础.md)。

| 问题 | 由哪一步处理 |
| --- | --- |
| 全局色调、光照、遮蔽、描边和材质笔触已实现并自测；模型大面几何细节仍待重做 | 第 1 步待 Claude 审图；模型由第 3 步处理 |
| 远景与洞穴明度、夜间巨像正面已调整并自查 | 第 1 步待 Claude 审图 |
| 古城广场像棋盘：方形大石板、方格状草地、白色细线 | 第 3 步 |
| 古城外围挡墙尖长变形、排列规律；梯田轮廓弱；塔链夜景近处挡墙尖片 | 第 3 步 |
| 天梯扶壁是无细节的大三角平面；主门底部黄色漏光；断口外壳规则尖角、缆索偏细 | 第 3 步 |
| 观景环栏杆是实心平板，挡住视线；从观景环看古城只有很小的浅色轮廓 | 第 2 步（选址时考虑视线）+ 第 3 步（栏杆） |
| 烽火塔火焰是扁平卡片加白色矩形；火盆不像铜；远景火盆三足不完整 | 第 3 步 |
| 神殿巨像像雪人轮廓；地砖过于规则；回声洞入口边缘粗、门宽与空腔不协调 | 第 3 步 |
| 峡谷岩壁等距白线，像千层蛋糕 | 第 2 步 |
| 探索者衣服和围巾折面明显，滑翔握姿靠近肩部，绳索近看粗糙 | 第 3 步（有余力）或第 10 步 |
