# 现状与遗留

2026-10-27 更新：第二版的渲染基础已完成，地形重塑做了第一轮；自动检查已建立并完成现状汇总。本文回答两个问题：**游戏里现在有什么**，**还有哪些已知问题、由哪一步处理**。

代码结构、数据文件、着色器和全局参数见 [工程约定](02-工程约定.md) 第一节。

## 一、现在能玩到什么

第一版（2026-10-24，提交 `0b60d8a`，已合并进 `main`）。

`ai/wanderer` 在第一版之上已经有：新的渲染基础（AgX 色调、描边、遮蔽、笔触材质，约定见 [工程约定](02-工程约定.md) 第七节）；晨的离线侵蚀高度场（第一轮，待修正，见 [11](11-地形重塑.md)），水系和主线地点已在新地形上重新烘焙，出发地到古城普通步行约 19.3 分钟。下表的主线用时是第一版的数据。

### 主线

| 段落 | 内容 | 熟练玩家用时 |
| --- | --- | --- |
| 出发地 → 河畔古城 | 海边出发，沿古道（普通步行约 45 分钟，驾驶飞船约 77 秒）到河边古城；广场停留观看**日常回声** | 约 2.3 分钟（飞船） |
| 古城 → 回声洞 | 道路约 2.5 公里（普通步行约 10 分钟）；神殿门、柱廊、大厅、天井，大厅观看**信仰回声** | 约 7.8 分钟（含洞内往返） |
| 烽火塔链 | 九座塔经山口翻过主山脉，点亮一座、下一座回应；末塔登顶观看**守望回声** | 约 1.3 分钟飞行 + 21 秒回声 |
| 天梯 | 主门外约 150 米的台地可降落；进主门观看**启程回声**；升降台单程 75 秒到 2455 米观景环 | 约 3 分钟 |
| 断口与结局 | 召唤飞船飞到 6160 米断口停泊台，沿石环和栈桥走到终章圆台，观看终章；沿光之路飞行约 60 秒进入字幕，之后继续自由探索 | 约 2 分钟 |

熟悉路线、驾驶飞船并加速步行约 20～30 分钟；首次探索、找路另计。

## 二、性能基线

本机 780M、1920×1080、渲染比例 1.0、关闭垂直同步，第一版全套验收的结果。预算：固定机位平均 ≤ 12.5 ms、P95 ≤ 16 ms，单次地形上传 ≤ 4 ms。56 个机位里 51 个通过，下面是没通过的和需要关注的：

| 项目 | 第一版结果 | 由哪一步处理 |
| --- | --- | --- |
| `s30_town_plaza` | 14.910 / 16.419 ms | 第 3 步（广场重做时控制构件数量和投影） |
| `s32_terraces` | 13.642 / 15.578 ms | 第 3 步 |
| `s46_echo_plaza` | 13.058 / 14.448 ms | 第 3 步 |
| `s19_broadleaf` | 12.873 / 15.122 ms，上传 3.928 ms | 以后的版本（植被重做） |
| `s25_waterfall` | 帧时间通过，上传 4.083 ms | 第 2 步（重新烘焙水系后复测） |
| 冷缓存降落 | 平均 7.3 ms，但三秒后仍有三帧超过 50 ms（最慢 191 ms） | 第 2 步 |
| 洞穴创建 | 无界面复查单帧创建峰值 23 ms、碰撞创建 8 ms | 以后的版本（洞穴补全） |
| 古城系统增量 | 文明构件在 `s30` 上增加 3.2 ms，超过单系统 1 ms 预算 | 第 3 步 |

第二版的变化：渲染基础在各机位的平均增量约 0.15～1.3 ms；地形重塑第一轮后，`s15` 14.506、`s52` 14.620、`s71` 12.970、`s30` 14.987、`s31` 14.322、`s43` 16.035 ms 超预算，冷缓存降落三秒后最慢一帧 227 ms（由第 2、3 步处理，见 [11](11-地形重塑.md) 第三节第 6 条）。

## 三、遗留问题

第二版第 1 步的范围、阈值、截图和原始报告见 [自动检查记录](记录/自动检查.md)。包围盒穿插、同面及离地结果含需看图复核的候选，不能把报告数量全部当作确诊。本步仅记录现状，未修复游戏内容。

### 画面与模型

| 问题 | 由哪一步处理 |
| --- | --- |
| 人物走在广场和路上会被卡住；路石和广场石板互相交叠、互相卡住 | 第 3 步最先处理（[12](12-主线近景.md) 第二、三节） |
| 河流入海口建模不好；实际三角形检查中 703 个河口未通过，主要为河面与海面重叠。野外石头三个细节层级体积均为负，确认表面朝内 | 第 3 步（[12](12-主线近景.md) 第五节） |
| 描边太多：广场石板、路石、低矮台阶和草叶边缘仍有线条；开关描边的同帧图已复现，中景坡顶也有粗线 | 第 3 步（[12](12-主线近景.md) 第四节） |
| 远处天空有塌落感：已复现低空云带压平，约 6.9° 处云层采样导数变化比 8.08；观景环球面地平线俯角约 14.8°，需分别核对云层形态与曲率观感 | 第 3 步渲染修正；第 2 步复核远景地形与地平线 |
| 摆放检查有 37 组地面重叠候选（23 组有三角形交集证据）、17 组同面候选及 1,239 组一般穿插候选；另有缺少碰撞、悬空、埋没及碰撞外扩，逐项位置在报告中 | 第 3 步；涉及地面支撑和岸坡的部分由第 2 步处理 |
| 全模型检查有 113 个网格至少一项未达拓扑、顶点色或分类面数要求；凹面质心方向仅作诊断，不能直接据此翻转法线 | 第 3 步 |
| 古城广场像棋盘；水渠渠顶台阶状悬空、拱太细像栅栏；道路铺石像瓷砖；山坡上几条笔直细线；左侧挡墙是大平板；外围挡墙尖长、排列规律；梯田轮廓弱；房屋像小方盒 | 第 3 步（[12](12-主线近景.md) 第二、六节） |
| 天梯扶壁是大三角平面；主门底部黄色漏光；断口外壳规则尖角、缆索偏细；观景环栏杆是实心平板挡住视线 | 第 3 步 |
| 烽火塔火焰是扁平卡片加白色矩形；火盆不像铜；远景火盆三足不完整；塔下绿坡上的白色条带 | 第 3 步 |
| 神殿巨像像雪人轮廓；地砖过于规则；天井光束像墙上的亮区，不是有体积的光柱；回声洞入口边缘粗 | 第 3 步 |
| 黄昏草地偏黄偏艳（`s30` 饱和度为第一版的 166%） | 第 3 步重做广场后复看；用户体验时确认 |
| 探索者衣服和围巾折面明显，滑翔握姿靠近肩部，绳索近看粗糙 | 第 3 步有余力时做，否则以后的版本 |
