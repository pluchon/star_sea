# 10 质感与渲染（去掉塑料感）

2026-10-25。第一版试玩后，用户的总体评价是"一种廉价的塑料感"。本规格说明原因、要改的渲染基础、建模标准，以及主线上要重做的模型。对应 [分步交接](20-分步交接.md) 的第 1 步（渲染基础）和第 3 步（主线模型重做）。第四节的建模标准对之后所有模型都有效。

## 一、塑料感从哪里来

对照第一版截图（`s30`、`s38`、`s43`、`s44`、`s54`、`s35`）和代码，原因有七条：

| # | 现象 | 原因 | 位置 |
| --- | --- | --- | --- |
| 1 | 画面发平、发灰，亮处和暗处都没有层次 | 色调映射是线性（`tonemap_mode = 0`），亮部直接截断，暗部没有压缩 | `scenes/main.tscn` |
| 2 | 每个物体边缘都有一圈均匀的亮光，像涂了一层漆 | 边缘光写成 `EMISSION = ALBEDO * rim * rim_strength`，不分受光面和背光面，所有方向一样亮 | `terrain.gdshader`、各着色器 |
| 3 | 大面积纯色，近看和远看一样 | 颜色只有一层大尺度变化，中尺度（2～20 米）几乎没有笔触，石材只有一张浅纹理 | `terrain.gdshader`、`ruin_common.gdshaderinc` |
| 4 | 物体像浮在地上，缝隙和角落不暗 | 没有环境光遮蔽：没有 SSAO、地形没有缝隙遮蔽、物体和地面之间没有接触阴影 | 全局 |
| 5 | 看得出方盒、平面、直角 | 模型没有倒角，大平面没有起伏和破损，例如天梯扶壁、广场石板、观景环栏杆 | Blender 脚本 |
| 6 | 轮廓不清楚，物体糊在背景里 | 没有描边；卡通风格的作品几乎都靠描边或明显的明暗交界分开物体 | 全局 |
| 7 | 远处和洞里一片灰蓝 | 远景淡化和洞穴雾都是"往一个颜色上混"，明度被拉平 | `atmosphere.gdshader`、`weather.gdshaderinc`、洞穴 |

一句话：**光照只有亮暗两档，材质只有一层颜色，几何没有倒角，画面没有描边和遮蔽**。每一条单独看都不严重，叠在一起就是塑料。

## 二、目标画面

参考作品：《塞尔达传说：旷野之息》（明暗交界、描边、草地笔触、远景层次）、《Sable》（描边和平涂）、《A Short Hike》（小尺度的温暖）、《Firewatch》（用色块和雾分层）。只学方法，不照抄画面。

判断标准（每张主机位截图都要满足）：

1. **去色测试**：截图转成灰度，前景、中景、远景三层明度分得开，主体比背景更亮或更暗，不是一片中灰。
2. **剪影测试**：主体（建筑、雕像、天梯、探索者）填成黑色，仍然认得出是什么。
3. **材质测试**：离 10 米看任何一块石头、一面墙、一片草地，能看到至少两个尺度的变化（大的色块和小的笔触），没有超过画面 5% 面积的纯色平面。
4. **接地测试**：物体和地面接触的地方有一圈暗部，看不到"浮着"。

## 三、渲染基础（第 1 步）

这一节都是全局改动，影响所有星球，所以要跑 `surface_checks`，并截烬、霜各一张确认没坏。

### 1. 色调映射与调色

- 改用 AgX 色调映射，曝光和白点按日间主机位调到天空不过曝、暗面不发黑。
- `SkyDirector` 现在用一维渐变做调色。改成**每个时段一张三维调色表**（黎明、白天、黄昏、夜晚、洞穴，各 32³），按太阳高度在相邻两张之间混合。调色表由 `tools/` 下新写的生成脚本根据第七节的色板生成，存在 `game/textures/grade/`。
- 饱和度整体不提高。要的是明度层次，不是更艳。

### 2. 光照模型

`toon_light.gdshaderinc` 改为：

- **三档明暗不变**，但明暗交界处加一条窄的偏暖、略饱和的过渡带（`ndl` 约 0.0～0.08），模拟光线在表面下的散射。卡通渲染最常用的就是这一条，它让表面看起来是"材料"，而不是"涂层"。
- **暗面颜色**：暗面不是同一个蓝紫色。按表面朝向混合两种颜色：朝上的暗面偏天空色，朝侧面和下方的偏地面反光色（白天偏暖绿、黄昏偏橙）。两种颜色由 `SkyDirector` 按时段给出，作为新的全局着色器参数。
- **边缘光**：删掉现在的 `ALBEDO * rim` 自发光。改成只在**受光一侧的轮廓**出现的细亮边，宽度窄，强度随距离减弱，暗面没有亮边。
- 不加高光。只有水面、铜器、冰保留各自的高光。

### 3. 环境光遮蔽与接触阴影

三层，按便宜到贵的顺序：

1. **模型烘焙遮蔽**：所有 Blender 模型导出前把环境光遮蔽烘焙到顶点色 R 通道（第四节），着色器乘到环境光和暗面上。已有模型在第 3 步和之后的重做中逐步补上。
2. **地形缝隙**：按曲率算凹处（沟、坡脚、岩缝），写进地形顶点的一个通道，凹处的环境光减弱 20～35%。
3. **接触阴影**：遗迹、树、石头、飞船和探索者底部放一个贴地的柔和暗斑（贴花或贴地四边形，按物体投影大小缩放），离相机 80 米外不画。

屏幕空间的 SSAO 在 780M 上偏贵，先不开。做完上面三层后在 `s30`、`s43` 上试一次 SSAO 的低质量档，增加的时间在 0.6 毫秒以内才保留，否则关掉并在记录里写明。

### 4. 描边

- 用全屏后处理：读深度和法线，找出深度突变和法线突变的像素画线。Godot 4.7 里可以用 Compositor 效果或者覆盖全屏的四边形着色器，选性能更好的一种，写进记录。
- **线的颜色不是黑色**，是该像素颜色压暗 55～65%，这样线跟着材质和时段变色，不会显得像漫画贴纸。
- 线宽在 1080p 下 1～1.5 像素；离相机 400 米以外逐渐淡出，远景交给大气层次。
- 不描边的：天空、云、水面、雨、粒子、回声人影（回声本身是发光剪影）、地图和界面。
- 洞穴里描边减弱一半，避免暗处全是线。
- 预算：在 `s30`、`s31`、`s43` 上增加不超过 0.8 毫秒。

### 5. 大气与雾

- **远景保留明度差**：现在远山越远越接近天空色，明度一起被拉平。改成颜色向天空色靠近，但明度只压缩一部分。判断标准：从出发地看 6 公里外的主山脉，山体的受光面和背光面在灰度图里仍有可见差别（`s41`、`s49`）。
- **低处的雾**：山谷和河谷里加一层薄的高度雾（只在低于周围地形的地方），黎明和黄昏更明显。雾的颜色按时段变化，不是固定的蓝灰。
- **洞穴**：洞穴雾的浓度减半；天井光束保留体积感，但光束以外的空间要能看清墙和地面（`s38`）。夜间大厅巨像正面不能整片黑。

### 6. 地形材质

`terrain.gdshader` 补齐三个尺度：

| 尺度 | 范围 | 做法 |
| --- | --- | --- |
| 大 | 50～500 米 | 现有的群系、气候、坡度配色，加一层低频色块（草地的明暗片、岩坡的冷暖片） |
| 中 | 2～20 米 | 新增：三轴投影的手绘笔触纹理，草地是一簇簇的笔触，岩石是块状的面和裂缝，400 米内可见，远处平滑淡出 |
| 小 | 0.2～2 米 | 现有的 `ground_paint` 近景笔触，保持 35～160 米淡出 |

- 草地上加大片的"风吹痕迹"：一条条随风慢慢移动的浅色带，和 `wind_push` 同方向同速度。这是《旷野之息》草原最有辨识度的效果，也让大片绿色不再是一块平面。
- 岩坡按坡度和朝向分成受光的暖色岩面和背光的冷色岩面，接缝处加碎石色。

### 7. 色板

所有调色表、暗面颜色、雾色从这一张表派生，不在各个着色器里各写一套：

| 时段 | 天空主色 | 受光色温 | 暗面朝上 | 暗面朝侧 | 雾色 |
| --- | --- | --- | --- | --- | --- |
| 黎明 | 淡青到淡粉 | 偏粉 | 淡紫灰 | 暖灰 | 淡粉灰 |
| 白天 | 天蓝 | 中性略暖 | 灰蓝 | 暖绿灰 | 浅蓝灰 |
| 黄昏 | 橙到紫 | 橙 | 紫 | 橙褐 | 橙紫 |
| 夜晚 | 深蓝 | 冷白（月光） | 深蓝紫 | 深蓝灰 | 深蓝 |
| 洞穴 | — | 天井处偏暖白，提灯偏琥珀 | 暖褐灰 | 暖褐灰 | 暖灰 |

具体数值由实现者定，写进 `game/data/palette.tres`；圣经第四、六节的石材色、铜色、光纹色不变。

## 四、建模标准

所有新模型和重做模型都按这一节做。原则来自用户：**人和东西要用真正的建模工具做，不能是代码拼凑**；地形、洞穴、天梯主体这类超大尺度的东西继续程序生成。

### 工具与流程

- 建模脚本在 `art/blender/`，由 `tools/Build-Models.ps1` 调用（Blender 4.x，脚本开头检查版本）。一条命令能重建全部模型；布料和刚体模拟用固定帧数和种子。
- 脚本调用的是 Blender 的建模工具：修改器、布料和刚体模拟、曲线、几何节点、雕刻位移、骨骼。脚本里直接列顶点坐标、拼面，只允许用于碰撞体和极简单的块。
- **不允许**在 GDScript 里为新物件手写网格。`RuinKit` 读取的 `geometry.json` 备用数据由导出脚本自动生成，可以保留。
- 通用自然物（石头、植物、叶片）优先用 CC0 素材：Quaternius、Kenney、KayKit、Poly Haven。原始文件放 `art/sources/<来源名>/`，来源、作者、链接、授权写进 `art/sources/来源.md`。素材只取形状，丢掉原有贴图和材质，改成我们的比例、倒角、顶点色和着色器后才能进场景。照片扫描素材减面到预算以内。

### 去掉塑料感的硬性要求

1. **倒角**：所有边都要倒角。宽度约为物体短边的 2～5%，至少 2 段。看不到一条刀切一样的锐边。
2. **轮廓不规则**：石材、墙、柱子的边缘有轻微的不平和缺口；大平面（超过 2 × 2 米）要有起伏、分块或破损，不能是一整块平板。
3. **法线**：用加权法线（Weighted Normal 修改器），大平面保持平，倒角处圆滑过渡；不要整个物体平滑着色造成的"橡胶"光感。
4. **烘焙到顶点色**：环境光遮蔽，以及由曲率得到的**边缘磨损**（凸起的边略亮、凹进的缝略暗）。这是卡通石材最有效的质感来源。
5. **修边贴图**：做一套共用的石材修边贴图（砌缝、横带、刻纹、破损边各一条），墙、台基、塔身、门框都从这张图取 UV，保证风格统一。
6. **面的朝向**：所有面的法线朝外。导出前统一"重新计算法线（朝外）"；开放的单面（叶片、布条）按"离开附着面的方向"检查。朝里的面会被卡通光照当成背光面，整片发黑。

### 常用做法

| 要做的 | Blender 里的做法 |
| --- | --- |
| 人形基础 | 顶点串加蒙皮修改器（Skin）再细分；或骨架加简单网格 |
| 姿势 | 骨架摆出站、跪、坐等姿势 |
| 长袍、兜帽、袖子 | 布料模拟罩在摆好姿势的人体上，肩颈固定，模拟若干帧后应用；布料分辨率低一些，褶子大而简洁 |
| 藤条、绳子、缆索 | 曲线加倒角，半径沿曲线渐细 |
| 叶子沿藤条分布 | 几何节点：曲线上取点，实例化叶片，随机旋转缩放 |
| 石头 | CC0 石头；或二十面球 → 体素重建 → 噪声位移 → 减面 → 倒角 |
| 一堆碎石 | 刚体模拟把石块丢下，静止后应用 |
| 断面 | 布尔差集，切割体先做噪声位移 |
| 墙、柱、台阶 | 倒角、阵列、实体化等修改器，加修边贴图 |
| 减到面数预算 | 减面修改器，最后一步做 |

### 规范

| 项目 | 规则 |
| --- | --- |
| 单位 | 1 = 1 米 |
| 坐标 | Blender 里按 +Z 建模，导出打开 `export_yup=True`；Godot 里 +Y 向上，正面朝 -Z |
| 原点 | 底面中心；墙段在底边中点 |
| 模数 | 水平以 1 米为模数，墙厚 0.6 米，层高 3.6 米 |
| 变换 | 导出前应用所有变换，缩放为 1 |
| 材质 | 最多四种，按名字区分：`stone`（石材）、`patina`（铜锈）、`glyph`（琥珀光纹，略微凹进的面片）、`cloth`（布）。导入时由代码换成项目着色器 |
| UV | 石材按 1 米一格立方体投影；用修边贴图的部分按贴图条带展开 |
| 顶点色 | R：环境光遮蔽（0.6～1）；G：布料摆动权重（固定端 0，自由端 1）；B：边缘磨损（0.5 为中性，凸边更高，凹缝更低） |
| 碰撞 | 物体名以 `-colonly`（凹体）或 `-convcolonly`（凸体）结尾，面数 ≤ 64；台阶和坡道的碰撞做成斜面 |
| 细节层级 | 导入开启自动 LOD；LOD0 面数上限：小件 300、中件 1800、大件 4000、雕像 5000、回声人影 3000、碎石 900、藤蔓 2000～3000 |

### 自查

每个模型用 EEVEE 渲一张四视图（正、侧、背、三分之二侧，中性灰底，一盏方向光），另出一张灰度图和一张剪影图，输出到 `test-output/models/<名字>.png`。先看图确认轮廓、比例、面的朝向，再进 Godot。

## 五、主线模型重做（第 3 步）

第 1 步的渲染基础做完以后，倒角和顶点色的效果才能在新光照下判断；第 2 步地形重塑会让古城、塔链、天梯重新选址。所以这一步排在第 2 步之后，模型做好直接放到新位置。

| 物件 | 现在的问题（第一版截图） | 要改成 | 主机位 |
| --- | --- | --- | --- |
| 古城广场铺地 | 一格一格的方形大石板，像棋盘；草是方格状的空缺 | 6～8 种不同大小（0.6～1.6 米）、带倒角和缺角的石板，沿同心弧线和放射线错缝铺，越往外越稀，草从缝里长出成条成团；少数石板倾斜、翘起、缺失。去掉白色细线 | `s30` |
| 古城外围挡墙、梯田 | 挡墙有尖长变形的构件、排列过于规律；梯田轮廓弱 | 挡墙按修边贴图重做，高度和长度有变化、局部坍塌；梯田每级的挡土边清楚，沿等高线弯曲 | `s31`、`s32`、`s36` |
| 天梯扶壁 | 四块没有细节的大三角平面 | 三到四级退台的扶壁，每级顶面有压顶石，侧面有砌缝和横带，底部埋进基座 | `s43` |
| 天梯主门 | 门底有一条黄色漏光 | 查明原因（大概率是门洞内面缺失或光纹溢出）并修掉；门框退进层次加深 | `s43` |
| 观景环栏杆 | 一整块绿色实心平板挡住下半个画面 | 高约 1.0 米的矮石栏，中间是镂空的环与径栏板，每隔一段有缺口；站在观景环上平视时，视线越过栏杆能看到下方的大地和古城 | `s44` |
| 烽火塔火焰 | 几片扁平卡片叠在一起，内芯是白色矩形 | 有体积的卡通火焰网格（几层向上收尖、彼此错开的火舌），着色器按高度从橙红到琥珀到浅黄渐变，边缘有一圈清楚的深色轮廓；不出现矩形 | `s35` |
| 烽火塔火盆 | 深灰色，看不出是铜 | 按第三节的光照重新调铜色：受光面青铜绿带亮边，暗面暖褐；盆沿磨损处露出更亮的铜色。远景低面数版本的三足也要完整 | `s35`、`s36` |
| 神殿巨像 | 像一个雪人的轮廓 | 按第四节方法做的长袍人形，布料垂坠，双手捧环，站在加高的台座上 | `s38` |
| 神殿地砖 | 排列过于规则 | 大小不一的石板，靠墙有积土和碎石 | `s38` |
| 回声洞入口 | 入口三角形边缘粗，门宽与空腔不协调 | 洞口构件和地形开洞重新对齐，边缘用岩石构件遮住 | `s37` |
| 回声人影 | 坐姿、跪姿衣摆有明显折面；单膝和盘坐轮廓不清 | 按第四节布料做法重做这几个姿势 | `s46`、`s47` |
| 峡谷岩壁 | 等距的白色水平线，像千层蛋糕 | 第 2 步重做峡谷时处理，见 [11 地形重塑](11-地形重塑.md) 第五节 | `s54` |

## 六、自查与验收

- 第 1 步：
  - 截 `s1`、`s30`、`s31`、`s35`、`s38`、`s41`、`s43`、`s49`、`s51`、`s54`，以及烬、霜各一张；每张和改动前同机位并排，加灰度图。
  - 逐张按第二节的四个测试写判断。
