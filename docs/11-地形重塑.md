# 11 地形重塑

对应 [版本计划](版本计划.md) 第二版的第 2 步。晨的大尺度地形已经从"运行时叠加公式"改成"离线雕刻、侵蚀、烘焙成高度场"（第一轮 `585ceb7`），第一版的等高台阶、阈值海崖、公式边界已经消除。但侵蚀几乎看不出来，山体光滑平淡，火山没变，峡谷变差。这一步把第三节列出的问题修好。

第一轮的实测数据（烘焙参数、耗时、哈希、选址结果、主线距离、性能）见 [地形重塑记录](记录/地形重塑.md)。

## 一、现在的做法

> 意图图 → 高度场生成 → 侵蚀 → 烘焙成立方体高度场 → 运行时采样，再叠加小尺度细节和后续特征

| 环节 | 文件 | 说明 |
| --- | --- | --- |
| 意图导出 | `game/scripts/tools/terrain_intent_export.gd` | 每面 512² 的低频地势和遮罩（主山脉抬升带、峡谷路线、火山、出发地保护区），布局写成 JSON；输出到 `test-output/terrain/intent/` |
| 生成与侵蚀 | `tools/Bake-Terrain.py`（依赖 `tools/requirements-bake.txt`） | Python + NumPy + Numba，单线程，结果可重复 |
| 输出 | `game/data/dawn_terrain.res` | 六面各 (2048 + 4)²，16 位高度，带出发地八米采样；约 43.8 MiB，上限 46 MB |
| 运行时 | `game/scripts/planet/dawn_heightfield.gd` | 双三次插值；晨的 `base_height()` 采样高度场加小尺度细节；烬、霜不变 |
| 后续烘焙 | `tools/Bake-World.ps1` | 水系、文明区、塔链、洞穴、攀爬路线都在新高度场上重跑 |

生成命令（仓库根目录）：

```powershell
& tools/Check-Godot.ps1 -GodotArgs @('--headless','--script','res://scripts/tools/terrain_intent_export.gd','--','--check=terrain-intent') -LogPath 'test-output/terrain/intent.log'
python tools/Bake-Terrain.py --godot 'D:/Godot/4.7.2/Godot_v4.7.2-stable_win64_console.exe'
& tools/Bake-World.ps1
```

高度函数的叠加顺序见 [工程约定](02-工程约定.md) 第二节第 0 条。

## 二、规则

### 地貌参数

位置以 `dawn_layout.tres` 为准：

| 地貌 | 参数 |
| --- | --- |
| 主山脉 | 脊线 60～80 公里，离出发地最近处 6～10 公里，从出发地看横在前方；离海岸至少 4 公里；半宽 7～10 公里 |
| 角峰 | 金字塔形尖峰，三四面陡壁，高 3.8～4.0 公里 |
| 双子峰 | 两座尖峰相距约 900 米，中间一道深 V 形缺口 |
| 平顶峰 | 四壁陡峭、顶部约 600 米范围平坦的桌状山 |
| 山口 | 至少 2 处，彼此相距 15 公里以上；鞍部宽约 1.5 公里，两侧坡度不超过 0.35，能走过去 |
| 冰川 | 海拔 2200 米以上、坡度小于 0.3 的谷底 |
| 大峡谷 | 离出发地 10～25 公里，和主山脉方位相差 60° 以上；长 20～30 公里，深 700～1000 米，顶宽 1.5～3 公里，谷底宽 150～300 米；一端通海或大湖，谷底单调下降；两侧岩壁不对称 |

### 重新烘焙和选址

地形每改一次，水系、文明区、塔链、洞穴、攀爬路线、回声锚点、手记地点、降落点都按现有流程重跑。

- 选址失败时**不降低选址阈值**，改为在意图图上把目标区域稍微放平，重新烘焙；
- 主线距离：出发地到古城普通步行 15～20 分钟（第一轮约 19.3 分钟）；古城到回声洞、回声洞到第一座烽火塔的距离和第一版相比变化不超过 30%；
- 回声洞第二出口通向河谷；
- 古城、塔链、天梯的位置仍要合理：古城在河边平地，塔在山顶两两相望，天梯从出发地和古城都看得见，从观景环能看到古城。

### 不做

- 不用 Gaea、World Machine 这类图形界面软件：编码会话没法操作。
- 不改烬和霜；不移动出发地、不改海平面、不改星球半径；不加新地貌（石林、温泉、第二座火山见 [22](22-地貌补充.md)）。

### 允许的例外

- 出发地保护区内保留的旧地形出水边（第一轮 434 条）：保护出发地优先，自动检查单独列出数量，不算失败；保护区外必须全部满足汇水规则。
- `dawn_terrain.res` 不超过 46 MB。修正过程中的中间结果放 `test-output/`，只在修正完成时提交一次，避免仓库里堆多份大文件。

## 三、要修的问题

公式痕迹消除、保护区、山口、选址、水系连通、古道约 19 分钟、洞口往返、回声逐点碰撞已经做好，**不要改坏**。

### 1. 侵蚀强度不够

- 现象：`s71`、`s74`、`s76` 的山体是光滑的大坡，没有分支冲沟、冲积扇、刀脊。
- 原因：每面 2048²（约 420 万格）只滴了 50 万滴，平均每格 0.12 滴；公开实现一般每格 1～3 滴。
- 要求：
  - 多分辨率侵蚀：先在每面 1024² 上侵蚀，每格平均不少于 2 滴（每面约 210 万滴以上）；上采样到 2048² 后再做一遍收尾侵蚀，每格不少于 0.5 滴；每滴最多步数可以提高到 120；
  - 冲沟在 2～6 公里外看得出来：主山脉山坡上的主冲沟间距约 150～400 米，向下汇合成树枝状；
  - 烘焙总耗时不超过 30 分钟（本机）；同样输入两次生成哈希一致；
  - 侵蚀算法优先移植成熟的公开实现（第五节），不从零写。

### 2. 缺少 50～300 米这一档起伏

- 原因：烘焙噪声最细只到约 160 米波长，运行时细节又限制在 3 米以内。
- 要求：
  - 烘焙时在侵蚀**之前**补中频脊状细节，最短波长约 60 米。振幅按抬升和坡度分配：主山脉 40～120 米，丘陵 10～30 米，平原和海岸接近 0；
  - 运行时细节噪声的振幅上限放宽到 6 米，波长 20～60 米，只在坡度大于 0.3 的岩坡和高地使用；出发地保护区、文明区平整范围、道路、洞口不加；
  - 名峰和主脊线附近保留锋利的山脊，热力侵蚀在这些地方用硬度遮罩减弱。

### 3. 火山

- 现象：`s75` 仍是光滑正圆锥。
- 要求：侵蚀前给锥体加噪声扰动的放射状浅沟（6～12 条，宽窄、长短不一），让侵蚀在上面加深；火山口沿口不等高、有一处缺口。`s75` 里能数出至少 6 条冲沟，侧面轮廓不是两条直线。

### 4. 山坡上的直沟

- 现象：`s76`、`s49` 山坡上一道又窄又深、近乎笔直的暗沟。
- 要求：查明来源（大概率是水系河道在高度场上刻得太窄太深），写进记录。峡谷之外，河道横断面宽度至少 3 个格距，两岸平滑过渡到坡面，深宽比不超过 0.3；山坡上的河道沿侵蚀形成的谷底走，不是直线。

### 5. 峡谷

- 现象：`s77`、`s54` 远壁仍是整面细而平行的横线（千层蛋糕）；近处原有的台阶和谷底河流被一个模糊的大土坡盖住。
- 要求：
  - 侵蚀和热力侵蚀不得填平峡谷：峡谷内部禁止沉积，谷底宽度和河流保留，近处台阶清楚；
  - 岩层台阶 8～11 级，每级高度不等（40～120 米），台阶边缘按噪声前后错动 5～20 米；少数几级局部坍塌成碎石坡；
  - 颜色：基色接近圣经的石材色（浅赭 `#D6C7A4`、暖灰 `#B8A58A`、淡红褐 `#B07A5A`），不要粉色、紫色和偏蓝的阴影；从 `s77` 的距离看整面岩壁只能分辨出 6～10 条色带，宽窄不一、相邻色差小，色带边缘随噪声起伏，叠加竖向流痕；平台朝上的面是土色加稀疏草色；
  - `s51`、`s52`、`s54`、`s77` 都看不出千层蛋糕，谷底能看到河。

## 四、检查

`landform_checks` 已有的各项继续通过：立方体面接缝（高差 ≤ 0.5 米、法线夹角 ≤ 3°）、峡谷和名峰之外坡度超过 45° 的面积低于 2%、汇水（保护区例外单独计数）、没有 180 米周期的台阶、地貌参数在第二节范围内、出发地两公里内高度变化 ≤ 1 米、`height()` 单次耗时不超过基线（8.94 微秒）。

这一步新增：

- **纯高度光照图**：不带材质，只按高度场算光照（类似地形软件的山体阴影图），覆盖出发地到主山脉、火山、峡谷三片区域，第一轮和修正后两列对比。这组图最能直接看出有没有树枝状的沟谷网；
- **冲沟计数**：在主山脉抬升带内，按汇水面积超过阈值的格子统计沟谷网，报告沟谷密度和平均分支数，和第一轮比较；
- 重截 8 个地形机位（`s70`～`s77`）和 `s49`、`s51`、`s52`、`s54`，两列对比加灰度。

`hydrology_checks`、`ecology_checks`、`ecology_runtime_checks`、`surface_checks`、`civilization_checks`、`cave_checks`、`traversal_checks`、`echo_checks`，以及 [10](10-自动检查.md) 的卡住检测、摆放检查和水面检查全部通过。最后跑一次 `Test-Acceptance.ps1 -Scope dawn`。

自查（按 [工程约定](02-工程约定.md) 第四节）：

- 从出发地四个方向看，有没有任何一处地形"一看就是公式"：直线、正圆、等距、平顶、突然的崖；
- 从 3 公里高空看，山、谷、河、海岸是不是一个连贯的整体；
- 冲沟、火山、峡谷是否达到第三节的标准。
