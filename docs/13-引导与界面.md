# 13 引导与界面

2026-10-25。第一版试玩后用户提出两个问题：**没有任务指引**，玩家不知道下一步该去哪；**界面文字堆得太多，没有留白**。对应 [版本计划](版本计划.md) 第二版的第 4 步。

## 一、已定的方向

用户同意"不做指路箭头，但一定要有引导"。具体是：

- **保留**：不做箭头、任务标记、任务列表、任务文字、距离数字（圣经第九节）。
- **新增**：用世界里本来就有的东西引导——光、烟尘、地标、道路、手记里的草图、地图上的模糊提示。玩家看到的是"那边好像有什么"，而不是"去那里"。
- 引导的强弱可以在设置里调：**开**、**弱**（默认）、**关**。

做法参考：《旷野之息》的三角形法则和地标"引力"（高塔、火光把人拉过去）；《Journey》远处始终可见的山和光；迪士尼乐园街道尽头的城堡（weenie）。

## 二、主线的引导

### 主线目标

主线按顺序有六个目标：古城 → 回声洞 → 第一座烽火塔 → 末塔（守望回声）→ 天梯主门 → 断口平台。存档里已有的 `discovered`、`echoes_seen`、`beacons_lit`、`ending_seen` 足够推出"下一个目标是哪个"，**不新增存档字段**。推算写成一个函数 `MainPath.next_target(journey) -> String`，放在 `game/scripts/civilization/main_path.gd`，所有引导都从它取目标。

### 四种引导手段

| 手段 | 做法 | 什么时候出现 |
| --- | --- | --- |
| **远景信号** | 下一个目标处有一个只有在远处才看得清的信号：古城是黄昏时广场纪念环亮起的琥珀光，加一缕慢慢升起的光尘柱；回声洞是洞口上方盘旋的一小群鸟；烽火塔本身就是信号（已点亮的塔回应下一座）；天梯主门是夜里门楣环与径的光；断口平台在四个回声都看过后亮起（已有） | 一直存在；"弱"档只在黄昏和夜里明显，"开"档白天也看得到；"关"档只保留烽火塔和天梯本来就有的光 |
| **路标** | 古道沿途每 150～250 米一块刻着环与径的路碑（遗迹构件 `stele` 的矮版），夜里光纹微亮；岔路口的路碑朝向主线方向倾斜 | 一直存在，属于古道本身，不受设置影响 |
| **回声余光** | 每个回声结束时，一串光点从回声位置飘出，朝下一个目标的方向飞 300～500 米后散开淡出 | 回声结束时一次；可以在手记里重看回声时再出现 |
| **手记草图** | 手记顶部多一张"下一处"的草图：从下一个目标附近一个固定机位截的画面，处理成铅笔线稿风格（描边加去色加纸纹），不写名字，只画轮廓和天梯作为方位参照 | 打开手记时；"关"档不显示 |

### 地图上的提示

- 已发现的地点照旧显示琥珀点。
- 下一个目标在地图上显示为一个**半径约 800 米的淡色圆圈**，不是精确的点，圆心随机偏离目标 200～400 米（按目标编号固定种子），玩家知道"大概在这一片"。
- "关"档不显示圆圈。

### 迷路时

玩家 15 分钟内没有接近下一个目标（距离没有缩短 30% 以上），并且离目标超过 2 公里时：远景信号的亮度和高度慢慢加大到"开"档的强度；接近目标后恢复。没有任何文字或声音提醒。

### 节奏要求

新玩家不看攻略，从出发地开始：

- 1 分钟内能看到天梯和至少一个远景信号；
- 古城应该是第一眼就会想去的方向（出发地看过去的构图里，古城方向有路、有信号）；
- 每个目标完成后，30 秒内能看到下一个目标的线索。

## 三、界面

### 规则

| 项目 | 规则 |
| --- | --- |
| 默认画面 | 步行时屏幕上**没有常驻文字**。只有需要时出现的操作提示，和右上角不带文字的小地图 |
| 字体 | 一种字体（现在的微软雅黑），三种字号：标题 32、正文 20、注释 16（1080p 下的像素）。任何文字不小于 16 |
| 行距与行宽 | 行距 1.5 倍；一行不超过 20 个汉字 |
| 留白 | 屏幕边缘留出至少 48 像素；弹出面板内边距至少 32 像素；面板最多占屏幕宽度的 40%，手记和地图除外 |
| 层级 | 一个面板最多三级信息（标题、正文、注释），能用图标或画面表达的不用字 |
| 对比 | 文字和背景对比度至少 4.5:1，面板用半透明深色底 |
| 提示 | 操作提示一次只显示一条，最多 8 个字（例如"F 登船"），2 秒淡入淡出；每种操作第一次出现时显示，熟悉以后（成功做过 3 次）不再显示 |
| 系统消息 | "旅程已保存"一类的消息在屏幕下方停留 2 秒后淡出，不弹窗 |

### 具体改动

| 位置 | 现在 | 改成 |
| --- | --- | --- |
| 帮助（H） | 一整块二十多行的按键列表，盖住左上角 | 删除开局自动弹出的帮助。按 H 显示一张按键示意图：三组（移动、飞船、视角与地图），每组不超过 4 行，用按键图标加 2～4 个字说明。完整列表放在暂停菜单的"操作说明"里 |
| 状态栏（右下角） | 常驻"晨 · 步行 · 第一人称　离地 0 m　0.0 m/s　H 帮助" | 步行时隐藏。驾驶飞船时只显示高度和速度两个数字，用图标代替文字 |
| 小地图 | 标题行有星球、群系、指北，底部有"范围 1.6 km　等高距 20 m　-292～184 m" | 去掉所有文字，只保留地图本身、玩家箭头、北方标记和发现的地点符号。范围、等高距放进 F3 性能面板 |
| 大地图（M） | 背景是压暗的全球地形，和洞穴局部图比例不一致 | 洞穴里打开时，背景和洞穴图用同一比例定位；说明文字放到右下角一行注释 |
| 洞内"离地"数值 | 可能显示相对外部地表的负值 | 随状态栏一起隐藏；F3 面板里在洞内显示"洞内"，不显示负值 |
| 暂停菜单 | 七个按钮一列 | 分成三组，组间留白：继续；手记、地图；存档、设置、操作说明、退出。设置单独一页，同类选项分组 |
| 手记 | 卡片网格，每行 3 张 | 顶部回声符号保留；新增"下一处"草图（第二节）；卡片每行 2 张，截图占卡片的 75% 以上，名字一行 |
| 开始菜单 | — | 只有标题、"开始漂流 / 继续漂流"和"设置"，其他放进暂停菜单 |

### 设置新增

- 引导：开 / 弱 / 关（默认弱）；
- 操作提示：开 / 关（默认开）。

两项写进 `settings.cfg`，旧设置文件缺省用默认值；非法值按现有规则整份拒绝。

## 五、自查与验收

### 自动检查

新增 `guidance_checks.gd`（可无界面）：

1. `MainPath.next_target()` 对主线每个阶段的存档组合返回正确的目标；旧存档（没有某些字段）也能推出合理的目标。
2. 每个目标的远景信号存在，并在三档设置下按规则显示或隐藏。
3. 古道上路碑的间距在 150～250 米之间，路碑都在道路 3 米内、贴地。
4. 地图提示圆圈包含真实目标，圆心偏离在 200～400 米之间，同一存档多次打开位置相同。
5. 模拟"15 分钟没有接近"时信号增强，接近后恢复。

新增 `ui_checks.gd`：

1. 步行状态下，屏幕上可见的文字字符数为 0（不含操作提示）；
2. 所有可见 `Label` 的字号不小于 16，位置在屏幕边缘 48 像素以内的安全区里；
3. 帮助面板、暂停菜单、手记在 1920×1080 和 1280×800 两种分辨率下都不超出屏幕、不互相重叠；
4. 引导和提示两项设置的往返与非法值。

### 机位

| 机位 | 看什么 |
| --- | --- |
| `s78_spawn_guidance` | 出发地面向古城方向，黄昏：能同时看到天梯和古城的远景信号 |
| `s79_after_echo` | 古城回声结束 3 秒后：回声余光朝回声洞方向飞 |
| `s80_journal_next` | 手记页面，带"下一处"草图 |
| `s81_hud_walk` | 步行时的完整画面：没有常驻文字 |
| `s82_pause_menu` | 暂停菜单 |

### 自查（最终由用户体验确认）

- 只看 `s78`，不看文档，能不能猜出"该往哪边走"。
- 默认画面有没有任何不需要的文字。
- 手记的草图看起来像手绘的线稿，而不是一张缩小的截图。
- 引导有没有破坏寂寥感：信号是不是安静、稀少、像世界本来就有的东西。
