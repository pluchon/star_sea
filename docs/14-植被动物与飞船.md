# 14 植被、动物、地标岩石与飞船重做

2026-10-25 由原规格整理而来，内容未变，建模要求改为引用 [10 质感与渲染](10-质感与渲染.md) 第四节。对应 [分步交接](20-分步交接.md) 的第 6 步（植被、动物、地标岩石）和第 7 步（飞船）。

## 一、为什么做

晨上大部分会被看到的东西，现在仍然是在代码里拼出来的：

| 现在 | 文件 |
| --- | --- |
| 9 种植被：草、阔叶树、松树、灌木、花、石块、蕨、芦苇、蘑菇 | `game/scripts/planet/vegetation_meshes.gd` |
| 鸟、鹿形生物、萤火 | `game/scripts/planet/wildlife.gd` |
| 海蚀柱、天然石拱、旗等地标 | `game/scripts/planet/landmark_meshes.gd`、`stonework_meshes.gd` |
| 飞船 | `art/blender/build_ship.py`（在脚本里写顶点） |

这些都换成 Blender 建的模型或 CC0 素材。不改的：地形、水面、天空、云、雨、草地远景着色。萤火保持现在的做法。

## 二、总原则

- 建模方法、CC0 素材、四视图自查、面的朝向、顶点色，全部按 [10](10-质感与渲染.md) 第四节。
- 画风是卡通：形状简洁、轮廓清楚、色块分明、有倒角。CC0 素材优先选低多边形或卡通风格的（Quaternius、Kenney 的自然类素材包）。
- **替换，不改规则**：每种东西的名字、所在群系、密度、远近细节层级、碰撞、MultiMesh 用法都不变。`ecology_checks` 里群系和分布的数字不应该变化，变的只是网格本身。
- 模型输出到 `game/models/nature/`、`game/models/wildlife/`、`game/models/ship/`，由 `tools/Build-Models.ps1` 的 `-Target nature`、`-Target wildlife`、`-Target ship` 生成。
- 原来的 GDScript 网格函数在新模型接入后删除，不保留两套。

## 三、植被

| 种类 | 要求 | 面数（LOD0） |
| --- | --- | --- |
| `broadleaf` 阔叶树 | 3 个变体。树干有分叉和根部隆起；树冠是几团大的、轮廓清楚的叶团，不是一个球；卡通块面，不做单片叶子 | ≤ 1500 |
| `pine` 松树 | 3 个变体。一层层下垂的枝层，顶端尖，树干略弯 | ≤ 1200 |
| `shrub` 灌木 | 2 个变体。几团叶团挤在一起，底部看得到几根细枝 | ≤ 500 |
| `fern` 蕨 | 2 个变体。从中心放射的弯曲叶片，叶片边缘有锯齿 | ≤ 300 |
| `reeds` 芦苇 | 2 个变体。一丛细长略弯的茎，几根顶端有穗 | ≤ 250 |
| `flowers` 花 | 3 种颜色。细茎加小花头，4～6 片小块面花瓣 | ≤ 150 |
| `mushrooms` 蘑菇 | 2 个变体。一簇 3～5 个，菌盖有弧度 | ≤ 200 |
| `grass` 草 | 一簇弯曲的草叶，叶片宽窄不一 | ≤ 80 |
| `stone` 石块 | 和遗迹碎石共用同一批石头，挑形状圆润的 4～6 种 | ≤ 200 |

- **风**：风动靠顶点 `UV2.x` 作为摆动权重（根部 0，梢部 1），`surface_detail.gdshaderinc` 读取。新模型按离根部的高度写入同样的权重，着色器不改。
- **颜色**：沿用各群系的配色，写在顶点色里，规则不变。导出前对照现有截图，颜色不要整体变亮或变暗。
- **LOD**：现有两级简化（`lods` 0.08 和 0.35）。新模型用 Godot 自动 LOD，或在 Blender 里导出两个减面版本，二选一，写进记录。
- **面的朝向**：草叶、蕨叶、花瓣这类单面，法线朝上或朝外；双面渲染设置保持不变。

## 四、动物

| 动物 | 要求 | 面数 |
| --- | --- | --- |
| 鸟 | 修长的海鸟或雨燕形，翅膀宽长。骨架：身体、两翼各两节、尾。动画：`flap`、`glide` | ≤ 300 |
| 鹿形生物 | 比真实的鹿更细长、颈更长，头上一对向后弯的细角，短尾。标准四足骨架。动画：`idle`（低头吃草、抬头张望）、`walk`、`run`、`alert` | ≤ 2000 |

- 动画在 Blender 里做关键帧，导出到 glb。
- **鸟群是 MultiMesh**，不能逐只播放骨骼动画：把 `flap` 烘焙成顶点动画纹理，着色器按时间和每只鸟的相位读取；或保持顶点着色器扇翅，只换网格。选更简单可靠的，写进记录。
- 鹿数量少，逐只用 `AnimationPlayer`。`wildlife.gd` 里鹿的移动逻辑（靠近就逃）不变，只把走、跑、吃草、警觉接到对应动画。
- 第 4 步的回声洞远景信号用到的鸟群，换成这里的新模型。

## 五、地标岩石

- 海蚀柱、出发地附近的天然石拱：体素重建、噪声位移、分层的岩石块面，顶部草皮。尺寸、位置、碰撞规则不变。
- 灯塔残骸、巨环、旗：属于远行者的东西。灯塔和巨环用遗迹构件重建；旗用 `cloth` 材质的布面模型，保留随风摆动。
- `LandmarkMeshes` 里对应的函数在替换后删除。

## 六、飞船

玩家的飞船不属于远行者，是外来者的小型探索船。风格和探索者一致：干净、圆润、卡通。

| 项目 | 规格 |
| --- | --- |
| 尺寸 | 长 8.5 米，翼展 6.4 米，落地时高 2.6 米（不变） |
| 形体 | 水滴形机身，后掠短翼，三个落地支架，驾驶舱在前上方 |
| 颜色 | 船体米白 `#E9E4D8`，面板深灰 `#3B4148`，一道与围巾同色的红色条纹 `#C9503C`，驾驶舱玻璃青色 |
| 细节 | 尾部两个引擎喷口，驾驶时发暖橙光 `#FFB867`，停放时熄灭；左侧舱门，停放时放下一块舷梯 |
| 做法 | 主体用细分曲面做出流畅外壳，倒角做出面板边，面板缝用几何做浅槽；舱盖、引擎、起落架是单独部件；起落架和舱门收放如需动画，在 Blender 里做关键帧 |
| 面数 | ≤ 8000 |
| 碰撞 | 机身一个凸包，舷梯一个盒体（不变） |

## 七、验收

按"植被 → 动物 → 地标岩石 → 飞船"的顺序，各自可以单独提交。

### 自动检查

- `ecology_checks`、`ecology_runtime_checks` 通过，群系和分布数字和替换前一致；
- `ship_checks` 通过；
- 新增 `nature_checks.gd`（可无界面）：每种植被、动物都能加载；面数不超过上表；包围盒和替换前相差不超过 30%；风动权重存在且根部为 0。

### 自查与机位

- 每个模型的四视图、灰度图、剪影图；
- 重截 `s3_ground_day`、`s4_ground_sunset`、`s9_woodland`、`s13_tree_detail`、`s14_third_person`、`s18_meadow`～`s22_tundra`、`s23_ship_parked`、`s24_ship_low`，和替换前并排；
- 性能：植被是全场景最多的东西，上面这些机位平均帧时间增加不能超过 1 ms，否则先减面。`s19_broadleaf` 第一版已经超预算（12.873 / 15.122 毫秒），这一步要把它压回预算内。
