# 16 晨的推广（概要）

2026-10-25 由原规格整理而来。主线和第 5～8 步都完成以后，把晨从"一条主线"扩展成"一整颗能逛的星球"。本文只定内容和规则；**开工前由 Claude 根据试玩反馈写详细规格，没有详细规格之前不开始**。对应 [分步交接](20-分步交接.md) 的第 9 步。

## 一、目标

主线走完之后，晨的其他地方仍然值得去：任意选一个方向飞出去、降落、走一走，都能遇到一点远行者的痕迹和值得看的地貌。

## 二、内容

全部在烘焙时生成，规则和河畔古城相同。

| 内容 | 数量 | 规则 |
| --- | --- | --- |
| 聚落 | 再加 5～7 个 | 都在汇水面积 40 平方公里以上的河边；互相之间至少 6 公里。规模分三档：一个大城（四圈台地），两三个镇（三圈），其余是村（两圈，没有广场雕像） |
| 道路网 | 连通所有聚落 | 先连最近的两两，再补成连通图（最小生成树加两三条额外的边）；翻越主山脉的路走山口；沿途按第 4 步的规则放路碑 |
| 烽火塔网 | 每个聚落附近一座 | 所有塔最终都能沿视线连到天梯；第一条塔链之外的塔点亮后也会回应相邻的塔 |
| 墓园 | 每个大城和镇一个 | 都面向天梯 |
| 其他遗迹 | 散布在路边和野外 | 孤立的门、倒下的雕像、桥的残段、水渠、界碑。按"每步行五到十分钟遇到一样东西"的节奏放，而不是平均撒 |
| 洞穴 | 不再增加大型网络 | 新聚落附近补 1～2 个岩厦 |
| 回声 | 不增加 | 晨的回声只有四个加终章，故事已经完整 |

### 节奏检查

烘焙后，沿道路网每 400 米取一个点，统计 600 米内有没有任何遗迹或地貌特征。没有的点连续超过 3 个（约 1.2 公里），就在中间补一个小遗迹。

### 手记

新聚落、新烽火塔加进地点列表，名称按地形特征取（例如「溪口村」「北岭镇」），不用编号。

## 三、不做

- 新的回声、新的故事线。
- 新的大型洞穴网络、新的巨构。晨只有一座天梯。
- 烬、霜、渊环上的任何内容。
