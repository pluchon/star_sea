# 晨的全球水系

2026-10-20。对应「远行者」原第 2 步。总体验收见[第一阶段验收记录](远行者第一阶段验收记录.md)。

## 烘焙与运行时

水系改为六面、每面 384 × 384 的球心投影格网，共 884736 格。跨面连接八邻域，格子面积按球面投影修正；从海洋开始优先填洼，统计汇水面积，提取湖泊与河道。河道两次切角、加入渐隐蜿蜒，再以约 15 米间距采样。

```powershell
.\tools\Bake-World.ps1
```

烘焙结果为 `game/data/dawn_world.res`；原出发地、火山和地标布局独立保存于 `game/data/dawn_layout.tres`。删除水系结果后，仍可从布局和基础地形重新生成。基础地形、火山或水系阈值改变后必须重新烘焙。

数据记录源文件和布局的 MD5 签名，签名前统一换行符，避免 Windows 与 Git 的换行差异产生误报。耗时写入本地报告，不写入水系资源，避免仅因运行时间变化而修改交付数据。

运行时删除了样板区填洼和区域河道提取，只读加载全局数据。原火山与地标位置保留，河湖形状随全球流域改变。网格、碰撞、地图、植被、飞行保护仍使用同一个高度函数。数据缺失、版本或星球参数不符时明确报错退出。

## 连续性与水面

- 保存原格点在平滑主河道上的连接位置，使支流接到实际曲线，而不是平滑前的旧格点；连接处水位向下传播至一致。
- 相邻河面段共享横向方向，消除转弯处的三角形缝隙。
- 瀑布段的水位下降集中在岩坎处；河床、下落水面和底部水潭使用同一段高度曲线，增加水雾与空间瀑布声。
- 峡谷段扩大岸坡范围并增加坡度；普通河段保留较缓的河岸。
- 湖面扩大一圈覆盖并按实际高度裁剪岸线，查询时排除高于水位的陆地，避免格子边缘形成方形水面。
- 河湖按桶加载：附近 3 公里生成，离开 4 公里释放。大湖在 20 公里内另建水面，按片元距离与近景交接。后台只计算数组，网格、节点、粒子和声音均在主线程创建。
- 验收等待水面任务结束后再截图，不仅等待地形与植被。

## 本次数据与检查

一次烘焙约 7 秒，压缩资源约 2.62 MiB；1647 条河段组成约 1773.20 公里河道，1828 个湖泊，湖区格网面积约 705.86 平方公里。水系包含 5532 个符合落差条件的瀑布段；这是分段统计，不等于独立瀑布景点数量。

`hydrology_checks.gd` 检查签名、末端连接、下游水位、2000 个河床中心、出发地和附近瀑布，并执行出发地周围 10 万次高度查询。修复后无断开末端、无干燥河床中心，最近瀑布约 4.29 公里，高度查询平均约 3.6 微秒，低于 6 微秒要求。完整报告位于 `test-output/wanderer/hydrology_checks.json`。

新增机位为 `s25_waterfall`、`s28_canyon`。瀑布声使用持续水幕冲击、滤波水潭低鸣与少量高频水花分层合成，循环接缝和音频素材检查已纳入统一验收。

## 范围边界

石林、温泉与第二座火山属于原第 10 步，本阶段没有提前实现。湖区面积来自烘焙格网，实际裁剪岸线会略有不同；固定抽样和机位不能代替任意河流全程的人工观察。
