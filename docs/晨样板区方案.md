# 晨：样板区方案

2026-10-20。目标是把「晨」做成真正能玩的类地星球。做法是先在出生点附近做出一块完整、耐看的样板区，再把其中的规则推广到全球。本文是这一阶段的总体方案，每一轮的实现和验证另写记录。

## 一、为什么先做样板区

晨是程序生成的整颗星球，规则一旦做对，全球都会受益；规则没打磨好就铺开，只会把问题放大。现在觉得粗糙，主要不是东西少，而是站在任何一个地方看都不够耐看。

所以先选一块区域，把地形、水、植被、光影和风都做到位，在里面走 15 分钟不觉得无聊，再推广。

## 二、样板区的位置

出生点附近，半径约 5 公里。原因：

- 所有玩家都从这里开始，第一印象在这里形成。
- `SurfaceSites.find()` 已经保证这里有近岸、视野开阔、远处有 1200 米以上的高山，还有一处遗迹。
- 从出生点出发，一边是海岸，一边是上山的路，天然包含"山—坡—平原—海"的完整剖面。

## 三、现状

先把已有的东西说清楚，避免重复造轮子。

| 方面 | 现在有什么 | 主要不足 |
| --- | --- | --- |
| 地形 | 大陆、脊状山、丘陵和细节噪声；高地有沟谷下切、台地、盆地和海岸陡坎（`terrain_noise.gd`） | 起伏的"性格"比较单一；沟谷里没有水；没有湖 |
| 水 | 海平面上的一层海面，带深浅色、浪花和太阳反光 | 只有海，没有河和湖 |
| 植被 | 九种近景物件，按群系分布，有远近细节层级 | 风吹时各株方向随机，看不出"风" |
| 光照 | 三档卡通明暗、边缘光、四级阴影、泛光；太阳颜色和环境光随时间变化 | 没有整体调色，黄昏和正午只差在太阳颜色上；地面上没有流动的光影 |
| 天空 | 大气球壳、星空、天空着色器里的一层平面云 | 云不会在地面投下影子 |
| 人物 | 程序拼合的探索者，有简单的摆臂摆腿 | 没有随风飘的部件，第三人称时显得僵 |
| 地标 | 出生点附近一座石拱遗迹 | 只有一处，远处看不见 |

## 四、分轮计划

每一轮都是一个可以在本地拉下来试玩的 PR。

### 第一轮：光影与风

全局生效，改动集中在着色器和 `SkyDirector`，不改地形，所以不会影响已有的机位、地图和碰撞。

1. **按时间调色**。用 Environment 的调色曲线，按太阳高度在正午、黄金时段、黄昏和夜晚几组参数之间混合：亮部偏暖或偏冷，暗部带一点紫蓝，再配上饱和度。曲线只在变化明显时重建，平时不产生开销。
2. **云影**。地形、植被和探索者都在光照里乘上一层缓慢移动的云影。云影沿太阳方向投影，太阳低的时候影子拉得更远；高空时淡出（从太空看不见云，也就不该看到云影）。各星球的云量不同：晨多一些，烬很少。
3. **统一的风**。新增全局风向和阵风：草、花、芦苇、灌木和树冠朝同一个方向摆，阵风以波的形式从草地上扫过。风向随时间缓慢转动。
4. **探索者的围巾**。加一条随风和移动方向飘动的长围巾，第三人称下能看出风从哪边来。

性能：云影每像素多两次值噪声，风只在顶点着色器里算，调色是后处理里已有的查表。预计远小于 1 ms，最终以本地 780M 的机位测量为准。

### 第二轮：地形与水

这是最大的一块，需要单独设计，动手前会先补充细节。

- **河流**：从样板区的高山出发，沿高度函数逐步往低处找路，一直走到海，得到一条确定的河道折线。高度函数按"到河道的距离"往下切出河床和两岸，河面用沿河道的条带网格单独绘制，水位沿河道单调下降。网格、碰撞、地图和小地图仍共用同一个高度函数。
- **湖**：在盆地里选几个低点，水位固定，用同样的方式绘制局部水面。
- **地貌性格**：在现有台地和沟谷之外，增加火山锥与火山口湖、冰川 U 型谷、海蚀崖与海蚀柱。拱门、悬垂岩这类高度场表达不了的形状，作为单独摆放的模型。

要提前说明的代价：高度函数一改，出生点、机位、群系抽样数量都会变化，需要重新找机位、更新验收记录。所以这一轮要集中改，不零碎地改。

### 第三轮：地标与地球仪

- 三到五个远处就能看见的地标，比如孤峰上的石塔、巨大的倒塌拱门、海边的灯塔残骸。它们只提供方向，不提供任务。
- 立体地球仪：复用全球高度数据，贴到一个可旋转的小球上。可以在上面插旗，飞行时 HUD 显示一个很淡的方位标记。
- 是否做"自动飞往"，等地球仪做完、实际走过之后再决定。即使做，也是拉升、沿弧线飞行、降落的无缝过程，不是瞬移。

### 第四轮：生命与天气

- 少量动物：天上盘旋的鸟，草甸上靠近就会跑开的鹿形生物，湿地夜里的萤火。
- 天气：山谷晨雾、低云、偶尔的雨。
- 夜晚：月光作为第二种光色，偶尔出现极光。

## 五、"能玩"的验收标准

自动检查只能证明没坏，好不好玩要在本地实际走。每一轮的人工验收清单：

- 从出生点出发，任选一个方向走 10 分钟，至少看到两种不同的地貌。
- 黄昏和正午截图放在一起，不需要看太阳位置也能分辨时间。
- 第三人称下站着不动，能看出风从哪边吹来。
- 第二轮之后：沿河往下走能走到海。

自动检查继续沿用 `tools/Test-Acceptance.ps1`，性能预算不变：固定机位平均 ≤ 12.5 ms、P95 ≤ 16 ms。

## 六、不做的事

- 生态模拟（种群、食物链）：玩家感知不到，成本高。
- SSAO、SDFGI、体积雾、屏幕空间反射：780M 负担不起，也不适合卡通画风。
- 瞬移传送：会抽空"距离"这件事，和无缝降落的核心体验冲突。
