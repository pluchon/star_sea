# 晨：生物群系、近景细化与轻量音乐

2026-10-20。本轮继续完善类地星球「晨」的卡通画面，新增明确的基础群系表现与少量音乐。小地图固定在右上角，性能面板移到其左侧；全球地图的操作方式不变。

## 群系与地表

群系读取同一套海拔、纬度温度、湿度和林地参数，影响地表配色、植被密度与林地环境声。地图查询和小地图标题显示群系名称。地形高度函数未调整，已有地图、碰撞和位置数据继续一致。

| 群系 | 地表与植被 |
| --- | --- |
| 海岸 | 浅色沙地，树木避开低海拔海岸 |
| 草甸 | 黄绿色草地、野花与疏林 |
| 干草地 | 暖赭色地表、偏金色草叶，限制树木进入过干区域 |
| 阔叶林 | 较暖的林地色、阔叶树、蕨类与蘑菇 |
| 针叶林 | 冷绿林地、松树和林下小植物 |
| 湿地 | 青绿色低地、较多芦苇，减少密林覆盖 |
| 高山苔原 | 灰绿地表、较低草丛和矮灌木，限制高大树木 |
| 雪原 | 沿用雪线与坡度控制的雪层，保留裸露岩面 |

海洋单独分类。群系标签用于查询，颜色和密度在边界连续混合；这是风格化植物群系规则，不是气候、水文或完整食物网模拟。

固定种子的 20,000 个球面抽样包含上述全部分类：海洋 7936、海岸 476、草甸 3398、干草地 3430、阔叶林 1572、针叶林 971、湿地 1092、高山苔原 979、雪原 146。这些数量仅代表本次抽样。

群系形态参考 [NASA Mission: Biomes](https://science.nasa.gov/kids/earth/mission-biomes/) 与 [NPS 苔原介绍](https://www.nps.gov/subjects/nnlandmarks/tundra.htm)。参数与配色按「晨」的尺度自行设计，未使用这些网站的图片或真实地球贴图。

## 模型与光影

- 松树近景补充枝梢针叶簇，树梢改为细长冠簇；保留远距离简化网格。
- 增加菌柄、菌盖与浅色斑点组成的蘑菇簇，提供三级细节。
- 巨石扩大顶部断面，减少尖锥轮廓；晨的小石块更稀疏，湿润地区的岩石增加苔色。
- 新增项目自绘 `ground.svg`，以低对比短笔触补充草地近景，启用多级渐远纹理，采用三轴投影并随距离淡出。
- 抬亮晨的日间环境光，保留背光面的冷色；细小薄叶停止投影，减少地面密集闪点，树木、灌木和岩石继续投影。

素材均为项目内设计的网格、SVG 与合成音频，没有引入照片或扫描材质。

## 音乐

`tools/Generate-Music.py` 生成 52 秒原创器乐，用舒缓短句、稀疏和声及离线回声表现安静的地表探索。生成器只依赖 Python 标准库；游戏运行不依赖 Python。

进入晨的近地范围约 8 秒后开始淡入，乐句结束后留出约 38 秒安静间隔。离开晨或进入高空时淡出。设置增加独立“音乐”音量，默认 45%，播放层另有低增益；音乐音量归零立即静音，总音量仍控制所有声音。旧设置缺少音乐字段时使用默认值，非数值或非有限值会安全拒绝。

播放与音量接口依据 [Godot AudioStreamPlayer](https://docs.godotengine.org/en/stable/classes/class_audiostreamplayer.html)。
