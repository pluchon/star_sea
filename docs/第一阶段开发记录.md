## 实现与交接文档的差异

### 已确认的引擎参数修正

实时天空采用 `RADIANCE_SIZE_256`。原要求的 `PROCESS_MODE_REALTIME` 配合尺寸 32 会触发警告，随后引擎强制使用 256。[Godot 4.7 Sky 官方说明](https://docs.godotengine.org/en/4.7/classes/class_sky.html#enum-sky-processmode)

相机采用 `near = 0.5`、`far = 3000000`。原 `near = 0.05` 在标准版中使远裁剪平面法线退化为零，并持续触发 `create_frustum_points` 错误。独立诊断验证近裁剪距离 0.2 和 0.5 均不再出现该错误；正式采用已获确认的 0.5。[对应版本投影矩阵源码](https://github.com/godotengine/godot/blob/4.7.2-stable/core/math/projection.cpp)

原始诊断日志保存在 `test-output/p1/logs/03-camera-near-*.log`，修正后的正式运行日志不再包含该错误。近裁剪距离以内的表面会被裁剪，这项影响仍需在实际试玩中确认。

### 地形与出生点

固定种子 20261019、半径 40000 米、20000 个均匀随机方向的原始统计产生 78.47% 海洋。按第五步允许的调整范围，将海陆混合阈值由 `(-0.05, 0.25)` 改为 `(-0.35, 0.0)`，噪声频率、层数、山脉系数与高度上限保持原值。

出生点与截图共用一个确定性的选点函数。除原有低海拔、近海岸和 8 公里内存在高山的要求外，增加周围 10 米地面起伏检查及远山仰角范围，避免首个候选点直接面对遮住视野的陡坡。当前固定选中第 300 号候选点：海拔约 22.33 米，5.5 公里外有约 1310.48 米高的山。

星球噪声在 `_enter_tree()` 初始化，使地形子节点执行 `_ready()` 时已经可以读取。新启动时，玩家会等待脚下碰撞就绪，避免地形尚未生成便开始下落。

### 后台任务与上传

工作线程只计算顶点、法线、颜色、索引及碰撞面数组；主线程创建网格、节点和碰撞资源。父地形块在四个子块就绪后才隐藏；被合并掉的节点仍会回收其后台任务，场景退出时也会等待所有剩余任务结束。[官方线程安全边界](https://docs.godotengine.org/en/4.7/tutorials/performance/thread_safe_apis.html)、[任务回收要求](https://docs.godotengine.org/en/4.7/classes/class_workerthreadpool.html)

保持每帧最多上传 4 块，并增加约 1 毫秒的累计上传检查；碰撞资源单独占用一帧的上传额度。该处理用于避免两块碰撞资源连续创建时超过 4 毫秒。

### 渲染与时间

大气材质在透明海面与光环之后绘制，海面不参与阴影投射。竖直裙边只用于不透明地形，海面按交接文档保留球面网格，避免在透明海面中混入额外的竖直面。最终效果通过实际截图检查。

首轮截图中，原大气密度 6.0 几乎盖住了太空中的海陆与 5.5 公里外的山体。将密度改为 1.5，保留相同的八段积分、颜色、厚度和明暗规则，以减弱遮挡；这项调整针对画面辨识度，不用于改变性能验收标准。

正常昼夜的太阳轨道位于星球赤道平面，避免高纬度出生点因初始太阳偏角而永久处于白昼。固定机位仍按交接文档设置指定太阳高度，并冻结时间。

太空机位结合出生点方向布置，使到地面的直线路径位于星球外部；镜头同时容纳星球与气态巨星。60 秒降落验证遵守飞行速度上限，复用玩家飞行惯性与贴地保护，不直接传送玩家到终点。

### CPU 数据的含义

交接文档指定的 `TIME_PROCESS + TIME_PHYSICS_PROCESS` 并非逐帧 CPU 工作时间。4.7.2 源码每秒将这两个监控器更新为窗口内峰值。因此报告中的 `cpu_ms` 是这些监控读数的统计，不能与逐帧 GPU 时间直接相加，也不能据此声称某一帧的 CPU 实际耗时。帧间隔使用单调时钟逐帧记录。[对应版本主循环源码](https://github.com/godotengine/godot/blob/4.7.2-stable/main/main.cpp)

截图写盘后等待两个监控窗口，再测量 240 帧，避免截图编码耗时污染 CPU 监控数据。

## 验证边界与待验收事项

性能结果仅代表本机、当前版本、1080p 和固定种子。静态截图与自动路线不能证明所有视角下都没有细节层级接缝或透明排序问题。

目前需要用户判断整体配色、大气浓度、远山层次和夜空亮度。当前版本保留单星球技术小样范围，尚未扩展更多星球、地表小物件、声音、菜单或存档。

机位 JSON 与截图同名，保存完整相机宇宙坐标、海拔、太阳高度、画质设置和统计量。

- 地形统计：海洋 42.105%，最高 1941.16 m，最低 -423.12 m，20000 个方向，检查通过。
- 几何检查：六个面、6534 个地表顶点的球面位置、法线、绕序及碰撞面一致性通过；海面不包含竖直裙边。
- 60 秒降落：P99 7.454 ms，最大帧间隔 9.066 ms，预热 3 秒后超过 50 ms 的帧数为 0，上传峰值 2.806 ms，最终距目标 0.0024 m。
- 固定速度上传专项：从 200 公里高度以 2000 m/s 下降，持续 100.00 s，上传峰值 1.261 ms，低于 4 ms。
- 40 秒行走：水平位移 151.51 m，最低相对地面高度 -0.0053 m，检查通过。
- 飞行与原点跟随：模拟最高海拔 1355.08 km，返航后离地 1.196 m，共平移原点 773 次，平移造成的宇宙坐标误差最大 0.000 m。此项是固定时间步长的逻辑检查，不作为真实渲染性能数据。
- 昼夜轨道：出生点完整周期的太阳高度覆盖 -25.71° 至 25.71°，检查通过。
- 输入事件检查：F 切换飞行、近地 F 切回步行、H 帮助、F3 性能、Esc 释放鼠标及 F12 保存截图通过。采用引擎输入事件注入，不代表用户已完成手动试玩。
- 最终无界面导入、启动及 PowerShell 语法检查通过；当前正式验证日志没有引擎 ERROR 或 SCRIPT ERROR。
