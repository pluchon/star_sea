## 视角修复

| 问题 | 复现依据 | 当前处理 |
| --- | --- | --- |
| 水平转动引入侧倾 | 身体上轴与最近星球径向轴不同，100 像素水平事件出现约 17° 侧倾 | 水平转动围绕角色自身上轴 |
| 窗口缩放改变灵敏度 | 相同屏幕位移、不同界面位移产生不同转角 | 捕获鼠标使用 `screen_relative`，水平与俯仰统一处理 |
| 飞行时视角自行转动 | 无鼠标输入仍执行每帧地面对齐 | 飞行不自动对齐；最近星球变化只影响高度与地表查询 |
| 飞行上下方向与观察坐标不一致 | 升降沿最近星球径向轴，水平转动沿另一坐标系 | 升降沿角色自身上轴 |
| 切回步行时可能改变观察方向 | 步行需要恢复当地重力方向 | 先保存视线，重新分解为地面朝向和俯仰 |
| 放置玩家后短暂使用原星球参数 | `place_at()` 查询旧 `_planet` 的高度 | 放置时立即更新最近星球及实际径向高度 |

输入坐标依据：[Godot InputEventMouseMotion](https://docs.godotengine.org/en/4.7/classes/class_inputeventmousemotion.html)。

新增 `camera_checks.gd` 检查水平转动、俯仰、缩放、无输入漂移、跨星球朝向和步行切换。源代码通过检查不代表手动操控已经验收。

本轮验证：开发引擎的视角检查通过，三颗星球行走和跳跃回归通过，F/H/F3/Esc/F12 输入检查通过；Windows Release 重新导出及正常菜单启动通过。视角修复随本轮改动提交，更新后的可执行文件位于 `build/StarSea/StarSea.exe`。植物生态等问题的最新状态见下文。

## 后续修复与覆盖

- 植被从近景草石扩展为林木、灌木、花草与温湿度分区；改用固定全球分块和位置种子，重新进入后保持分布一致。
- 高速飞行加入沿位移的地表检查，防止仅检查终点时穿过天体；接触点容差避免单精度舍入阻止重新起飞。
- 整球检查增加三颗星球共九条环线、六面十八处着陆；有限采样不能代表任意地点都已验证。
- 声音增加连续循环、林地层次、近岸判断和四种地面脚步，每种三个变体；保留五种环境的实际混音录音。
- 异常设置与旅程先完整校验，再修改世界状态；零音量关闭主音频总线。
- 暂停菜单隐藏原有帮助与性能面板，继续时恢复，避免界面重叠。
