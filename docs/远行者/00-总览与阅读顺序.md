# 远行者：总览与阅读顺序

2026-10-20。本目录是《星海尽头》第二阶段的完整方案。方案由 Claude 编写，编码由 GPT 按文档执行，画面、手感、性能由用户在本机验收。

## 一、这一阶段要做成什么

一个已经消失的文明留下的星系。玩家是唯一的来访者，通过遗迹、尺度和环境，慢慢读懂这里曾经发生过什么，最后走到他们离开的地方。

用户要的感觉是：**宇宙文明的寂寥与沧桑**。故事很简单，氛围要到位。

## 二、已经定下的决定

| 决定 | 内容 |
| --- | --- |
| 故事 | 简单的暗线，不写一句台词和文字说明，靠建筑、壁画和"回声"讲 |
| 氛围 | 优先级最高；所有内容先问"它让这里更寂寥、更沧桑、更有文明感吗" |
| 飞行 | 飞船和人分开：飞行就是驾驶飞船；降落后飞船停在原地，人只能步行 |
| 建模 | 优先用 Blender 的 Python 脚本生成模型、导出 glb；做不到时用 GDScript 程序化生成，两条路的尺寸和命名完全一致 |
| 起步范围 | 先在「晨」做一个完整的文明区，跑通全部系统，再推广到全球和另外两颗星球 |
| 不做 | 敌人、战斗、任务、指路箭头、文字剧情、对话、收集计数器、照片或扫描贴图 |

## 四、执行方式

1. 按 [分步交接](20-分步交接.md) 一步一步做，不跳步，不合并步骤。
2. 每一步结束时：
   1. 跑该步列出的检查，以报告里的 `passed` 为准；
   2. 截该步列出的机位；
   3. 在 `docs/` 下写一份记录，说明做了什么、和规格有什么出入、检查结果；
   4. 更新 README 的文档表；
   5. 提交。
3. 规格里写明的数值是起点，不是最终值。实际效果不好可以调整，但要在记录里写明调了什么、为什么。
4. 规格没写到、需要做设计判断的地方，按 [世界观与美术圣经](01-世界观与美术圣经.md) 的原则决定，并在记录里说明。拿不准的停下来问用户，不要自己发挥。
5. 不改和当前步骤无关的代码。发现别处的问题，记在记录的"遗留问题"里。

## 五、名词

| 名词 | 意思 |
| --- | --- |
| 远行者 | 这个已经消失的文明。只在文档里使用，游戏里不出现文字 |
| 文明区 | 一组相互关联的遗迹：聚落、道路、水渠、梯田、墓地、神殿洞穴、烽火塔 |
| 回声 | 在关键遗迹处出现的一段过去的剪影光影，无文字，是讲故事的主要手段 |
| 烽火塔 | 建在山顶、两两相望的石塔，点亮一座就能看到下一座，是不用箭头的指路方式 |
| 天梯 | 晨上通往太空的巨型高塔，已断裂，是全星球最醒目的巨构 |
| 渊环 | 气态巨星「渊」外的环形空间站残骸，游戏的终点 |
| 样板区 | 第一阶段在出发地附近做的火山、河湖和地标区域 |
| 烘焙 | 用离线工具把耗时的计算结果（例如全球水系）预先算好存成数据文件 |
