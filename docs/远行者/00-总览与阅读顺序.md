# 远行者：总览与阅读顺序

2026-10-20。本目录是《星海尽头》第二阶段的完整方案。方案由 Claude 编写，编码由 GPT 按文档执行。画面和手感由 GPT 按工程约定第四节自查；性能、听感和最终手感由用户在"第一版可玩"时在本机确认。

## 当前状态

- 第 0～3 步（飞船与步行、全球水系、遗迹构件库）已经完成，见 [远行者第一阶段验收记录](../远行者第一阶段验收记录.md)。
- 2026-10-20 用户调整了范围：**目前只做晨**；加强高山、峡谷、洞穴和移动方式；结局改在晨上收尾。文档已按此整理，从 [分步交接](20-分步交接.md) 的第 4 步继续。

## 一、这一阶段要做成什么

一个已经消失的文明留下的星系。玩家是唯一的来访者，通过遗迹、尺度和环境，慢慢读懂这里曾经发生过什么，最后走到他们离开的地方。

这一阶段的具体目标：把**晨**做成一个基本能玩的探索世界，有高山、峡谷、洞穴网络和远行者的遗迹，有一条轻量的主线和结局。以后的开发从这里继续生长。

用户要的感觉是：**宇宙文明的寂寥与沧桑**。故事很简单，氛围要到位。

## 二、已经定下的决定

| 决定 | 内容 |
| --- | --- |
| 故事 | 简单的暗线，不写一句台词和文字说明，靠建筑、壁画和"回声"讲 |
| 氛围 | 优先级最高；所有内容先问"它让这里更寂寥、更沧桑、更有文明感吗" |
| 飞行 | 飞船和人分开：飞行就是驾驶飞船；降落后飞船停在原地，人只能步行 |
| 范围 | **只做晨。** 烬、霜、渊环暂不涉及，代码里不为它们新增内容；公共代码的改动仍要保证它们不坏 |
| 地形 | 晨要有史诗尺度的地形：一条最高近 4 公里的主山脉，一条深近 1 公里的大峡谷，三个大型洞穴网络和十几个小洞穴 |
| 移动 | 步行、跳跃之外，加滑翔（围巾展开成软翼）和只能在标出的地方进行的简单攀爬；没有体力条、没有摔伤 |
| 结局 | 晨自己收尾：四个回声看完后，天梯断口亮起；驾驶飞船飞上去，看终章回声，沿光之路飞向星海，字幕，然后继续自由探索 |
| 音乐 | 用用户提供的曲目（只用于个人游玩，不商用），按情境分配，统一响度 |
| 建模 | 人和东西用 Blender 的建模工具做（修改器、布料和刚体模拟、曲线、几何节点、骨骼动画），不在代码里拼几何体；石头、植物等通用自然物可用 CC0 素材。地形、洞穴、天梯这类大尺度的东西继续程序生成（[规格 12](12-遗迹构件与模型规范.md) 第二节） |
| 验收 | GPT 自查画面和手感，不等用户逐步验收；用户只在"第一版可玩"时试玩 |
| 优先级 | 尽快做出第一版能完整玩一遍的版本：出发地 → 古城 → 回声洞 → 塔链 → 天梯 → 断口结局。其余内容在第一版之后补 |
| 不做 | 敌人、战斗、任务、指路箭头、文字剧情、对话、收集计数器、照片或扫描贴图 |

## 四、执行方式

1. 按 [分步交接](20-分步交接.md) 一步一步做，不跳步，不合并步骤。
2. 每一步结束时：
   1. 跑该步列出的检查，以报告里的 `passed` 为准；
   2. 截该步列出的机位；
   3. 在 `docs/` 下写一份记录，说明做了什么、和规格有什么出入、检查结果；
   4. 更新 README 的文档表；
   5. 提交。
3. 规格里写明的数值是起点，不是最终值。实际效果不好可以调整，但要在记录里写明调了什么、为什么。
4. 规格没写到、需要做设计判断的地方，按 [世界观与美术圣经](01-世界观与美术圣经.md) 的原则决定，并在记录里说明。只有规格之间互相矛盾、或者要改变已定决定（第二节）时才停下来问用户。
5. 不改和当前步骤无关的代码。发现别处的问题，记在记录的"遗留问题"里。
6. **画面和手感由 GPT 自己检查，不等用户验收。** 用户没有时间逐步看图。每一步按 [工程约定](02-工程约定.md) 第四节的"自查"流程，自己看截图、自己判断、自己修，然后直接进入下一步。各规格里的"人工确认"一节，都是 GPT 的自查项。用户只在"第一版可玩"完成时试玩一次（见 [分步交接](20-分步交接.md)）。
7. **随时可以停，停下不丢东西。** 额度有限，会话可能随时中断：
   - 每完成一步就提交并推送，不要攒几步一起提交；
   - 一步做到一半要停时（用户要求停、看到额度或用量的提示、或者用户给的终点到了），先把能提交的部分整理成可以运行的状态提交推送，再更新 `docs/远行者/进度.md`：做到哪一步的哪一项、下一步从哪里接着做、有什么没做完或临时的东西。然后停下，不开始新的一步；
   - 用户给了终点（例如"这次只做第 4b、5 步"）就做到那里为止；
   - **按余量决定继续还是停**：如果本机能查到 Codex 的用量（见下），每一步开始前、每完成一个子项后查一次：
     - 五小时窗口剩余不到 25%，或每周剩余不到 10%：不开始新的一步，把手上这步做到能提交的状态，提交、更新 `进度.md`、停下；
     - 准备开始第 5、6、9a、10、11 步这些大步骤时，五小时窗口剩余不到 45% 就不开始，直接停下；
     - 查用量的方法只在本机用，不提交进仓库，脚本不能把登录凭据写进日志或文件；
     - 查不到用量时，按用户给的终点停。
   - 下次开始时先读 `进度.md`，从那里接着做。

## 五、名词

| 名词 | 意思 |
| --- | --- |
| 远行者 | 这个已经消失的文明。只在文档里使用，游戏里不出现文字 |
| 文明区 | 一组相互关联的遗迹：聚落、道路、水渠、梯田、墓地、神殿洞穴、烽火塔 |
| 回声 | 在关键遗迹处出现的一段过去的剪影光影，无文字，是讲故事的主要手段 |
| 烽火塔 | 建在山顶、两两相望的石塔，点亮一座就能看到下一座，是不用箭头的指路方式 |
| 天梯 | 晨上通往太空的巨型高塔，已断裂，是全星球最醒目的巨构 |
| 断口平台 | 天梯 6.2 公里高的断口下方还完整的平台，只能驾驶飞船到达，晨的结局在这里 |
| 光之路 | 终章回声留下的一串光点，从断口平台伸向「渊」，沿着它飞行进入结尾 |
| 渊环 | 气态巨星「渊」外的环形空间站残骸。原来是游戏的终点，现在暂不涉及 |
| 主山脉、大峡谷 | 晨上两处史诗尺度的地形，见规格 21 |
| 洞穴网络 | 有多个入口、分岔和环路的大型洞穴，晨上有三个：回声洞、暗河洞、青晶洞 |
| 上升气流 | 山脊、峡谷边、塔顶、火山口上方把滑翔的人往上托的气流 |
| 攀爬区 | 明确标出可以攀爬的地方：藤蔓墙、绳子、崖面上的攀爬路线 |
| 样板区 | 第一阶段在出发地附近做的火山、河湖和地标区域 |
| 烘焙 | 用离线工具把耗时的计算结果（例如全球水系）预先算好存成数据文件 |
