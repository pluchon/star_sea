# 规格 10：飞船与步行

## 一、为什么改

现在按 F 就能在任何地方起飞，贴地时也能飞。结果是河谷、山路、远处的地标都不需要走过去，地面上做的所有内容都会被"飞过去"打折扣。

改法：**飞行就是驾驶飞船。** 降落后飞船停在原地，人下来只能步行。从太空到地面的无缝降落保持不变。

## 二、行为

### 状态

| 状态 | 玩家模式 | 飞船在哪里 | 能做什么 |
| --- | --- | --- | --- |
| 驾驶 | `Mode.FLY` | 跟着玩家，就是玩家所在的位置 | 现有的飞行操作；在合适的地面附近按 F 降落 |
| 降落中 | 过渡，约 2.5 秒 | 自动下降到地面 | 不接受输入 |
| 步行 | `Mode.WALK` | 停在降落点，是一个有碰撞的物体 | 走、跑、跳；靠近飞船按 F 登船；远处长按 F 召唤飞船 |
| 召唤中 | `Mode.WALK` | 自己飞过来 | 照常步行；飞船落地后可以登船 |

太空里只能驾驶。不能在半空中下船。

### 操作

沿用现有的 `toggle_fly` 动作（F 键），按"短按"和"长按"区分：

| 情况 | 操作 | 结果 |
| --- | --- | --- |
| 驾驶，离地 40 米以内，速度低于 30 m/s | 短按 F | 检查脚下能否降落；能就开始降落，不能就提示「这里不能降落」2 秒 |
| 驾驶，其他情况 | 短按 F | 无反应 |
| 步行，离飞船中心 6 米以内 | 短按 F | 登船 |
| 步行，离飞船 6 米以外 | 长按 F 1.2 秒 | 召唤飞船；不能召唤时提示原因 |

短按：按下到松开不足 0.4 秒。长按：持续按住满 1.2 秒时立即触发，不等松开。

### 能否降落

以候选点为中心，在半径 6 米内取 9 个点（中心加两圈各 4 个）检查：

1. 所有点 `height() >= 0.5`，不在海里；
2. 所有点 `water_surface()` 为负无穷，不在河湖里；
3. 最高点和最低点相差不超过 2.5 米；
4. 不在任何地标、遗迹或聚落的空地范围内（`TerrainFeatures.in_clearing()`，以及后续文明区的占地查询）；
5. 不在洞穴入口 20 米以内。

### 降落过程

1. 锁定输入，飞船水平速度在 0.6 秒内降到零。
2. 用 2 秒缓入缓出地下降到地面：飞船底部离地 1.2 米（落地脚的高度），姿态的"上"对齐当地径向，朝向保持降落前的水平朝向。
3. 播放落地声和一圈扬尘。
4. 飞船脱离玩家，变成停放的飞船，挂到当前星球节点下，保存相对星球的坐标和朝向，打开碰撞。
5. 玩家放到飞船左侧舱门外 4 米处，朝向与飞船相同，切换为 `Mode.WALK`，`_waiting_for_ground = true`，相机回到第一或第三人称（保持降落前的选择）。

### 登船

在 1 秒内淡出淡入（声音同时播放舱门声），玩家切换为 `Mode.FLY`，位置放到飞船位置上方 3 米，速度为零，停放的飞船节点移除，飞船重新跟随玩家。

### 召唤

1. 不能召唤的情况：玩家在洞穴里；飞船在另一颗星球上（提示「飞船不在这颗星球上」）；周围找不到能降落的地面。
2. 在玩家周围 15～40 米内找一个能降落的点，按与玩家的距离从近到远试，找不到就提示「附近没有能降落的地方」。
3. 飞船起飞到离地 60 米，沿大圆以离地 120 米的高度飞向目标，再下降落地。巡航速度 `clampf(距离 / 20, 40, 300)` m/s，所以几公里内的召唤大约 20 秒，远处最多每秒 300 米。
4. 飞行途中能在天上看到它、听到引擎声（3D 声源）。
5. 玩家在飞船到达前离目标点超过 60 米，就在新位置附近重新找落点。

召唤要花时间、能看见它飞来，这样世界的距离感还在，又不会让人为了走回飞船而烦躁。

### 开局

新旅程开始时，玩家在出发地步行，飞船停在出发地附近：从出发地朝向转 120°、距离 16 米处，通过上面的降落检查。找不到就在 10～40 米内按角度搜索。

## 三、界面

- 步行时离飞船 30 米以外，屏幕上方显示飞船方位：白色小箭头加距离，样式与旗子方位标记一致（`TerrainAtlas.draw_compass`），透明度 0.5。只在同一颗星球的地面附近显示。
- 靠近飞船 6 米以内时，屏幕下方中间短暂显示「F 登船」。
- 提示文字用现有 HUD 字体，13 号，显示 2 秒后淡出。
- 帮助面板更新 F 键的说明：「F　降落 / 登船（长按召唤飞船）」。

## 四、实现

### 新文件

| 文件 | 内容 |
| --- | --- |
| `game/scripts/player/ship.gd` | `class_name StarSeaShip extends Node3D`：飞船模型、碰撞、引擎光、声音；停放、跟随、召唤飞行三种状态 |
| `game/scripts/player/ship_meshes.gd` | 程序化飞船网格，在没有 glb 模型时使用 |
| `game/models/ship/ship.glb` | Blender 导出的飞船模型（见 [遗迹构件与模型规范](12-遗迹构件与模型规范.md)） |

### `StarSeaShip`

```gdscript
enum State { CARRIED, PARKED, CALLED }
var state: State
var planet: Planet              # 停放或召唤时所在的星球
func attach_to(player: StarSeaPlayer) -> void      # 驾驶：作为玩家的子节点，关闭碰撞
func park(planet: Planet, local_transform: Transform3D) -> void   # 挂到星球下，打开碰撞
func call_to(planet: Planet, target_direction: Vector3) -> void   # 召唤飞行
func landing_transform(planet: Planet, direction: Vector3, forward: Vector3) -> Transform3D
static func can_land(planet: Planet, direction: Vector3) -> String  # 返回空字符串表示可以，否则返回提示文字
```

- 驾驶时，飞船是 `Player` 的子节点，局部位置让相机位于驾驶舱。第一人称时隐藏飞船模型；第三人称时显示飞船，不显示探索者，相机弹簧臂长度改为 12 米、抬高 2 米。
- 停放时，飞船是星球节点的子节点，碰撞层 2（与地标、树木相同），玩家可以绕着走、站上舷梯。
- 召唤飞行时也是星球节点的子节点，碰撞关闭，每帧沿路径移动，高度用 `height()` 加离地高度。

### 对 `player.gd` 的修改

- `_unhandled_input` 里 `toggle_fly` 的处理改为短按/长按判断，删除"离地 2 米以内能切回步行"的旧逻辑。
- 新增 `land()`、`board()`、`call_ship()`，状态切换都经过这三个函数。
- `set_third_person()` 根据当前模式切换弹簧臂长度和可见模型。
- `Mode.FLY` 的含义不变，`ShotCatalog` 和 `verify.gd` 直接设置 `mode = Mode.FLY` 放置机位的做法继续有效：此时飞船跟随玩家。

### 存档

在 `journey` 节新增可选字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `boarded` | bool | 是否在船上 |
| `ship_planet_seed` | int | 飞船所在星球 |
| `ship_position` | Vector3 | 相对星球中心 |
| `ship_up`、`ship_forward` | Vector3 | 停放姿态 |

旧存档没有这些字段时：`mode` 为飞行则视为在船上；否则在玩家附近按开局规则放置飞船。召唤途中保存时，存成飞船已到达目标点。

### 声音

用 `tools/Generate-Audio.py` 新增：

| 文件 | 内容 |
| --- | --- |
| `engine.wav` | 循环，低频嗡鸣加少量滤波噪声，音高随速度变化 |
| `ship_land.wav` | 落地的闷响与气声 |
| `ship_hatch.wav` | 舱门开合 |

记得同步更新 `tools/Check-Audio.py` 的文件清单和数量。

## 五、飞船外形

玩家的飞船不属于远行者，是外来者的小型探索船。风格与探索者一致：干净、圆润、卡通。

| 项目 | 规格 |
| --- | --- |
| 尺寸 | 长 8.5 米，翼展 6.4 米，落地时高 2.6 米 |
| 形体 | 水滴形机身，后掠短翼，三个落地支架，驾驶舱在前上方 |
| 颜色 | 船体米白 `#E9E4D8`，面板深灰 `#3B4148`，一道与围巾同色的红色条纹 `#C9503C`，驾驶舱玻璃青色（与头盔玻璃一致） |
| 细节 | 尾部两个引擎喷口，驾驶时发暖橙光 `#FFB867`，停放时熄灭；左侧舱门，停放时放下一块舷梯 |
| 面数 | LOD0 不超过 4000 个三角形 |
| 碰撞 | 机身一个凸包，舷梯一个盒体 |

## 六、验收

### 自动检查

扩展 `interaction_checks.gd`，或新建 `ship_checks.gd`：

1. 在出发地附近的平地降落：玩家变成步行，飞船停放，碰撞存在，玩家与飞船距离 3～6 米。
2. 在海面、河面上方、陡坡上降落：被拒绝，状态不变。
3. 6 米内登船：玩家变成飞行，停放节点移除。
4. 在 3 公里外召唤：飞船在预期时间（±20%）内落在玩家 15～40 米内的可降落点。
5. 存档往返：在船上、停放、召唤途中三种状态都能正确恢复；非法字段整份拒绝。
6. 现有的降落测试（`--descent`）和行走测试（`--walk`）继续通过。
