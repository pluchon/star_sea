# 规格 16：天梯

## 一、目标

晨上最醒目的东西：一根从大地直插天空的巨塔。远行者沿着它离开。它的主体保存完好，顶部在 6 公里多的高空断开，几根缆索垂下来，在风里缓缓摆动。

它要做到：

- 从出发地、河畔古城和晨的大部分地方都能看到；
- 白天是一道淡淡的灰白色竖线，夜里是一串通向星空的琥珀色光环；
- 走到它脚下时，人小得像一粒沙；
- 可以乘一部还能动的升降台，上到 240 米高的观景环，俯瞰整个文明区。

## 二、选址（烘焙时计算）

烘焙顺序：水系 → **天梯** → 河畔古城 → 烽火塔链 → 洞穴。古城和墓园的朝向要参照天梯的方向，所以天梯要先定。

条件：

1. 离出发地 12～25 公里。
2. 所在地海拔 150～700 米；半径 250 米内平均坡度小于 0.1；不在河道、湖泊内。
3. 从出发地（眼高 1.7 米）能看到天梯 1500 米高处以上的部分：视线不被地面挡住，考虑曲率。
4. 从出发地看去，天梯的方位与出发地朝向远山的方位相差 40°～120°，两者不重叠，各占一片天空。
5. 满足的候选里，选离出发地最近的。

## 三、结构

| 部分 | 规格 |
| --- | --- |
| 基座 | 三层同心圆台地：半径 180、120、70 米，分别比基准地面高 6、12、18 米。外圈立面用 `wall`、`plinth_round` 拼成，带残破和积土。东南西北四面各有一道 20 米宽的大台阶（`steps` 拼接）。顶层台地中央是塔身，塔身外一圈 `column` 柱廊 |
| 塔身 | 底部半径 34 米，到 1 公里高处收到 22 米，之后保持 22 米直到断口。古铜色的环箍 `patina` 每 120 米一道（比塔身宽 4 米）；四条竖向的光纹细带从底部一直通到断口 |
| 光环 | 每 600 米一道发光的琥珀色环带，宽 6 米。白天几乎看不见（`awake` 0.15），夜里 `awake` 0.6 |
| 主门 | 顶层台地朝出发地方向一侧，塔身上开一道高 24 米的拱门，门楣上一个巨大的环与径；门两侧各一尊放大 3 倍的站立雕像（高约 14 米）。门前台阶顶端是**回声 3**的锚点（见 [回声与旅行手记](17-回声与旅行手记.md)） |
| 升降台 | 门内一个直径 12 米的圆形平台，见第四节 |
| 观景环 | 240 米高处环绕塔身一圈的阳台，外半径 42 米，有护栏，一处护栏塌落 |
| 断口 | 6.2 公里高处，断面不规则，几块翘起的外壳 |
| 缆索 | 从断口垂下 5 根缆索，直径 1.2 米，长 300～800 米，用顶点着色器按风缓慢摆动 |

## 四、升降台

- 玩家走上门内的平台，站 2 秒：平台边缘和门楣的光纹亮起（`awake` 0 → 1），播放低沉的启动声（`lift_start.wav`）。
- 平台用 `AnimatableBody3D`，沿塔身轴线匀速上升，40 秒升到 240 米；起步和停止各有 3 秒的缓动。上升时有持续的低频嗡鸣（`lift_hum.wav`）。
- 到达后，平台停在观景环的门口，玩家走出来。
- 平台上站 2 秒会再次启动下降；平台不在玩家所在的这一层时，站在升降井门口 2 秒，平台会自己下来或上去接人。
- 玩家站在平台上时，`CharacterBody3D` 必须跟着平台走，不能抖动或滑落。验收时要实测。

## 五、渲染

### 两套网格

| 网格 | 内容 | 什么时候显示 |
| --- | --- | --- |
| 远景 | 16 边形渐收的柱体，含环箍和光环，断口和缆索，三角形不超过 3000 | 在晨的大气层内一直显示，没有可见距离限制 |
| 近景 | 基座、台阶、柱廊、雕像、主门、升降井、观景环，用遗迹构件和专门的网格 | 离基座 2.5 公里内 |

- 远景网格在近景范围内仍然显示塔身部分，只隐藏和近景重叠的底部 300 米。
- 远景网格只在玩家 3 公里内投影（太远时阴影贴图覆盖不到，开着也没用）。
- 从太空能看到它刺出大气层。断口在 6.2 公里，大气厚 8 公里，所以从高空俯瞰是一根从地面伸进大气层的细线。

### 着色

- 塔身石材用 `ruin.gdshader`，但颜色比普通遗迹略冷、略亮：`#DCD6C8`。
- 环箍用铜锈，光环和光纹用 `glyph`。
- 塔身高处受大气淡化，白天在远处看是淡灰白，与天空颜色接近但能分辨。

### 夜景

- 光环 `awake` 夜里升到 0.6，加上泛光，远看是一串向上缩小的光点。
- 断口处一盏极弱的琥珀色光斑（同烽火塔的远景光斑做法），像有什么还在等待。

## 六、实现

| 文件 | 内容 |
| --- | --- |
| `game/scripts/civilization/sky_ladder.gd` | `class_name SkyLadder extends Node3D`：读天梯数据，建远景和近景网格、升降台、触发与动画 |
| `game/scripts/civilization/sky_ladder_meshes.gd` | 塔身、环箍、光环、断口、缆索、观景环的程序化网格（这些尺度太大，不适合用 Blender 的通用构件） |
| `game/shaders/tether.gdshader` | 缆索摆动 |

- 地形塑造：基座三层台地写进 `TerrainFeatures` 的平整数据，和古城的广场、台地同一种机制。
- 天梯位置、朝向、基准高度存在 `CivilizationData` 里。
- 新的音效：`lift_start.wav`、`lift_hum.wav`，由 `Generate-Audio.py` 生成。

## 七、验收

### 自动检查

扩展 `civilization_checks.gd`：

1. 天梯离出发地 12～25 公里，从出发地能看到 1500 米以上的部分。
2. 从河畔古城中心能看到 1000 米以上的部分。
3. 基座三层台地的地面高度与设计值相差不超过 0.2 米。
4. 模拟玩家乘升降台上下各一次：全程始终站在平台上（`is_on_floor()` 为真的帧数占 95% 以上），到达后能走出平台。
5. 统计远景网格三角形数。
