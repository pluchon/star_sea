# 规格 17：回声与旅行手记

## 一、目标

- **回声**：在关键遗迹处，过去的一个片段以琥珀色的剪影重现十几秒。没有文字，没有声音对白，只有人影、光和一小段音乐。晨的四个回声连起来，就是 [世界观与美术圣经](01-世界观与美术圣经.md) 第二节故事里属于晨的部分。
- **旅行手记**：自动记录去过的地方和看过的回声，是玩家唯一的"进度"，但不催促。
- **结局**：晨的四个回声都看过以后，天梯断口亮起一处光，引向最后一个回声和结局（[规格 16](16-天梯.md) 第七节）。

> 2026-10-20 调整：目前只做晨。烬、霜和渊环的回声保留在第四节作为以后的方向，**这一阶段不做**，结局也不依赖它们。

## 二、回声

### 回声人影

- 远行者的样子：修长的人形，身高 2.1 米（比探索者高），兜帽长袍，看不到脸，袍子盖住脚。孩子 1.3 米。
- 模型：`echo_figure` 和孩子 `echo_child`，外形按 [构件修订](23-构件修订.md) 第二节第 1 项。
  - 带骨架的蒙皮模型（第 4b 步做好骨架和蒙皮，见规格 23 第六节）。长袍随骨骼变形，下摆随移动自然摆动。
  - 下表的姿势和动作都在 **Blender 里做成骨骼动画**（关键帧），和模型一起导出到 glb；Godot 里用 `AnimationPlayer` 播放和混合。不在 GDScript 里用节点变换拼动作。
  - 动画用循环（`walk`、`carry`、`child_run`、`old_walk`）或单次加保持最后一帧（`kneel`、`sit`、`raise`、`paint`）。动作之间用 0.3 秒混合过渡。
- 姿势：

  | 姿势 | 说明 |
  | --- | --- |
  | `stand` | 站立 |
  | `walk` | 行走：身体轻微起伏，袍摆前后摆 |
  | `kneel` | 单膝跪地 |
  | `sit` | 盘坐 |
  | `raise` | 一臂上举 |
  | `carry` | 背着包裹走 |
  | `paint` | 一臂伸向墙面，缓慢画弧 |
  | `child_run` | 孩子小跑（用 `echo_child`） |
  | `old_walk` | 老人慢走：步子小、背微驼、偶尔停一下（终章回声） |
  | `place` | 弯腰把手里的东西放到地上或火盆里（回声 4 添火、终章放灯） |

- 新着色器 `echo.gdshader`：
  - 琥珀色 `#F2B45A`，不受光照；
  - 身体半透明（0.35），边缘强（菲涅尔）；
  - 自下而上缓慢流动的细横纹，偶尔轻微闪烁；
  - 用噪声溶解做淡入淡出（`uniform float presence` 0～1）；
  - 人影身上持续向上飘出少量光点粒子。

### 触发

| 条件 | 规则 |
| --- | --- |
| 位置 | 玩家步行，在回声锚点半径 `radius`（8～14 米，每个回声单独定）内 |
| 静止 | 速度低于 0.5 m/s 持续 2 秒 |
| 重看 | 看过之后可以重看：离开半径再回来，静止 3 秒 |
| 提示 | 没看过的回声，锚点处一直有一团缓慢旋转、上升的琥珀色光点，30 米外就能看到，邀请玩家走近 |

### 播放过程

1. 光点向锚点聚拢（1.5 秒）。
2. 环境变化：
   - `SkyDirector` 的 `echo_blend` 在 2 秒内升到 1：环境光乘 0.75，饱和度乘 0.7；
   - 风声降低 8 分贝；
   - 播放这个回声的音乐片段（见 [声音与音乐](18-声音与音乐.md)）。
3. 人影淡入（1.5 秒），按脚本表演 10～18 秒，淡出（2 秒）。
4. 环境在 3 秒内恢复。
5. 旅行手记记录，存档。

玩家在播放中可以自由走动和转动视角，不锁定相机。走出半径 2 倍以外，回声提前淡出结束，但已经算看过。

### 数据

| 文件 | 内容 |
| --- | --- |
| `game/scripts/civilization/echo_system.gd` | `class_name EchoSystem extends Node3D`：管理全部回声的提示、触发、播放、存档 |
| `game/scripts/civilization/echo_scripts.gd` | 每个回声的表演脚本，静态常量字典 |
| `game/scripts/civilization/echo_figure.gd` | 人影节点：姿势、行走、淡入淡出 |

脚本格式：

```gdscript
# 坐标为锚点局部坐标：x 右，y 上，-z 前；时间单位秒
const PLAZA_EVENING: Dictionary = {
	"duration": 16.0,
	"music": "echo_daily",
	"actors": [
		{"pose": "sit", "path": [Vector3(-3, 0, -2)], "start": 0.0, "end": 16.0},
		{"pose": "child_run", "path": [Vector3(4, 0, 2), Vector3(-4, 0, 3), Vector3(-2, 0, -4), Vector3(4, 0, 2)], "start": 1.0, "end": 14.0},
	],
}
```

锚点的位置和朝向存在 `CivilizationData` 里。

## 三、晨的四个回声

脚本里的站位、动作都按下面的描述写。锚点朝向就是"观众"（玩家进入时大概站的方向）的反方向。

### 回声 1：日常（河畔古城广场）

- 时间感：傍晚。
- 环形纪念碑旁坐着三四个大人；两个孩子绕着环追跑；一个人从路口走来，把背上的包裹放下，坐到他们中间；一个大人抬手指向天空的某处，其他人跟着抬头。
- 16 秒。音乐：`echo_daily`，温暖、轻。
- 想传达：这里曾经是家；他们一直望着天上。

### 回声 2：信仰（神殿洞穴大厅）

- 一个人站在壁画墙前，伸手在墙上画一个大圆环，再画一条从地面通向圆环的直线。画到哪里，壁画上对应的 `glyph` 就亮到哪里，`awake` 跟随这个动作。
- 他身后六七个人跪着，面向天井的光。
- 最后所有人一起抬头看光。
- 15 秒。音乐：`echo_faith`，空灵。
- 想传达：他们相信星海有尽头。

### 回声 3：离开（天梯主门）

- 一队人背着包裹，从台阶走上来，缓缓走进主门，十几个人，间隔不一。
- 队伍最后有一个人停在门口，回头看了一眼来路，然后转身进去。
- 18 秒。音乐：`echo_departure`，长音、克制。
- 想传达：他们走了，带着不舍。

### 回声 4：守望者（塔链的最后一座烽火塔顶）

- 只在点亮最后一座塔之后触发。
- 一个人坐在火盆旁边，看着天梯的方向。天梯的光环自下而上一道接一道亮起，像有什么沿着它升上去（`SkyLadder` 的光环在这 15 秒内依次变亮，回声结束后恢复）。
- 最后他往火盆里添了一把火，火焰跳高了一下。
- 15 秒。音乐：`echo_watcher`，孤独、温柔。
- 想传达：有人留了下来，守着这些火，为了后来的人。

### 发现时

1. 屏幕下方中间淡入地点名称：字号 20，字间距加宽，白色略带暖色，3 秒后淡出。
2. 同时一声很轻的提示音（`discover.wav`）。
3. 1.5 秒后自动截图：隐藏 HUD 一帧，截主视口，缩小到 384 × 216，存为 `user://journal/<编号>.png`，然后恢复 HUD。
4. 地图和地球仪上该地点出现一个小琥珀点；回声地点出现一个小环形符号。

### 手记页面

- 暂停菜单新增「手记」按钮，打开一页。
- 这一阶段只有晨，不做星球标签。以后加星球时再在顶部加标签。
- 顶部是一排回声符号：晨的四个回声各一个圆环，没看过是空心细线，看过是实心琥珀色；终章回声的圆环在看过之后才出现。**不显示数字**。
- 下面是已发现地点的卡片网格，每行 3 张：截图加名称。**没发现的地点不显示占位**，避免变成清单。
- 点一张卡片：放大显示截图，下方一个「在地图上查看」按钮，打开地图并定位到该地点。

## 七、结局

> 2026-10-20 改为晨自己收尾。完整规格在 [规格 16 天梯](16-天梯.md) 第七节，这里只列和回声、手记有关的部分。

1. **条件**：晨的四个回声（日常、信仰、离开、守望者）都看过。
2. 条件满足后，天梯断口亮起呼吸的光斑；驾驶飞船降落在断口平台的停泊台。
3. **终章回声**在栈桥尽头：老年的守望者放下一盏灯，一串光点向「渊」升起，他坐下淡去。约 25 秒，音乐 `echo_ending`，使用新姿势 `old_walk`、`sit`。
4. 光之路、沿路飞行、字幕、恢复自由探索，见规格 16。
5. 终章回声的编号是 `dawn_ending`，看过后加入 `echoes_seen`；手记里第五个圆环出现并填满。

## 八、验收

### 自动检查

新建 `game/scripts/verify/echo_checks.gd`（可无界面）：

1. 每个回声脚本：时间在 `duration` 内，所有站位离锚点不超过 `radius`；在晨上的站位都落在地面或建筑上（高度检查，允许 0.3 米误差）。
2. 模拟玩家走进回声半径并静止 2 秒：回声开始；播放结束后 `echoes_seen` 包含它，存档往返保持。
3. 发现地点：模拟进入触发半径，`discovered` 增加，截图文件生成（有渲染器时）。
4. 结局条件：把晨的四个回声设为已看，天梯断口光斑出现；少任何一个都不出现。结尾流程的检查在规格 16 第八节。
