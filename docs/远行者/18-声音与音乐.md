# 规格 18：声音与音乐

## 一、原则

见 [世界观与美术圣经](01-世界观与美术圣经.md) 第七节。概括：

- 风是主角，音乐稀疏，大量安静的时间；
- 空间感靠混响和环境声的变化：洞里、遗迹里、塔顶、开阔地听起来要不一样；
- 不用人声、不用对白。

## 二、总线

现在所有声音都直接进 `Master`。改成：

```
Master
├─ World      环境声、脚步、各种 3D 声源；带一个混响效果（AudioEffectReverb）
├─ Music      音乐；不受混响影响
└─ Interface  手记、发现提示等界面声音
```

- 总线布局写进 `game/default_bus_layout.tres`，并在 `project.godot` 里指定。
- 总音量设置作用于 `Master`，音乐音量设置作用于 `Music`（现在是直接改播放器音量，改成改总线音量，播放器只管淡入淡出）。
- `World` 的混响参数由 `Soundscape` 按环境平滑调整（1 秒内过渡）：

  | 环境 | 房间大小 | 湿声 |
  | --- | --- | --- |
  | 野外 | 0.1 | 0 |
  | 遗迹室内（房屋内、主门内、观景环） | 0.45 | 0.15 |
  | 神殿大厅、洞穴 | 0.8 | 0.35 |

  "遗迹室内"用 `CivilizationSites` 提供的室内包围体判断。

## 四、音乐

### 情境

现在的做法是：在晨的地面附近，每 38 秒间隔播一次 `dawn_theme`。改为由新的 `MusicDirector`（`game/scripts/render/music_director.gd`，从 `Soundscape` 里拆出来）按情境选曲。

| 情境 | 条件 | 曲风 |
| --- | --- | --- |
| `dawn_day` | 晨，白天，晴或多云 | 舒缓、开阔 |
| `dawn_dusk` | 晨，太阳高度在 -0.1～0.15 | 温暖、略带感伤 |
| `night` | 任何星球的地面，夜里 | 稀疏、空灵 |
| `rain` | 晨，下雨 | 低沉、安静 |
| `cave` | 在洞里 | 几乎只有长音，或者干脆不放 |
| `space` | 离地高于大气层 | 宏大、缓慢 |
| `ending` | 结局沿光之路飞行和字幕 | 见规格 16 第七节 |

烬、霜的情境这一阶段不做。

回声的音乐片段（`echo_daily`、`echo_faith`、`echo_departure`、`echo_watcher`、`echo_ending`）是短曲，由 `EchoSystem` 直接请求播放。

### 规则

1. 一首曲子播完后，留一段安静：40～120 秒随机；夜里和雨天 60～150 秒。
2. 情境改变时不打断正在播的曲子，等它播完，下一首按新情境选。例外：
   - 进入洞穴，或离开大气层 → 当前曲子 4 秒淡出；
   - 回声开始 → 当前曲子 2 秒淡出，回声音乐播完后重新开始安静计时。
3. 同一情境有多首时随机选，但不连续重复同一首。
4. 每次开始播放用 3 秒淡入。

### 文件约定

- 位置：`game/audio/music/<情境>_<序号>.ogg`，例如 `dawn_day_1.ogg`、`night_2.ogg`、`echo_faith.ogg`。`MusicDirector` 启动时按文件名扫描。导出后的包里目录中是 `.ogg.import` 或 `.remap` 文件，扫描时要去掉这些后缀再识别，`packaged_asset_checks` 里加一项确认导出包能找到全部曲目。
- 格式：Ogg Vorbis，立体声，44.1 kHz，质量 6 左右。
- 响度：整首的平均响度大致统一。`Check-Audio.py` 增加检查：音乐文件的均方根电平落在 -26～-18 dBFS 之间，峰值不超过 -1 dBFS。
- 来源：`game/audio/music/来源.md` 写清每首的来源和授权。只放用户确认可以使用的曲目（目前这批只用于个人游玩，不商用、不公开分发）。
- 现有的 `dawn_theme.wav` 移动为 `game/audio/music/fallback/dawn_theme.wav`，只在 `dawn_day` 没有任何文件时使用，不参与正常轮播。同时更新 `tools/Generate-Music.py` 的输出路径，以及 `tools/Check-Audio.py` 里对它的引用；`soundscape.gd` 里的音乐播放由 `MusicDirector` 取代。
- 某个情境没有任何文件时，这个情境不放音乐，不报错。

接入代码要先完成，不依赖具体曲目。

### 曲目分配

用户提供了 27 首候选曲，原文件在仓库的 `refer/音乐/`（m4a）。用户确认这批音乐可以使用，只用于个人游玩、不商用；`来源.md` 里照此写明。

试听和响度分析后，分配如下：

| 情境 | 曲目（文件名不含扩展名） | 说明 |
| --- | --- | --- |
| `dawn_day` | 蓝天、树林晨光、清晨露水、溪流、松树、初春之梦、漫游、湖面、波光 | 晨白天的主力，数量最多 |
| `dawn_dusk` | 夕阳下的回忆、晚风、风和落叶 | |
| `night` | 静谧之夜、满天繁星、黑夜、星空下的畅谈 | |
| `rain` | 雷雨、雾霭 | |
| `cave` | 洞穴 | 只有一首，在洞里播完后安静时间加倍 |
| `space` | 巡航、倒影 | |
| `ending` | 倒影 | 和 `space` 共用，结局时从头播放 |
| 暂不使用 | 积雪、雪天、薄冰、雪漠 | 气质适合霜，以后再用 |
| 暂不使用 | 和好如初、路灯 | 偏城市、偏叙事，和晨的气质不太合，用户可以自己决定放进哪个情境 |

回声片段从整曲里截取（每段 15～25 秒，开头 1 秒淡入、结尾 3 秒淡出）：

| 片段 | 取自 | 选段要求 |
| --- | --- | --- |
| `echo_daily` | 初春之梦 | 旋律最温暖的一段 |
| `echo_faith` | 洞穴 | 最空灵、长音最多的一段 |
| `echo_departure` | 夕阳下的回忆 | 最克制的一段，避开高潮 |
| `echo_watcher` | 静谧之夜 | 最孤独的一段，最好只有一两件乐器 |
| `echo_ending` | 满天繁星 | 约 25 秒，配合终章回声的光点升起；选一个有明显"上升"感的乐句 |

选段由实现者试听后决定，记录里写明每段的起止时间。截取用的同一首曲子仍然可以作为整曲出现在情境里。

### 转换与响度

分析结果：原曲的整体响度在 -9～-17 LUFS 之间，峰值普遍到 0 dB，比本规格的范围（均方根 -26～-18 dBFS、峰值 ≤ -1 dBFS）响得多，而且曲与曲之间差 8 dB。直接放进去会盖过风声，而且忽大忽小。

转换步骤（写成 `tools/Convert-Music.py`，用 ffmpeg；ffmpeg 不在时报错退出，不要静默跳过）：

1. 每首用 `loudnorm` 两遍法统一到 -23 LUFS 左右，真峰值上限 -1.5 dBTP；
2. 转成 Ogg Vorbis，立体声，44.1 kHz，质量 6；
3. 按上面的表命名输出到 `game/audio/music/`（例如 `dawn_day_1.ogg`～`dawn_day_9.ogg`），回声片段按表截取后同样处理；
4. 生成 `来源.md`：每个输出文件对应的原文件名、截取区间、授权说明。

- 转换后的总大小预计 60～90 MB。打包体积会明显增加，在记录里写明。
- `refer/` 下的原文件不进打包，只作为来源保留。
- `Check-Audio.py` 的响度检查以转换后的文件为准。

## 五、验收

### 自动检查

1. `Check-Audio.py`：环境声清单与文件一致，循环接缝平滑；音乐文件的响度在范围内；`来源.md` 里列出了所有音乐文件。
2. 新建 `music_checks.gd`（可无界面）：
   - 模拟各种情境，`MusicDirector` 选出的情境正确；
   - 安静间隔在范围内；
   - 回声能打断音乐，结束后重新计时；
   - 音乐音量设为 0 时 `Music` 总线静音。
3. `completion_checks.gd` 里环境音播放器和循环的数量跟着更新。

### 人工确认

- 遗迹里的风声有没有"空"的感觉？
- 进洞时混响的变化自然吗？
- 音乐出现的频率合适吗？会不会太少或太多？
- 每首曲子分到的情境对不对？有没有哪首在某个场景里显得突兀？
- 回声片段和画面配不配？
