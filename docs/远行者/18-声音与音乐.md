# 规格 18：声音与音乐

## 一、原则

见 [世界观与美术圣经](01-世界观与美术圣经.md) 第七节。概括：

- 风是主角，音乐稀疏，大量安静的时间；
- 空间感靠混响和环境声的变化：洞里、遗迹里、塔顶、开阔地听起来要不一样；
- 不用人声、不用对白。

## 二、总线

现在所有声音都直接进 `Master`。改成：

```
Master
├─ World      环境声、脚步、各种 3D 声源；带一个混响效果（AudioEffectReverb）
├─ Music      音乐；不受混响影响
└─ Interface  手记、发现提示等界面声音
```

- 总线布局写进 `game/default_bus_layout.tres`，并在 `project.godot` 里指定。
- 总音量设置作用于 `Master`，音乐音量设置作用于 `Music`（现在是直接改播放器音量，改成改总线音量，播放器只管淡入淡出）。
- `World` 的混响参数由 `Soundscape` 按环境平滑调整（1 秒内过渡）：

  | 环境 | 房间大小 | 湿声 |
  | --- | --- | --- |
  | 野外 | 0.1 | 0 |
  | 遗迹室内（房屋内、主门内、观景环） | 0.45 | 0.15 |
  | 神殿大厅、洞穴 | 0.8 | 0.35 |

  "遗迹室内"用 `CivilizationSites` 提供的室内包围体判断。

## 三、新增环境声

都由 `tools/Generate-Audio.py` 生成，规则与现有的环境声相同：循环、交叠拼接、只用标准库。每加一个都要同步更新 `tools/Check-Audio.py` 的清单和数量。

| 文件 | 内容 | 在哪里响 |
| --- | --- | --- |
| `ruin_wind.wav` | 风穿过拱门和窗洞的空心低鸣，夹杂偶尔的细哨音 | 古城、天梯基座、神殿门口附近，音量随距离和风力变化 |
| `high_wind.wav` | 高处更强更连贯的风 | 烽火塔顶、观景环、山顶，按离地高度和是否在高点混入 |
| `cave_drip.wav` | 稀疏、随机间隔的滴水，带空间感 | 洞里 |
| `night_insects.wav` | 很轻的虫鸣 | 夜里的草甸、湿地 |
| `waterfall.wav` | 瀑布 | 3D 声源，见规格 11 |
| `spring.wav` | 温泉咕嘟声 | 3D 声源，见规格 11 |
| `engine.wav`、`ship_land.wav`、`ship_hatch.wav` | 飞船 | 见规格 10 |
| `beacon_ignite.wav` | 火焰腾起的呼声加一个温暖的长音 | 点亮烽火塔 |
| `lift_start.wav`、`lift_hum.wav` | 升降台启动和运行 | 见规格 16 |
| `discover.wav` | 极轻的一声铃音，带长尾音 | 发现新地点（`Interface` 总线） |

## 四、音乐

### 情境

现在的做法是：在晨的地面附近，每 38 秒间隔播一次 `dawn_theme`。改为由新的 `MusicDirector`（`game/scripts/render/music_director.gd`，从 `Soundscape` 里拆出来）按情境选曲。

| 情境 | 条件 | 曲风 |
| --- | --- | --- |
| `dawn_day` | 晨，白天，晴或多云 | 舒缓、开阔 |
| `dawn_dusk` | 晨，太阳高度在 -0.1～0.15 | 温暖、略带感伤 |
| `night` | 任何星球的地面，夜里 | 稀疏、空灵 |
| `rain` | 晨，下雨 | 低沉、安静 |
| `cave` | 在洞里 | 几乎只有长音，或者干脆不放 |
| `space` | 离地高于大气层 | 宏大、缓慢 |
| `ember`、`frost` | 烬、霜的地面，白天 | 各自的气质，见规格 19 |
| `ending` | 结局 | 见规格 17 |

回声的音乐片段（`echo_daily`、`echo_faith`、`echo_departure`、`echo_watcher`、`echo_ending`，以及烬、霜的回声）是短曲，由 `EchoSystem` 直接请求播放。

### 规则

1. 一首曲子播完后，留一段安静：40～120 秒随机；夜里和雨天 60～150 秒。
2. 情境改变时不打断正在播的曲子，等它播完，下一首按新情境选。例外：
   - 进入洞穴，或离开大气层 → 当前曲子 4 秒淡出；
   - 回声开始 → 当前曲子 2 秒淡出，回声音乐播完后重新开始安静计时。
3. 同一情境有多首时随机选，但不连续重复同一首。
4. 每次开始播放用 3 秒淡入。

### 文件约定

- 位置：`game/audio/music/<情境>_<序号>.ogg`，例如 `dawn_day_1.ogg`、`night_2.ogg`、`echo_faith.ogg`。`MusicDirector` 启动时按文件名扫描。
- 格式：Ogg Vorbis，立体声，44.1 kHz，质量 6 左右。
- 响度：整首的平均响度大致统一。`Check-Audio.py` 增加检查：音乐文件的均方根电平落在 -26～-18 dBFS 之间，峰值不超过 -1 dBFS。
- 来源：`game/audio/music/来源.md` 写清每首的作者和授权。没有明确授权允许打包分发的不能放进来。
- 现有的 `dawn_theme.wav` 改名并移动为 `game/audio/music/dawn_day_1.wav`，作为没有其他曲子时的默认。同时更新 `tools/Generate-Music.py` 的输出路径，以及 `tools/Check-Audio.py` 里对它的引用；`soundscape.gd` 里的音乐播放由 `MusicDirector` 取代。
- 某个情境没有任何文件时，这个情境不放音乐，不报错。

用户手里有一批候选音乐，会在本机自己放进上面的目录。接入代码要先完成，不依赖具体曲目。

## 五、验收

### 自动检查

1. `Check-Audio.py`：环境声清单与文件一致，循环接缝平滑；音乐文件的响度在范围内；`来源.md` 里列出了所有音乐文件。
2. 新建 `music_checks.gd`（可无界面）：
   - 模拟各种情境，`MusicDirector` 选出的情境正确；
   - 安静间隔在范围内；
   - 回声能打断音乐，结束后重新计时；
   - 音乐音量设为 0 时 `Music` 总线静音。
3. `completion_checks.gd` 里环境音播放器和循环的数量跟着更新。

### 人工确认

- 遗迹里的风声有没有"空"的感觉？
- 进洞时混响的变化自然吗？
- 音乐出现的频率合适吗？会不会太少或太多？
