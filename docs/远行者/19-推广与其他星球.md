# 规格 19：推广与其他星球（概要）

本文是第一个文明区完成之后的方向。每一项在开工前都要再写一份详细规格，本文只定内容和规则，保证整体故事和氛围的一致。

## 一、晨的推广

河畔古城跑通以后，按同样的规则在晨上再放更多文明区。全部在烘焙时生成。

| 内容 | 数量 | 规则 |
| --- | --- | --- |
| 聚落 | 共 6～8 个 | 都在汇水面积 40 平方公里以上的河边；互相之间至少 6 公里。规模分三档：一个大城（四圈台地），两三个镇（三圈），其余是村（两圈，没有广场雕像） |
| 道路网 | 连通所有聚落 | 先连最近的两两，再补成连通图（最小生成树加两三条额外的边） |
| 烽火塔网 | 每个聚落附近一座 | 所有塔最终都能沿视线连到天梯；第一条塔链之外的塔点亮后也会回应相邻的塔 |
| 神殿洞穴 | 只有河畔古城那一座 | 回声只有四个，不增加 |
| 天然洞穴 | 10～15 个 | 晶石洞、地下湖洞、带瀑布的洞 |
| 墓园 | 每个大城和镇一个 | 都面向天梯 |
| 其他遗迹 | 散布在路边和野外 | 孤立的门、倒下的雕像、桥的残段、水渠、界碑。按"每步行五到十分钟遇到一样东西"的节奏放，而不是平均撒 |

### 节奏检查

烘焙后，沿道路网每 400 米取一个点，统计 600 米内有没有任何遗迹或地貌特征。没有的点连续超过 3 个（约 1.2 公里），就在中间补一个小遗迹。

## 二、烬：熔炉

- **气质**：炎热、荒芜、被耗尽。赤红色沙丘和台地，巨大的人工伤痕。
- **巨构：倒下的巨像。** 一尊远行者雕像，原本高约 300 米，倒在沙丘上，身体断成几截，头部半埋在沙里，兜帽朝天，手里的环滚落在一旁，像一座拱桥。可以爬上它的背。
- **遗迹**：
  - 阶梯状的露天采石坑，直径 1～2 公里；
  - 运石的高架轨道残段；
  - 冶炼台，有烧黑的熔炉；
  - 工人的简陋棚屋群，和晨精致的房屋形成对比。
- **地貌**：沙丘已有；新增风蚀石柱、干涸河床（烘焙水系后，把河道画成干河床，没有水）、盐滩。
- **天气**：沙暴。能见度降到几百米，天空变成橙褐色，沙粒横飞（复用雨丝的做法，换颜色和方向）。
- **回声**：3 个，见规格 17。
- **音乐**：`ember`，更干、更低，带一点金属的回响。

## 三、霜：记忆

- **气质**：冰冷、凝固、封存，像时间停止。
- **巨构：冰中方舟。** 一艘长约 1.2 公里的远行者方舟，一半埋在冰川里，船首翘出冰面指向天空。可以从冰裂缝走进船舱。
- **遗迹**：
  - 冰原上的观测站；
  - 被冰封的码头和起重架；
  - 一排排插在雪里的标杆，通向方舟。
- **地貌**：冰川（新的地形特征，平滑的冰面加冰裂缝）、冰洞（复用洞穴系统，换成冰材质，半透明的蓝色）、冰湖。
- **天气**：降雪，复用雨丝的做法换成飘落的雪片。极光比晨上更常见、更强。
- **回声**：3 个，见规格 17。
- **音乐**：`frost`，清冷、透明，大量留白。

## 四、渊环：终点

- 气态巨星「渊」外的一段环形空间站残骸，大部分已经断裂，只剩一段弧形结构在轨道上。
- 结构用和天梯同样的材质语言：浅石色外壳、古铜环箍、琥珀光纹。
- 有一处平坦的终章平台，可以降落、步行。平台尽头面向远离渊的深空。
- 结局流程见规格 17 第七节。
- 渊环上的平台是太空中唯一可以下船步行的地方。这里有一点点人造重力的设定，探索者可以正常行走，不需要另外解释。

## 五、顺序建议

1. 晨的推广（聚落、道路网、塔网、天然洞穴）。
2. 渊环与结局。先做，让故事能闭合；这时烬和霜的回声可以暂时不作为结局条件。
3. 烬。
4. 霜。
5. 把结局条件恢复为全部十个回声。
