# 规格 21：主山脉与大峡谷

## 一、目标

现在晨的最高峰约 2.3 公里，起伏的"性格"比较单一。这一份要给晨加上两样真正有史诗感的地形：

1. **主山脉**：一条横贯大陆的山脉，最高峰 3.5～4 公里，有刀脊、悬崖、雪峰、冰川谷和几座轮廓特别的名峰。中间有两三处山口，是翻越山脉的路。
2. **大峡谷**：一条长 20～30 公里、深 700～1000 米的峡谷，岩壁是一层一层的台阶状岩层，谷底有河。

站在出发地，主山脉应该占据一大片天际线；走到大峡谷边，应该有"大地裂开"的震撼。

## 二、总体做法

### 作为特征叠加，不改基础地形

主山脉和大峡谷都和火山一样，作为**地形特征**叠加在 `base_height()` 之上，**在水系烘焙之前**计算：

> 基础地形 → **主山脉** → **大峡谷** → 火山 → 河道 → 文明区 → 洞穴开洞

这样做的原因：

- 出发地仍由 `base_height()` 选定，已经存在 `dawn_layout.tres` 里，不会因为山脉而移动。
- 水系烘焙会自动让河流沿新的山谷和峡谷流，不需要另外设计河道。
- 所有使用高度函数的系统（地形、碰撞、地图、植被、飞行保护）自动得到新地形。

### 布局数据

山脉的脊线、名峰、山口，峡谷的路线，都由布局工具生成一次，存进 `dawn_layout.tres`（和出发地、火山、地标放在一起），之后每次运行直接读取。布局工具重新运行的结果必须完全一样（固定种子）。

## 三、主山脉

### 脊线

1. **位置**：脊线是球面上的一条折线，总长 60～80 公里，经过第一阶段的远山山峰（`site["mountain_direction"]`）附近 1.5 公里内，让那座山成为主山脉的一部分。
2. **走向**：与出发地朝远山的视线大致垂直（夹角 60°～120°），这样从出发地看去，山脉横在前方。
3. **距离**：脊线离出发地最近处 6～10 公里。
4. **形状**：
   - 折线由 8～12 个控制点组成，相邻控制点之间切角平滑；
   - 再加一点横向扰动（振幅 1.5 公里，波长 15～25 公里），不要是一条直线。
5. **陆地**：脊线全程都要在陆地上，离海岸至少 4 公里。不满足就调整走向重试。

### 断面

对地面上任意一点，取它到脊线的最近距离 `d` 和沿脊线的位置 `s`：

- **山体包络**：`envelope = H(s) * (1 - smoothstep(0, W(s), d))^1.6`。
  - `H(s)` 是沿脊线变化的加高量：1400～2200 米，名峰处更高，山口处降到 400～600 米；
  - `W(s)` 是半宽：7～10 公里。
- **刀脊**：用一个新的脊状噪声（`FRACTAL_RIDGED`，频率 1/2600，4 层）乘以包络，越靠近脊线权重越大。这样山顶是锋利的脊线，而不是圆包。
- **悬崖带**：在 `_geology` 噪声大于 0.62 的区域，对山体加高部分做阶梯量化：每级 60～120 米，级与级之间在 15 米内陡升，形成一段段竖直的岩壁。悬崖带只在海拔 900 米以上出现。
- 加高量叠加到基础地形上：`h = base + envelope_with_ridges`。

### 名峰

在脊线上选 3 座名峰，各有不同的轮廓，从远处一眼就能认出：

| 名峰 | 形状 | 做法 |
| --- | --- | --- |
| 角峰 | 金字塔形的尖峰，三四面陡壁 | 以峰顶为中心，用"到几个方向平面的最大距离"代替圆形距离，得到棱角分明的锥体；高 3.8～4.0 公里 |
| 双子峰 | 两座并立的尖峰，中间一道深 V 形缺口 | 两个尖锥相距 900 米，中间压低 400 米 |
| 平顶峰 | 四壁陡峭、顶部平坦的桌状山 | 顶部 600 米范围内平整，四周 30 米内陡降成悬崖 |

第一阶段的山顶石塔（之后的烽火塔）放在离出发地最近的山口旁的次峰上：海拔不超过鞍部加 400 米，从出发地看得到。不放在 3.5 公里以上的名峰上，玩家要爬上去点亮它。

### 山口

- 脊线上选 2～3 处山口，彼此相距 15 公里以上；其中一处离出发地方向最近。
- 山口处的加高量降到 400～600 米，鞍部宽 1.5 公里，两侧坡度控制在 0.35 以内，保证能走过去。
- 山口是重要的路线：古道、烽火塔链和晶洞网（规格 15）都会利用山口。

### 冰川谷

- 第一阶段已经有"高处沟谷展宽成 U 形"的规则，这里沿用。
- 在海拔 2200 米以上、坡度小于 0.3 的谷底，地表标记为冰川（见第五节），着色为冰面。

## 四、大峡谷

### 路线

1. **位置**：离出发地 10～25 公里，与主山脉不在同一方向（两者方位相差 60° 以上），从出发地附近的高处（例如烽火塔顶）能看到峡谷的边缘。
2. **地势**：所经之处的基础海拔 300～900 米的高原。
3. **出口**：峡谷的一端通向海或大湖，另一端在高原上逐渐变浅消失。谷底从源头到出口单调下降，这样水系烘焙会让河流沿谷底流出去。
4. **形状**：长 20～30 公里，用 10～14 个控制点的折线表示，切角平滑；加大幅度的蜿蜒（振幅 1～2 公里，波长 4～7 公里），形成几个大的拐弯。

### 断面

- **深度**：`D(s)` 在源头附近从 0 逐渐增加到 700～1000 米，靠近出口时略减。
- **宽度**：顶部全宽 1.5～3 公里，谷底宽 150～300 米。
- **阶梯状岩壁**：
  1. 从谷底到顶部分成 8～14 级岩层，每级高 40～100 米（随机，但同一高度的岩层沿峡谷连续）；
  2. 每级由一段陡壁（坡度大于 2，接近竖直）加一段平台（宽 30～120 米）组成；
  3. 两侧岩壁的平台宽度不同，一侧更陡，一侧更缓，形成不对称的峡谷。
- **谷底**：平坦，水系烘焙后会有一条河。

### 峡谷里的东西

- 3～5 座天然石拱和一片石柱群（拱跨 40～80 米，柱高 30～60 米）。用 Blender 建模（建模方法按[规格 12](12-遗迹构件与模型规范.md) 第二节），不用 `LandmarkMeshes` 里代码拼的拱和柱：体素重建网格、噪声位移、和峡谷岩壁一致的水平层理（顶点色），顶部草皮。做 2～3 种拱、6～8 种柱，缩放旋转后复用；第 16 步重做海蚀柱和出发地石拱时复用这套做法。
- 一处岩壁上的洞口，通向地下河洞网（规格 15）。
- 一条远行者开凿在岩壁上的栈道：沿某一级平台延伸约 2 公里，用遗迹构件（矮墙、台阶、残破的桥段）拼成，中间一处断开要靠攀爬（规格 22）。
- 峡谷边缘的一处观景台：三根柱子和一块石碑，面向峡谷最壮观的一段。

## 五、地表标记

现有地形顶点色的四个通道都已经用完（高度、坡度、湿度、林地）。新增一个顶点属性，用来告诉地形着色器"这里是什么特殊地表"：

- 在 `TerrainChunkBuilder.build()` 里填 `Mesh.ARRAY_CUSTOM0`（格式 `ARRAY_CUSTOM_RGBA8_UNORM`），数据来自新函数 `TerrainFeatures.surface_marks(direction) -> Color`：

  | 通道 | 含义 |
  | --- | --- |
  | R | 峡谷岩壁强度（0～1），用于层状岩色 |
  | G | 冰川（0～1） |
  | B | 预留给道路、遗迹地面（规格 13 可以改用这里，不再单独画路面网格；由实现时决定，在记录里说明） |
  | A | 预留 |

- 地形着色器读 `CUSTOM0`：
  - **峡谷岩壁**：陡坡处混入层状岩色。岩色按 `v_height` 分成红褐 `#A65A3C`、赭黄 `#C99A5B`、灰白 `#D8CDB8` 三色交替的色带，每条色带 15～40 米，带内用噪声做轻微的不均匀。
  - **冰川**：冰蓝白 `#CFE6EE`，带几条平行于谷向的浅色裂纹（用沿坡向拉长的噪声）。
- 远处的地形块也要有地表标记，这样从高处看峡谷就能看到色带。

## 六、需要跟着改的地方

| 位置 | 改动 |
| --- | --- |
| `TerrainNoise.MAX_HEIGHT` | 从 2600 改为 4300。它被用在顶点色的高度归一化、`FlightSafety` 的包围球和地图上，改完逐个确认 |
| 地图与地球仪的配色 | `terrain_map.gdshader` 和 `globe.gdshader` 的 `altitude_color` 延伸到 4000 米：2400 米以上从灰白过渡到冰白；图例增加 3200 米一档 |
| 雪线 | 晨的雪线保持在约 1600 米。高山会有大片雪，这是想要的 |
| `SurfaceSites` | 依赖地貌搜索的机位（`s10_highland`、`s16_terrace`、`s17_valley` 等）重新确认；`find_biome` 找到的点不要落进峡谷岩壁 |
| 第一阶段地标 | 海蚀柱、拱门、灯塔、巨环位置不变，但要确认没有被山体或峡谷覆盖；山顶石塔按第三节移到名峰 |
| 水系 | 重新烘焙；`hydrology_checks` 的期望值随之更新，在记录里写明新旧数字 |
| 群系 | 高山上的群系分布会变（更多高山苔原和雪原），`ecology_checks` 的抽样数字会变，只要每种群系仍然存在即可 |
| 性能 | 远处能看到更多高大的山体，地形块数量可能增加。`s2_high`、`s10_highland` 和新机位重点看 |

## 七、验收

### 自动检查

新建 `game/scripts/verify/landform_checks.gd`（可无界面）：

1. **最高峰**：晨的最高点在 3.5～4.2 公里之间，位于主山脉上。
2. **出发地**：位置不变，`spawn_clear` 仍然通过；离脊线 6～10 公里；从出发地能看到至少一座名峰（视线检查）。
3. **山口可通行**：
   - 在每个山口两侧各取一个点，在 20 米格网上做寻路，最大坡度限制 0.45；
   - 至少两个山口能走通；
   - 写入路线长度。
4. **大峡谷**：
   - 最大深度 700～1000 米；
   - 谷底单调下降；
   - 水系烘焙后谷底有河，并通到海或湖；
   - 岩壁平台的数量统计。
5. **地表标记**：峡谷岩壁和冰川的顶点在 `CUSTOM0` 上有值；普通地面为零。
6. **高度查询耗时**：沿用 `hydrology_checks` 的测法，平均仍不超过 6 微秒。

### 人工确认

- 从出发地看主山脉，有没有"高山"的压迫感？会不会太高，显得不像一个 40 公里半径的星球？
- 站在峡谷边，想不想下去？
- 翻越山口的那段路好不好走、有没有成就感？
