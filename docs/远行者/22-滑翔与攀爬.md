# 规格 22：滑翔与攀爬

## 一、目标

有了主山脉、大峡谷和洞穴网络以后，只会走和跳就不够了：爬上去很累，下来只能绕路。这一份加两种移动：

1. **滑翔**：从高处跳下，展开围巾滑翔。从烽火塔顶、山口、峡谷边缘滑下去，是"史诗感"最直接的来源。
2. **简单攀爬**：只能爬**明确标出来的地方**：藤蔓墙、绳索和绳梯、远行者在崖面上凿的攀爬路线。不能爬任意岩壁。

两者都没有体力条、没有失败惩罚。这个游戏不考验操作，移动只是为了让人走到想去的地方、看到想看的风景。

### 为什么不做"任意岩壁攀爬"

- 任意攀爬会让山口、栈道、塔的外挂石阶这些"路"失去意义，远行者留下的路是文明感的一部分。
- 地形是高度场加洞穴网格，任意攀爬要在两种碰撞上都做贴合，手感很难调好。
- 限定在标出的地方，就可以在关键位置（峡谷栈道的断口、洞穴竖井、天井）设计路线。

## 二、滑翔

### 进入

同时满足以下条件时，在空中**再按一次跳跃键**展开：

- 步行模式（`Mode.WALK`），不在洞穴里（`cave_at() == -1`；第 6 步时洞穴还没做，先用一个总是返回 -1 的占位函数，第 9a 步换成真的）；
- 离开地面已经 0.35 秒以上；
- 脚下离地 4 米以上（向下射线检测地形和遗迹碰撞，长度 4 米，没碰到才算）。

从地面起跳后马上按第二次不会展开，需要等 0.35 秒，避免和普通跳跃冲突。

### 运动

| 量 | 值 | 说明 |
| --- | --- | --- |
| 水平速度 | 9 m/s | 按住前进时；松开前进时减到 5 m/s |
| 转向 | 跟随视角，每秒最多转 90° | 不做翻滚 |
| 下落速度 | 稳定在 2.5 m/s | 展开后 0.6 秒内从当前下落速度过渡到 2.5 |
| 滑翔比 | 约 3.6 : 1 | 从 300 米高的山口能滑出 1 公里左右 |
| 后退键 | 减速到 3 m/s，下落仍是 2.5 | 用来"悬停"看风景 |

水平方向是相对星球表面的切平面，下落方向是当地的"下"（朝星球中心）。不使用飞船的飞行代码。

### 上升气流

在几类地方，风会把人往上托：

| 位置 | 判定 | 抬升 |
| --- | --- | --- |
| 山脊 | 主山脉脊线 600 米内，且离地不超过 150 米 | 上升 4 m/s |
| 峡谷边缘 | 峡谷顶边 150 米内，且在峡谷上空 | 上升 4 m/s |
| 烽火塔顶 | 塔中心 25 米内，塔顶以上 60 米内 | 上升 3 m/s |
| 火山口 | 火山口半径内，火山口以上 200 米内 | 上升 5 m/s（热气） |

- 抬升随离地高度线性衰减：离地 0 米时最强，到上限时为 0。这样上升气流不能把人送上无限高。
- 抬升是加在下落速度上的：下落 2.5、抬升 4，净上升 1.5 m/s。
- 上升气流的位置由 `TerrainFeatures` 提供查询（`updraft_at(direction, altitude) -> float`），数据来自布局（山脉脊线、峡谷路线、塔链、火山）。
- 可见：上升气流区域里有少量向上飘的细小光尘和草叶粒子，只在玩家 200 米内、滑翔或站在边缘时生成，粒子数不超过 120。

### 结束

- 碰到地面或遗迹：落地，回到步行。落地速度大于 6 m/s 时播放一个"踉跄"动作（0.4 秒内移动速度减半），不扣任何东西。
- 再按一次跳跃键：收起，按普通下落继续掉。
- 进入水面：收起，按普通入水处理。
- 进入洞穴范围：收起。

没有摔伤，任何高度掉下来都只是踉跄。

### 围巾变成滑翔翼

探索者已有一条随风飘的围巾。滑翔时：

1. 0.3 秒内，围巾从脖子两侧向后展开成一面三角形的软翼：翼展 2.6 米，探索者双手拉着两端。
2. 软翼是 Blender 里建好的布面模型（见下面"探索者模型"），由骨骼控制展开和收起，有自然的布褶和兜风的弧度；颜色同围巾（`scarf` 色）。滑翔时布面随风轻微起伏（顶点着色器，幅度 3 厘米）。
3. 探索者身体前倾 30°，双腿略微后收（`glide` 动画）。
4. 收起时 0.25 秒内反向收回成围巾。

第一人称时：视野边缘能看到两角软翼的布边轻轻抖动（用软翼模型本身的布边部分，挂在相机下，同一个 glb），不挡视线。

### 声音

- 展开：布料抖开的"噗"声（`glide_open.wav`）。
- 滑翔时：风声循环（复用 `high_wind.wav`，音量随速度），软翼的布料抖动声混在里面。
- 进入上升气流：风声音调升高一点（`pitch_scale` 1.0 → 1.08）。

## 三、攀爬

### 可攀爬的东西

只有以下三种，都是由代码明确放置的：

| 种类 | 外形 | 用在哪里 |
| --- | --- | --- |
| `vine_wall` | 贴墙的一整片藤蔓，宽 2～4 米，高 4～15 米 | 遗迹墙面、峡谷栈道的断口、神殿洞穴附近的崖面 |
| `rope` | 一根垂下的粗绳，绳头系在铜环或石桩上 | 洞穴竖井、天井、塔外 |
| `climb_route` | 崖面上一列凿出的浅脚窝和铜钉，带一点光纹 | 峡谷岩壁、山脉的悬崖带 |

每一处攀爬点都由一个**攀爬区**描述：

| 字段 | 内容 |
| --- | --- |
| `kind` | 上面三种之一 |
| `bottom`、`top` | 底端和顶端的位置（相对星球中心） |
| `width` | 宽度；绳子是 0.6 |
| `normal` | 朝外的方向（攀爬时人面朝 `-normal`） |
| `exit_top` | 顶端翻上去之后站立的位置 |

### 进入

- 步行或滑翔时，朝攀爬区移动并碰到它（距离攀爬面 0.6 米内，且面向攀爬面，夹角小于 50°）就自动抓住。
- 从上面往下：站在 `exit_top` 附近、背对攀爬面后退，就会转身抓住顶端往下爬。
- 显示一次性提示"W/S 攀爬　空格 跳离"，看过就不再出现（存在设置里）。

### 运动

| 操作 | 效果 |
| --- | --- |
| 前进 / 后退 | 向上 / 向下爬，1.6 m/s；绳子 1.3 m/s |
| 左 / 右 | 在藤蔓墙和攀爬路线上横移，1.0 m/s；绳子上不能横移 |
| 空格 | 跳离：沿 `normal` 方向向外弹出 2 m/s，向上 3 m/s，随后可以展开滑翔 |
| 到达底端时继续后退 | 落地，回到步行 |
| 到达顶端 | 自动翻上去：0.6 秒内沿一条弧线移到 `exit_top`，期间不能操作 |

- 没有体力，可以一直挂着。
- 攀爬时角色不受重力，位置被约束在攀爬面前方 0.45 米的平面（绳子是一条线）上，用 `move_and_collide` 处理和其他碰撞的接触。
- 第三人称相机在攀爬时自动后拉到 4.5 米、略微偏到一侧，让人能看到自己和上方的路。

### 外形

- `vine_wall`：在 [构件修订](23-构件修订.md) 里重做的贴墙藤蔓的加密版本：主藤是贴墙的条带，横向有分叉，叶片成簇；有一层略微凸出的粗藤让人"看得出来能抓"。
- 三种外形都用 Blender 建模（建模方法按[规格 12](12-遗迹构件与模型规范.md) 第二节）：绳子用曲线加倒角和扭转，藤蔓墙用规格 23 第六节的 `vine_wall`，脚窝和铜钉是小模型。
- `rope`：直径 8 厘米的扭绳，每 1.2 米一个绳结；上端系在铜环（`patina`）或石桩上。按风很轻地摆，幅度在底端最大 0.3 米；有人攀爬时停止摆动。
- `climb_route`：每 0.5 米一对浅脚窝，左右交错；每 2 米一颗铜钉，钉头有一点微亮的光纹（`awake` 0.25），从 30 米外就能看出"这里有一条路"。

### 动作

探索者需要三个新姿态：

| 姿态 | 说明 |
| --- | --- |
| `climb` | 面向墙，双臂交替上伸，双腿交替上蹬，周期随速度 |
| `climb_rope` | 双手上下握绳，双腿夹绳 |
| `mantle` | 翻上顶端：双臂撑起，一条腿跨上 |

### 探索者模型（本步一起重做）

现在的探索者（`explorer_avatar.gd`）是用胶囊、圆环、椭球在代码里拼起来的，动作靠节点变换摆臂摆腿。按 [规格 12](12-遗迹构件与模型规范.md) 第二节的原则（人和东西要用真正的建模工具做），这一步把探索者换成 Blender 建的骨骼模型：

- **造型**：保持现有的配色和气质（浅灰绿的衣服、深色护具、浅色细节、红褐色围巾、青色面罩），身高 1.75 米。用蒙皮修改器和细分曲面做身体，衣服用布料模拟或实体化做出厚度和褶子；面罩、背包、腰间的提灯（规格 15）是单独的小模型。整体比远行者矮、更结实，一眼能区分"来访者"和"远行者"。
- **骨架**：标准人形骨架，另加围巾骨骼链（6～8 节）和软翼骨骼。围巾仍然随风飘：骨骼链的摆动沿用现在 `_pose_scarf` 的思路，在代码里驱动骨骼旋转，而不是驱动拼起来的分段。
- **动画**：全部在 Blender 里做成关键帧动画，导出到同一个 glb：`idle`、`walk`、`run`、`jump`、`fall`、`land_stumble`、`glide`、`climb`、`climb_rope`、`mantle`。Godot 里用 `AnimationTree` 按速度和模式混合。
- **文件**：`art/blender/build_explorer.py` → `game/models/explorer/explorer.glb`。`explorer_avatar.gd` 改为加载这个模型、驱动动画和围巾骨骼，删掉代码拼的几何体。
- **面数**：≤ 8000（只有一个，第三人称近看）。
- 第一人称看不到身体，只看到滑翔时的软翼布边，不受影响。

## 四、实现

### 文件

| 文件 | 内容 |
| --- | --- |
| `game/scripts/player/player_traversal.gd` | `class_name PlayerTraversal extends RefCounted`：滑翔与攀爬的状态和运动计算，`player.gd` 调用它，避免 `player.gd` 继续膨胀 |
| `game/scripts/civilization/climb_zones.gd` | `class_name ClimbZones extends Node3D`：读攀爬区数据，在玩家 300 米内生成外形网格和 `Area3D`，提供 `zone_near(position) -> Dictionary` |
| `game/shaders/glider.gdshader` | 软翼布面的轻微起伏 |
| `art/blender/build_explorer.py`、`game/models/explorer/explorer.glb` | 探索者模型、骨架和全部动画 |

### 玩家模式

`StarSeaPlayer.Mode` 增加 `CLIMB` 和 `GLIDE`，追加在已有值之后（`WALK = 0`、`FLY = 1` 不变）：

- 所有现在判断 `mode == Mode.WALK` 的地方都要逐个确认，在 `CLIMB`、`GLIDE` 时应该怎样：
  - 登船、召唤飞船：只在 `WALK` 且站在地上时可以；
  - 第三人称时显示探索者：`WALK`、`CLIMB`、`GLIDE` 都显示；
  - 贴地对齐（`_align_to_up`）：三种都照常；
  - `_waiting_for_ground`：只在 `WALK`。
- 地图、小地图、高度显示不受影响。

### 存档

- `journey.mode` 只会写 `0` 或 `1`。在攀爬或滑翔时存档：模式写成 `WALK`，位置写成最近一次**站在地上**的位置。
- 读取时，`mode` 是 2 或 3 的存档按非法处理（和现在一样整份拒绝）。
- 不新增存档字段。

### 攀爬区的来源

| 来源 | 什么时候生成 | 位置 |
| --- | --- | --- |
| 峡谷栈道的断口 | 第 5 步（主山脉与大峡谷）之后，在本步加上 | 规格 21 第四节 |
| 峡谷岩壁的攀爬路线 | 本步 | 从谷底到观景台下方的一级平台，一条 120～200 米的分段路线，中间有两处可以站的平台 |
| 洞穴的绳索和竖井 | 第 9a 步（回声洞天井）、第 9b 步（青晶洞竖井、暗河洞） | 规格 15 |
| 古城和天梯基座附近的藤蔓墙 | 第 7、10 步 | 规格 13、16 |
| 烽火塔外 | 第 8 步 | 塔外挂石阶残缺超过 1.2 米的地方，改为挂一根绳子，代替"必须跳过去" |

攀爬区数据和其他布局一起存在 `dawn_layout.tres` 或 `CivilizationData` 里，按来源各自生成；`ClimbZones` 只负责读取和显示。

本步先做好系统，并放三处**测试攀爬区**：出发地附近的第一阶段拱门遗迹上一片藤蔓墙；山顶石塔外一根绳子；峡谷岩壁一条攀爬路线（第 5 步已完成峡谷时）。

## 五、验收

### 自动检查

新建 `game/scripts/verify/traversal_checks.gd`（可无界面）：

1. **滑翔展开条件**：在平地上起跳后 0.2 秒按跳跃，不展开；从 30 米高处跳下 0.5 秒后按跳跃，展开。
2. **滑翔比**：从 300 米高处、无上升气流的平地上方滑翔到落地，水平距离在 900～1200 米之间。
3. **上升气流**：在山脊上升气流区内滑翔 20 秒，离地高度不超过 150 米；离开区域后开始下降。
4. **落地**：从 200 米高处直接掉下（不滑翔），落地后回到 `WALK`，没有任何扣减，踉跄结束后能正常移动。
5. **攀爬**：在测试藤蔓墙底端，模拟按住前进，到达顶端后自动翻上，最终站在 `exit_top` 0.5 米内，`is_on_floor()` 为真。
6. **跳离**：攀爬到一半按空格，离开攀爬面，0.5 秒后再按跳跃能展开滑翔。
7. **存档**：滑翔中存档，读档后在最近站过的地面位置，`mode == WALK`。
8. **洞穴里**：模拟在洞内范围按两次跳跃，不展开。第 6 步没有洞穴，这一条记为"未运行，依赖第 9a 步"，在第 9a 步启用。

### 人工确认

- 从高处跳下展开滑翔，有没有"飞起来"的快感？下落会不会太快或太慢？
- 上升气流能不能察觉到？会不会被它"拖着走"？
- 攀爬时操作直不直观？会不会卡在攀爬面边缘？
- 滑翔会不会让人不想走路了？如果会，把滑翔比调低到 3:1。
