# 规格 23：构件修订

## 一、为什么修订

第 3 步交付的构件库工程上是扎实的：72 个模型、两条制作路线一致、碰撞和面数都在预算内，`ruin_kit_checks` 全部通过。但对照 `s29_ruin_kit` 的总览和逐件展示，有几类构件的**外形**还达不到 [世界观与美术圣经](01-世界观与美术圣经.md) 的要求。之后的古城、塔链、洞穴、天梯都会大量用到这些构件，所以在继续之前先改好。

问题集中在一点：**很多构件还是"基本几何体的堆叠"**，方盒子、圆柱、球拼起来，轮廓太规整，看不出手工凿刻和时间侵蚀。

本规格只改外形，不改名称、尺寸、原点、朝向、碰撞的约定（[规格 12](12-遗迹构件与模型规范.md) 第二节），也不改 `RuinKit`、`RuinBuilder` 的接口。

## 二、逐项修订（第一轮，已完成）

### 1. 远行者雕像与回声人影

**现状**：一个圆台当长袍、一个球当头、两块方盒当手臂、一个铜色扁球当"脸部阴影"。远看像一个保龄球瓶，近看像积木。

**要求**：

| 部位 | 做法 |
| --- | --- |
| 长袍 | 用旋转体（截面曲线绕竖轴旋转）代替圆台：肩部窄而圆，腰部略收，向下逐渐放宽，下摆触地并向外微微展开。截面不是正圆，前后略扁（宽深比约 1.25）。下摆边缘做 5～7 个大的波浪起伏，表示布料垂坠，不做细碎褶皱 |
| 衣褶 | 从肩到下摆 4～6 道竖向的大褶：在旋转体上沿竖线向内压 2～4 厘米（按 4.6 米高的雕像计），褶的宽度上窄下宽 |
| 兜帽 | 不是球。兜帽是一个向前伸出的、开口朝前的壳：后脑圆，顶部略尖，前沿是一道厚 6 厘米的帽檐，帽檐边缘略微外翻。兜帽在肩上与长袍连成一体，肩部看不到接缝 |
| 脸 | **没有脸**。兜帽开口内是一个凹进去的深腔，深度至少 0.25 米（按 4.6 米计），内壁用 `stone` 材质并在顶点色里压暗（环境遮蔽 0.15），从正面看是一团阴影。删掉现在的铜色扁球 |
| 手臂 | 手臂完全藏在袖子里：袖子是从肩部垂下、在肘部向前弯折的两段管状体，袖口宽大（直径约为上臂的 1.6 倍），在胸前两只袖口相对，几乎相碰 |
| 环 | 两只袖口之间捧着那个小环（直径 0.6 米，`patina`），环面朝前，下缘略低于袖口。从袖口里不露手，只看到环被"托住" |
| 比例 | 头（含兜帽）占身高约 1/8.5，比人更小、更修长；肩宽约为身高的 0.2 |
| 下跪 | `statue_kneel`：一膝着地，另一膝立起，长袍盖住腿，形成一个三角形的轮廓；上身略前倾，兜帽低垂；环捧在胸前 |
| 残破 | `statue_broken`：缺头的那一版，断口在颈部，是一个斜向、凹凸不平的断面（见第 2 项的断面做法）；缺一臂的那一版，一侧袖子从肘部断开，环落在脚边的地上。两种都要做，由 `variant` 选 |

**回声人影** `echo_figure` 用同一套造型，高 2.1 米，再做以下区别：

- 分成 `Head`（兜帽）、`Robe`（长袍）、`ArmLeft`、`ArmRight`（袖子）四个节点，各自的原点在关节处（颈、腰、两肩），以便第 11 步做动作。
- 不捧环（回声里需要的道具另外放）。
- 孩子版本 `echo_child`：高 1.3 米，头身比 1:6，长袍到小腿，兜帽更圆。**新增**，原清单没有。

**面数**：雕像 ≤ 5000（不变）；回声人影 ≤ 3000。

### 2. 残破变体的断面

**现状**：残破变体是在完好模型上切掉一个方块，断口是阶梯状的直角缺口，一看就是程序挖的。

**要求**：

1. 断面不是一个平面，也不是直角台阶，而是一个**斜向、起伏的面**：
   - 断面整体与水平成 15°～40° 的倾角（方向随机，按名字派生的种子）；
   - 断面上叠加 3～5 个大的起伏（振幅为构件厚度的 15%～30%）和细碎的凹凸；
   - 断面边缘不规则，从外面看是一条锯齿状的轮廓线，而不是一条直线。
2. 断口附近的边缘有几处**崩缺**：在断面边缘随机选 2～4 处，向内削掉一个不规则的小楔形。
3. 断下来的部分变成**掉落的碎块**：在构件脚边放 2～5 块不规则的石块（做法见第 5 项），总体积大约是缺失部分的 30%（其余的"被时间带走了"）。碎块是构件的一部分，一起导出，一起计算碰撞（碎块用简化的凸包碰撞，太小的不做碰撞）。
4. 断面颜色：断面比表面略浅、略暖（新鲜断面），顶点色亮度乘 1.08。

做法建议：在 Blender 里对完好模型做布尔差集，差集体是一个用噪声位移过的、倾斜的大块；再用一个小的位移修改器给断面加细碎凹凸。程序化路线读取导出后的三角形数据（现在的做法），不需要在 GDScript 里重新实现。

适用：所有 `_broken` 变体，以及 `column_fallen` 的断口。

### 3. 环与径符号

**现状**：大部分刻纹只有"环"，没有"径"。

**要求**：所有刻有符号的构件都要有完整的**环与径**：一个圆环，下方一条竖直的线连到圆环底部，线的长度约为圆环直径的 1.2 倍。

| 构件 | 符号位置 | 尺寸 |
| --- | --- | --- |
| `plaza_ring` | 中心铺装：环在中心，径从环向广场主入口方向延伸，是地面上的一条铺砌带 | 环直径 3 米，径长 3.6 米，宽 0.3 米 |
| `stele` | 正面上半部 | 环直径 0.7 米 |
| `door` | 门楣正中 | 环直径 0.5 米 |
| `mural_panel` | 每块壁画板右下角一个小的作为"落款"，壁画内容另见规格 17 | 环直径 0.25 米 |
| `temple_gate` | 门楣正中一个大的，门框两侧各一列小的（每侧 5 个） | 大环直径 1.6 米；小环 0.3 米 |
| `brazier` | 盆沿外侧，均匀 3 个 | 环直径 0.3 米 |
| `lamp_post` | 铜环中间嵌的 `glyph` 改成完整的环与径 | — |
| `ring_monument` | 台座正面 | 环直径 0.8 米 |

- 符号做成略微凹进石面的 `glyph` 面片（规格 12 第二节）：凹进 1～2 厘米，边缘有一圈 1 厘米的倒角。
- 残破变体的符号如果落在缺失部分上，就跟着缺失，不要把符号"贴"在断面上。
- 新增一个辅助函数（Blender 脚本里）`ring_and_path(position, normal, diameter)`，所有构件共用，保证比例一致。

### 4. 藤蔓

**现状**：`vines` 是几块悬空的方形面片，离墙面有缝，像贴纸。

**要求**：

1. 藤蔓**贴着墙面生长**：
   - 主藤是 2～4 条从墙脚向上延伸的窄条带（宽 4～8 厘米），沿墙面弯曲爬升，彼此交错；
   - 主藤每隔 0.3～0.6 米分出一根短的侧藤（长 0.2～0.6 米）；
   - 叶片成簇长在藤上：每簇 3～7 片，单片是一个两三个三角形的小菱形，朝外略微翘起（与墙面成 10°～30°）；
   - 整片藤蔓的轮廓下密上疏，顶端是几根伸出的细藤尖。
2. 藤蔓的背面紧贴墙面（离墙 1～2 厘米），不能看到悬空的缝。
3. 两个变体：`vines`（宽 2 米、高 1.8 米，从墙脚长起）、`vines_1`（宽 1.2 米、高 2.6 米，从墙顶垂下，下端参差）。
4. 颜色：主藤深绿褐，叶片两种绿交错，个别叶片偏黄。仍用 `cloth` 材质的绿色变体，不摆动。
5. 面数 ≤ 1200。

另外新增一个可攀爬的加密版本 `vine_wall`，给 [滑翔与攀爬](22-滑翔与攀爬.md) 用：宽 3 米、高 6 米，可以竖向平铺；比 `vines` 多一层略微凸出墙面（8～12 厘米）的粗藤（直径 4 厘米），让人一眼看出"能抓"。面数 ≤ 1800。

### 5. 碎石

**现状**：`rubble` 是一堆立方体。

**要求**：

1. 每块石头是**不规则的多面体**：从一个立方体出发，随机切掉 3～6 个角（每刀切掉的深度为边长的 10%～35%），再给所有边倒一个小角（边长的 4%）。不能有两块形状完全一样的石头。
2. 石头大小有层次：每堆有 1～2 块大的（0.8～1.4 米）、4～8 块中的（0.3～0.7 米）、10～20 块小的（0.1～0.25 米）。
3. 摆放：大块先放，有的斜靠在另一块上；中小块堆在大块周围和缝隙里，整体堆成中间高、边缘低的一堆。所有石块都要接触地面或另一块石头，不能悬空。
4. 有几块是**加工过的**：一个面平整、有直角边，看得出是墙或柱子的一部分（这是"倒塌"而不是"天然落石"）。
5. 面数：三个 `rubble` 变体各 ≤ 600（原来是 300，提高上限）。碰撞只给大块和中块做凸包，小块不做。

### 6. 墙、台基与柱子

**现状**：墙段和台基是纯粹的长方体，边缘锐利，表面平整。

**要求**：

| 改动 | 适用 | 做法 |
| --- | --- | --- |
| 基座线脚 | `wall`、`wall_window`、`wall_arc`、`door`、`plinth`、`plinth_round` | 底部 0.3 米高的一圈，比墙面外凸 5 厘米；上沿做 2 厘米倒角 |
| 收分 | `wall`、`wall_window`、`wall_arc`、`door` | 墙体从底部到顶部，厚度从 0.6 米收到 0.5 米（外侧面倾斜，内侧面竖直） |
| 砌缝 | 所有墙和台基 | 表面每 0.6～0.9 米一道水平缝，每段之间的竖缝错开（像砌石）；缝宽 1.5 厘米、深 1 厘米。用几何做（凹槽），不要只靠贴图 |
| 倒角 | 所有石构件 | 外露的边做 2～4 厘米的倒角，不要刀锋一样的直角 |
| 顶部 | `wall`、`wall_window`、`wall_low` | 完好版顶部做一道压顶石：比墙宽 4 厘米，厚 0.15 米 |
| 柱子 | `column` | 柱身做 3% 的卷杀（中间略粗）；柱础两级，柱头一圈环形线脚加一块方形顶板 |
| 风化 | 所有石构件 | 在顶点色里按"朝上、靠边、靠底"加一点亮度变化，把边缘的倒角染得略浅 |

砌缝和倒角会增加面数。中件（墙、柱、拱）的上限从 1200 提高到 1800；如果仍超出，砌缝改为只做在正反两个大面上，侧面和顶面不做。

## 六、第二轮：用真正的建模方法重做人形、藤蔓、碎石（第 4b 步）

> 2026-10-20。用户看过第一轮的展示图后确认：墙、门、石碑、柱子、台基、断面、环与径都合格。但人形、藤蔓、碎石仍然是"脚本里写顶点"的做法，看得出代码拼凑的痕迹。按改写后的 [规格 12](12-遗迹构件与模型规范.md) 第二节，这三类**用 Blender 的建模工具重做**，石头和叶片可以用 CC0 素材。其他构件不动。
>
> 本节取代之前写过的"改顶点顺序、移动袖子起点"的补修方案，那个方案只是在旧做法上打补丁。

### 第一轮发现的两个问题（新做法必须避免）

1. **藤蔓发黑**：叶片和藤条的面法线朝向墙里，卡通光照按背光处理，整片接近黑色（已在云端单独渲染核实：把面翻过来以后，平均颜色从约 `(34, 59, 27)` 变成 `(74, 117, 62)`）。新做法里，所有面都要朝外。
2. **雕像方形护肩**：袖子起点在长袍外面且高于肩线，起点的封口斜着露出来，正面看两肩各有一块尖角。新做法里，袖子是布料，从肩部自然垂下，看不到任何封口。

### 1. 人形

涉及：`statue`、`statue_kneel`、`statue_broken`、`statue_arm_broken`、`echo_figure`、`echo_child`。造型要求不变（第二节第 1 项：修长、兜帽深腔、无脸、长袍及地、袖子宽大、双袖托环）。

做法：

1. **基础人体**：用蒙皮修改器（Skin）在一串顶点骨架上生成平滑的人体，再加细分曲面。比例：头约为身高的 1/8.5，肩宽约为身高的 0.2，四肢修长。人体只用来"撑"起布料，最终不可见（可以在模拟后删掉，或者留在长袍里面）。
2. **骨架与姿势**：给人体加骨架（Armature），骨骼至少有：根、脊柱 2 节、颈、头、左右上臂、前臂、手、左右大腿、小腿、脚。
   - 站立：前臂向前弯到胸前，两手相对，托住环的位置；
   - 跪姿：一膝着地、一膝立起，上身略前倾，头低垂；
   - 孩子：同一套骨架，比例按 1:6 的头身比缩放。
3. **长袍**：一个从肩到地的圆筒网格，罩在摆好姿势的人体上，用布料模拟（Cloth）：
   - 颈部和肩部的顶点固定（Pin Group）；
   - 碰撞对象是人体；地面是一个平面碰撞体，下摆落地后自然铺开；
   - 模拟固定帧数（例如 80 帧）后应用；
   - 布料网格分辨率不要高（例如 24～32 段一圈），褶子就大而简洁，和卡通画风一致；跪姿时长袍会自然盖住膝盖，形成三角形的轮廓。
4. **兜帽**：同样用布料模拟罩在头上，或者用一个开口朝前的壳加实体化（Solidify）和细分做出来。帽檐外翻；开口内是至少 0.25 米深的腔（按 4.6 米计），腔内顶点色压暗。
5. **袖子**：沿上臂和前臂的布料筒，袖口宽大、敞开（实体化给出厚度，**不封口**），在胸前两袖口相对。袖子和长袍在肩部连成一片：可以把袖子和长袍做成同一块布料一起模拟，或者模拟后用布尔并集再平滑接缝。**正面逆光看，肩部是一条从脖子到上臂的连续弧线。**
6. **环**：圆环体（Torus），`patina` 材质，托在两袖口之间。
7. **残破变体**：在完好的雕像上用现有的 `fracture()` 做断面（缺头、缺一臂），断面规则不变。
8. **减面**：最后用减面修改器压到预算：雕像 ≤ 5000，`echo_figure`、`echo_child` ≤ 3000。

**回声人影改用骨骼动画**：

- `echo_figure`、`echo_child` 导出为**带骨架的蒙皮模型**（glTF 支持），不再拆成 `Head`、`Robe`、`ArmLeft`、`ArmRight` 四个节点。长袍跟着骨骼变形，走路时下摆会自然摆动，比节点变换好得多。
- 蒙皮权重：长袍下摆主要跟大腿和小腿骨，袖子跟手臂骨。
- 这一步只做骨架、蒙皮和静止姿势。规格 17 里的各种动作（`walk`、`kneel`、`sit`、`raise`、`carry`、`paint`、`child_run`、`old_walk`、`place`）在第 11 步用 Blender 做成动画，一起导出到 glb 里（见规格 17）。
- 雕像是静止的，摆好姿势后应用骨架，导出普通网格。

### 2. 藤蔓

涉及：`vines`、`vines_1`、`vine_wall`。尺寸不变。

做法：

1. **藤条**：在墙面平面上生成几条向上（`vines_1` 向下）生长的路径，可以用随机游走加向上的偏向；路径转为曲线，加倒角，半径从根部 2.5 厘米渐细到藤尖 0.5 厘米。主藤之间偶尔交叉。侧藤从主藤上分出，同样做法、更细更短。
2. **叶片**：
   - 优先用 CC0 的常春藤或藤蔓叶片模型；没有合适的，在 Blender 里建 2～3 种叶片：心形或掌形轮廓，中间沿叶脉略微折起，每片 4～8 个三角形；
   - 用几何节点沿藤条取点实例化叶片：叶片贴着墙、向外翘起 10°～30°，随机旋转和缩放（0.7～1.3），下部密、上部疏；
   - 叶片颜色仍用 `cloth` 材质的绿色，顶点色 R 通道给一点明暗变化（0.85～1）。
3. **贴墙**：藤条和叶片背面离墙 1～2 厘米，不能悬空，也不能穿进墙里。
4. **面的朝向**：所有面的法线朝向墙外，导出前统一检查。
5. `vine_wall`：在上面的基础上加一层更粗的攀爬藤（半径 4 厘米，凸出墙面 8～12 厘米），让人一眼看出"能抓"。
6. 面数：`vines`、`vines_1` ≤ 2000，`vine_wall` ≤ 3000。

### 3. 碎石

涉及：`rubble`、`rubble_1`、`rubble_2`。

做法：

1. **石块**：
   - 优先用 CC0 的石头模型（低多边形风格的更合适；照片扫描的只取形状，减面）。选 6～10 种形状，缩放和旋转后反复使用；
   - 没有合适素材时：二十面球 → 体素重建网格 → 噪声纹理位移（Voronoi 加噪声）→ 减面 → 小倒角。
2. **加工过的石块**：每堆 2～3 块，从现有的墙或柱子构件上用布尔切下一块（保留一两个平整面和直角边），表示倒塌的建筑，不是天然落石。
3. **堆叠**：用刚体模拟（Rigid Body）。大块先落，中块、小块随后从上方随机位置落下，模拟到静止（例如 120 帧）后应用。结果自然是中间高、边缘低，石块互相斜靠，没有悬空。
4. 三个变体用不同的种子和石块组合。
5. 面数：每堆 ≤ 900。碰撞只给大块和中块做凸包，小块不做，规则不变。
