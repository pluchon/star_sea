# 规格 24：植被、动物、地标岩石与飞船重做

## 一、为什么做

晨上大部分会被看到的东西，现在仍然是在代码里拼出来的：

| 现在 | 文件 |
| --- | --- |
| 9 种植被：草、阔叶树、松树、灌木、花、石块、蕨、芦苇、蘑菇 | `game/scripts/planet/vegetation_meshes.gd` |
| 鸟、鹿形生物、萤火 | `game/scripts/planet/wildlife.gd` |
| 海蚀柱、天然石拱、旗等地标 | `game/scripts/planet/landmark_meshes.gd`、`stonework_meshes.gd` |
| 飞船 | `art/blender/build_ship.py`（在脚本里写顶点） |

按 [规格 12](12-遗迹构件与模型规范.md) 第二节的原则（人和东西要用真正的建模工具做），这些都换成 Blender 建的模型或 CC0 素材。用户已同意。

不改的：地形、水面、天空、云、雨、草地的远景着色（这些本来就该是着色器和程序生成）。萤火是发光的小点，保持现在的做法。

## 二、总原则

- 建模方法、CC0 素材的使用、四视图自查、面的朝向，全部按规格 12 第二节。
- 画风是卡通：形状简洁、轮廓清楚、色块分明。CC0 素材优先选低多边形或卡通风格的（例如 Quaternius、Kenney 的自然类素材包，都是 CC0）；照片扫描的素材只取形状、减面。
- **替换，不改规则**：每种东西的名字、出现在哪个群系、密度、远近细节层级、碰撞、MultiMesh 的用法都不变。`ecology_checks` 里关于群系和分布的检查数字不应该变化。变的只是网格本身。
- 模型统一输出到 `game/models/nature/`、`game/models/wildlife/`、`game/models/ship/`，由 `tools/Build-Models.ps1` 的新目标 `-Target nature`、`-Target wildlife` 和已有的 `-Target ship` 生成。
- 原来的 GDScript 网格函数在新模型接入后删除，不保留两套。

## 三、植被

| 种类 | 要求 | 面数（LOD0） |
| --- | --- | --- |
| `broadleaf` 阔叶树 | 3 个变体。树干有分叉和根部隆起；树冠是几团大的、轮廓清楚的叶团，不是一个球。树冠用卡通的块面，不做单片叶子 | ≤ 1500 |
| `pine` 松树 | 3 个变体。一层层下垂的枝层，顶端尖，树干略弯 | ≤ 1200 |
| `shrub` 灌木 | 2 个变体。几团叶团挤在一起，底部看得到几根细枝 | ≤ 500 |
| `fern` 蕨 | 2 个变体。从中心放射的弯曲叶片，叶片有锯齿状的边 | ≤ 300 |
| `reeds` 芦苇 | 2 个变体。一丛细长、略弯的茎，几根顶端有穗 | ≤ 250 |
| `flowers` 花 | 3 种颜色。细茎加小花头，花瓣是 4～6 片的小块面 | ≤ 150 |
| `mushrooms` 蘑菇 | 2 个变体。一簇 3～5 个，菌盖有弧度 | ≤ 200 |
| `grass` 草 | 一簇弯曲的草叶，叶片宽窄不一 | ≤ 80 |
| `stone` 石块 | 和碎石共用同一批石头（规格 23 第六节），挑形状圆润的 4～6 种 | ≤ 200 |

- **风**：现在的风动靠顶点的 `UV2.x` 作为摆动权重（根部 0，梢部 1），着色器 `surface_detail.gdshaderinc` 读取。新模型导出时按"离根部的高度"写入同样的权重，着色器不改。
- **颜色**：沿用现在各群系的配色，写在顶点色里，规则和现在一致。导出前对照现有截图，颜色不要整体变亮或变暗。
- **LOD**：现在的阔叶树、松树等有两级简化（`lods` 0.08 和 0.35）。新模型用 Godot 导入时自动生成 LOD，或在 Blender 里导出两个减面版本，二选一，在记录里写明。
- **面的朝向**：草叶、蕨叶、花瓣这类单面，法线朝上或朝外；着色器现在对单面是否双面渲染的设置保持不变。

## 四、动物

| 动物 | 要求 | 面数 |
| --- | --- | --- |
| 鸟 | 一种修长的海鸟或雨燕形的鸟，翅膀宽长。骨架：身体、两翼各两节、尾。动画：`flap`（扇翅）、`glide`（滑翔，翅膀平展微调） | ≤ 300 |
| 鹿形生物 | 修长的四足动物，比真实的鹿更细长、颈更长，头上有一对向后弯的细角，尾巴短。骨架标准四足。动画：`idle`（低头吃草、抬头张望）、`walk`、`run`、`alert`（竖起头、耳朵转动） | ≤ 2000 |

- 动画在 Blender 里做成关键帧，导出到 glb。
- **鸟群是 MultiMesh**，不能逐只播放骨骼动画。做法：把 `flap` 动画烘焙成顶点动画纹理（每帧顶点位置存进一张小纹理），着色器按时间和每只鸟的相位读取；或者鸟群保持顶点着色器扇翅，只把网格换成新模型。选更简单可靠的那个，在记录里写明。
- 鹿群数量少，逐只用 `AnimationPlayer` 播放即可。现在 `wildlife.gd` 里鹿的移动逻辑（靠近就逃）不变，只把"走/跑/吃草/警觉"接到对应的动画。

## 五、地标岩石

- 海蚀柱、出发地附近的天然石拱：用 Blender 的方法重做（体素重建网格、噪声位移、分层的岩石纹理感，顶部有草皮）。尺寸、位置、碰撞的规则不变。
- 灯塔残骸、巨环、旗：属于远行者的东西。灯塔和巨环用遗迹构件重建（规格 12 第六节"人工确认"里早已提到）；旗用 `cloth` 材质的布面模型，保留现在的随风摆动。
- `LandmarkMeshes` 里对应的函数在替换后删除。

## 六、飞船

- 外形规格见 [规格 10](10-飞船与步行.md) 第五节，尺寸和碰撞不变。
- 用 Blender 的建模方法重做：主体用细分曲面做出流畅的外壳曲面，倒角修改器做出面板的边，舱盖、引擎、起落架是单独的部件；面板缝用几何做浅槽。
- 起落架和舱门的收放、开合如果需要动画，在 Blender 里做成关键帧，不在代码里拼变换。
- 面数 ≤ 8000。

## 七、实现顺序与验收

按"植被 → 动物 → 地标岩石 → 飞船"的顺序，各自可以单独提交。

### 自动检查

- `ecology_checks`、`ecology_runtime_checks` 通过，群系和分布的数字和替换前一致。
- `ship_checks` 通过。
- 新增 `nature_checks.gd`（可无界面）：每种植被、动物都能加载；面数不超过上表；包围盒尺寸和替换前相差不超过 30%（避免尺度失误）；风动权重存在且根部为 0。

### 自查与机位

- 每个模型的 Blender 四视图（规格 12 第二节）。
- 重新截这些已有机位，和替换前的同一机位并排比较：`s3_ground_day`、`s4_ground_sunset`、`s9_woodland`、`s13_tree_detail`、`s14_third_person`、`s18_meadow`～`s22_tundra`、`s23_ship_parked`、`s24_ship_low`。
- 性能：植被是全场景最多的东西，替换后上面这些机位的平均帧时间增加不能超过 1 ms，否则先减面。这一步要在本机测性能，是例外。
