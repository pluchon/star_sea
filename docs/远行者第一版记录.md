# 远行者第一版试玩记录

2026-10-24。晨的主线与第 25 步画面打磨已收尾，可开始第一版试玩。主线已按断点接续验证到字幕后恢复控制。

**怎么玩**：选择新旅程，从海边沿古道驾驶飞船到河畔古城，在广场停留观看日常回声；沿道路到回声洞，进入大厅观看信仰回声，再返回洞外。沿烽火塔链飞过山口，在末塔登顶观看守望回声。天梯主门外约 150 米的台地可以降落，先对准正面石阶，再进入主门观看启程回声。乘升降台到 2455 米观景环，返回台地登船，飞至 6160 米断口停泊台，沿石环与栈桥观看终章，再沿光之路飞行六十秒进入字幕，之后继续自由探索。

**操作**：WASD／鼠标移动与环顾，Shift 加速，空格跳跃，离地后再次按空格展开软翼；面向标出的藤蔓或绳索攀爬。F 降落／登船，远处长按 1.2 秒召唤；V 切换视角，M 查看地图，Esc 打开菜单与手记。塔阶断口和塔冠入口需要跳跃。

| 本轮核心动作 | 游戏内实测时间 |
| --- | --- |
| 古道飞行、古城回声 | 飞行 77 秒；含登船、降落、观看约 2.3 分钟 |
| 古城至洞口、大厅回声并返回 | 道路加速步行 5.3 分钟；连同洞内往返和观看约 7.8 分钟 |
| 塔链、末塔回声 | 飞行 79 秒，末塔回声 21 秒 |
| 天梯观景 | 升降纯行程各 75 秒，往返含步行约 3 分钟 |
| 终章、光之路、字幕 | 终章 32 秒，光路累计 60 秒，字幕约 23 秒 |

熟悉路线、驾驶飞船并加速步行，按这些动作时间估算约 20～30 分钟；首次探索、找路和加载另计。古道普通步行约 45 分钟，古城到洞口普通步行约十分钟。主线采用真实已完成断点接续，未做单进程无中断通关；详见[主线自查与截图](画面打磨记录.md)。

**验收与性能**：已执行一次 Scope all，修复后仅复查受影响项目，功能检查通过。56 个机位中 4 个帧时间超预算，瀑布上传峰值 4.083 毫秒；冷缓存降落有 3 帧超过 50 毫秒，最慢 191 毫秒。洞穴创建也有峰值偏差，完整数值与验收范围见[性能对照](远行者第一版性能对照.md)。

**还没做／限制**：暗河洞、青晶洞、小洞穴，植被、动物、地标与飞船重做均属于后续阶段。山口塔完整上下行未复查；回声洞第二出口未接规定河谷。观景环的古城轮廓较小，夜间大厅巨像阴影较重；其他未检查项见主线记录。音乐只用于个人游玩，个人听感留待试玩。
