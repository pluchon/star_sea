# 飞船与步行

2026-10-20。对应「远行者」原第 0、1 步，属于合并后的第一大阶段。总体验收见[第一阶段验收记录](远行者第一阶段验收记录.md)。

## 实现

- 飞行改为驾驶探索船。地面上短按 F 登船，低空低速时短按 F 降落，远处按住 F 1.2 秒召唤。过渡期间不接受操作。
- 降落检查中心与两圈共九个点，拒绝海面、河湖、陡坡和地标占地。停放后保留船体凸包和舷梯碰撞；玩家从左侧下船。
- 减速阶段积分 0.6 秒的平滑速度曲线，保留实际前移距离，再从停留点下降；预测停留点也检查地面，避免出现先前移再退回的动画。
- 召唤沿球面飞行，途中根据实际高度抬升，玩家远离落点时重新选择。不同星球之间拒绝召唤。
- 第一人称隐藏船体；第三人称驾驶显示船体并扩大相机距离。步行显示探索者。屏幕保留淡色飞船方位标记与短暂操作提示。
- 存档新增船上状态、飞船所在星球、局部位置和朝向；召唤途中保存为目标位置。读取前完整检查，非法字段不修改角色或飞船。旧步行存档会补放飞船。

飞船原点与视觉底面分开：停放时原点离地 1.2 米，视觉底面向下偏移 1.2 米，支架接触地面；驾驶时调整挂接位置，避免现有贴地保护下支架穿地。

召唤采用 2 秒直接抬升到 120 米巡航高度，省去规格中 60 米高度的中间停留，保持起飞过程连续；总时间仍由巡航速度和两端过渡决定。

## 模型与声音

Blender 4.5.9 LTS 便携版位于 `D:\Godot\tools\blender-4.5.9-windows-x64\`，没有依赖原有系统安装。`art/blender/build_ship.py` 确定性生成模型和备用网格数据，模型共 3436 个三角形，低于 4000 的预算。船体、短翼、玻璃、红色饰条、双引擎、三个支架和左侧舷梯分别建模。

```powershell
.\tools\Build-Models.ps1 -Target ship
python tools/Generate-Audio.py --only ship
```

引擎分为低频旋转谐波和滤波气流；落地分为三支支架的错时冲击、阻尼共振与减压气声；舱门分为锁扣、电机滑动和末端锁止。音频由项目代码生成，没有使用参考目录里的候选音乐。

实际录音检查曾发现重新挂接飞船时引擎资源遭到清空，已修复。录音时先停止前一个事件并等待混音缓冲更新，避免把模拟召唤结束的落地声叠入引擎独立录音。

## 验证

`ship_checks.gd` 覆盖真实 F 键短按／长按、带水平速度的降落与暂停、碰撞、召唤、驾驶与停放存档、途中保存、非法字段拒绝和旧存档。一次固定场景的检查结果：下船距离 4.34 米，3 公里召唤约 24.02 秒，221 个水面拒绝样本、31 个陡坡拒绝样本、5 类非法飞船字段均通过；减速下降期间没有反向回退。参数与种子固定，结果不代表任意地形都已覆盖。

引擎、落地、舱门均保留实际 3D 混音录音，并通过 `Check-Audio.py --ship-recordings test-output/wanderer/audio` 检查。非静音、无削波、播放位置推进与录音完整性可以自动确认，声音是否自然仍属于听感判断。

新增机位 `s23_ship_parked`、`s24_ship_low`。原相机检查继续验证旋转、缩放、无输入漂移和径向对齐；原 F 键自由起飞断言改为登船、完整降落断言。

## 基线

修改前使用 `c71153b` 导出的固定 Windows 包执行基线，报告保留在 `test-output/wanderer/baseline/`。源码开发没有更改这份基线包。

原完整验收在阔叶林 `s19_broadleaf` 因性能中止：首次平均 13.10 ms，复测 12.64 ms，均超过 12.5 ms 的预算。保留两次原始报告，再补齐剩余机位、降落和行走检查，没有把该基线写成全部通过。

基线连续降落平均 6.61 ms、P99 10.64 ms，最大地形上传 1.88 ms，前三秒后没有超过 50 ms 的帧；连续行走水平位移 143.18 米，最低离地误差约 -0.0062 米。

## 范围边界

当前尚无洞穴和文明区运行时系统，相关的禁止降落／召唤条件将在它们接入时补入公共查询，不建立虚假的占位判断。飞船模型、起降过程和声音的主观观感需结合本机试玩。
